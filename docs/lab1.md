## 준비

- 강사가 배부한 교육용 M365 계정으로 로그인합니다. 브라우저는 **Microsoft Edge**를 씁니다.
- 실습 SharePoint 사이트는 `pa_practice` 하나입니다. 수강생 전원이 같은 사이트를 씁니다.
- 교육생 전원이 교육 계정 하나와 같은 사이트·환경을 씁니다. 이름이 있는 객체(목록·흐름)에는 끝에 본인 이니셜을 붙입니다.
- 메일·Teams 메시지도 전원이 같은 받은 편지함으로 받습니다. 그래서 흐름이 보내는 문구 앞에 이니셜(`HGD`)을 넣습니다.

## 확인

**필수**: 여기까지 되면 이 랩은 통과입니다

- ① 본인 이니셜이 붙은 `업무요청_HGD` 목록에 제목 · 요청자 · 긴급 · 마감일 열이 있다 (4~8번)
- ② 긴급 예로 실행하면 Teams에 흐름 봇 메시지가 온다 (35·36번)
- ③ 긴급 아니요로 실행하면 접수 알림 메일이 온다 (37·38번)
- ④ 목록에 두 항목이 있고 요청자에 본인 이름이 들어 있다 (39번)
- ⑤ 실행 기록 두 건이 성공이다 (40번)
- ⑥ 마감 알림 메일의 건수가 목록에서 마감일이 오늘이거나 지난 항목 수와 같다 (51·52번)

**관찰**: 나오면 좋고, 안 나와도 실패가 아닙니다

- ⑦ 작성 카드의 출력이 UTC가 아니라 한국 날짜로 나온다 (51번)
- ⑧ 배열 필터링 카드의 출력에 항목이 마감일 조건에 맞는 것만 남는다 (51번)

## 여기까지의 흐름

흐름 두 개를 새로 만들었습니다.

`업무요청 접수_HGD`

```
수동으로 흐름 트리거  (입력: 제목 · 긴급 · 마감일)
├─ 항목 만들기  pa_practice · 업무요청_HGD
│    제목 = 제목 · 요청자 = 사용자 이름 · 긴급 = 긴급 · 마감일 = 마감일
└─ 조건  긴급 is equal to true
   ├─ True:  채팅 또는 채널에서 메시지 게시  흐름 봇 · 흐름 봇과 채팅 · 본인
   └─ False: 이메일 보내기(V2)  받는 사람 = 본인 · 제목 = HGD 업무요청 접수 알림
```

`마감 알림_HGD`

```
되풀이  (1일 · (UTC+09:00) 서울)
├─ 작성  formatDateTime(convertFromUtc(utcNow(), 'Korea Standard Time'), 'yyyy-MM-dd')
├─ 항목 가져오기  pa_practice · 업무요청_HGD
├─ 배열 필터링  원본 = value · 마감일 is less than or equal to 출력(작성)
└─ 이메일 보내기(V2)  받는 사람 = 본인 · 제목 = 마감 알림
     본문 = 문구 + length(body('배열_필터링')) + 건
```
