## 여기까지의 흐름

빈 흐름에 아래 열두 개 카드가 생겼습니다. 이름 오른쪽은 핵심 설정값입니다.

```
Recurrence                1 개월 · 2026-11-01T00:00:00Z(한국 09:00) · (UTC+09:00) 서울
├─ 대상월                 작성 · formatDateTime(addToTime(...),'yyyy-MM')
├─ 원본행                 테이블에 있는 행 나열 · 점검기록.xlsx › 점검기록
├─ 점검행                 배열 필터링 · From 원본행 · 점검월 다음과 같음 대상월
├─ 조치필요               배열 필터링 · From 점검행 · 결과 다음과 같지 않음 정상
├─ 주의행                 배열 필터링 · From 점검행 · 결과 다음과 같음 주의
├─ 이상행                 배열 필터링 · From 점검행 · 결과 다음과 같음 이상
├─ 건수                   작성 · concat(... length() ...)
├─ 선택                   원본 조치필요 · 설비명·구역·점검항목·측정값·결과·조치내용
├─ HTML 테이블 만들기      From 선택 출력
├─ 보고서                 작성 · HTML 틀 + 대상월·건수·HTML 테이블 출력
└─ 파일 만들기            Power Automate 실습 · /Shared Documents/보고서 · 정기점검_<대상월>_HGD.html
```
