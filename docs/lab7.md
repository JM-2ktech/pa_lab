## 준비

- PX-ERP 실행 파일이 `C:\PA실습\PxErp\PxErp.exe` 에 있어야 합니다. 강사가 나눠 준 파일을 이 위치에 둡니다. 설치는 필요 없습니다.

- ② 요청 세 건이 차례로 입력되고, 결과 파일 D열에 S 2건 · E 1건이 적힌다 (41번)
{: .checklist }

**관찰**: 나오면 좋고, 안 나와도 실패가 아닙니다

- ③ 창 선택기에서 제목을 빼지 않으면 두 번째 화면에서 창을 찾지 못한다 (26번)
- ④ 구매 보류 건 뒤에도 `/nPO01` 덕분에 다음 건이 깨끗한 화면에서 시작한다 (24번)
{: .checklist }
