### PX-ERP 명령 필드

PX-ERP 는 SAP GUI 를 본뜬 실습용 앱입니다. 화면 맨 위 명령 필드에 트랜잭션 코드를 넣고 `Enter` 를 누르면 그 화면이 열립니다. 이 랩에서 쓰는 것은 아래 넷입니다.

- `PO01` — 발주 생성 화면을 엽니다. 코드만 넣는 것은 시작 화면에서만 됩니다.
- `/nPO01` — 지금 화면을 저장하지 않고 닫은 뒤 발주 생성 화면을 새로 엽니다. 다른 화면 안에서는 이렇게 `/n` 을 앞에 붙입니다.
- `/n` — 저장하지 않고 시작 화면으로 돌아갑니다.
- `/nex` — 저장하지 않고 앱을 닫습니다. 확인 창이 뜨지 않습니다.
