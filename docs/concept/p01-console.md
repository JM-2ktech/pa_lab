## 콘솔

콘솔은 데스크톱용 Power Automate 의 중심 화면입니다.[^console] 흐름을 만들고 실행하고 디자이너로 여는 일을 여기서 합니다.

| 위치 | 있는 것 | 하는 일 |
|---|---|---|
| 제목 표시줄 오른쪽 위 | 계정 이름 | 로그인한 계정 확인. 테넌트가 둘 이상이면 조직 전환 |
| 오른쪽 위 | 환경 | 작업할 환경 확인과 전환 |
| 왼쪽 막대 | 홈 · 흐름 · 공유 흐름 · 예제 | 화면 전환 |
| 위쪽 · 가운데 | + 새로운 · 새 흐름 | 흐름 만들기 |
| 흐름 줄 | 실행 · 중지 · 편집 | 실행 · 멈추기 · 디자이너 열기 |
| 흐름 줄 | 상태 열 | 각 흐름의 현재 상태 |
| 설정 | 설정 단추 | 아래 「콘솔 설정」 |

현재 환경의 권한이 부족하면 일부 옵션이 꺼져 있을 수 있습니다.[^console] 입력 변수가 있는 흐름을 콘솔에서 실행하면 값을 묻는 창이 뜹니다. 여러 사람이 공유 흐름을 고치면 마지막에 저장한 내용만 남습니다.[^console]

---

## 흐름 줄의 상태

| 화면 | 뜻 |
|---|---|
| 아이콘에 금지 표시 · 실행과 중지 꺼짐 | 게시하지 않은 흐름 |
| 상태 현재 편집 중 · 편집 꺼짐 | 디자이너가 열려 있음 |
| 상태 실행되고 있지 않음 · 실행과 편집 켜짐 | 게시했고 디자이너가 닫혀 있음 |

## 콘솔 설정

| 묶음 | 항목 |
|---|---|
| 모양 | 라이트 · 다크 · 시스템 기본값 |
| 흐름 실행 제어 | 모니터링과 알림 방식 · 일시 중지와 재개 단축키 · 중지 단축키 · 외부에서 호출할 때의 확인 창 |
| 데이터 수집 | 진단 데이터 수집 여부. 관리자만 변경 |
| 일반 | 업데이트 알림 표시 · 업데이트 확인 |

## 흐름 속성

흐름을 마우스 오른쪽 단추로 눌러 **속성**을 고릅니다.[^console]

| 탭 | 항목 |
|---|---|
| 일반 | 이름 · 설명 · 바로 가기 키 · 태그(미리 보기) · 오류 시 동작 · 로그에 스크린샷 추가 · 흐름 시간 제한 |
| 세부 정보 | 소유자 · 만든 날짜 · 마지막 수정 날짜 · 흐름 ID · 스키마 버전 · 실행 URL |

**흐름 시간 제한**은 기본으로 꺼져 있습니다. 켜면 정한 시간에 도달한 흐름이 멈춥니다. 콘솔이나 클라우드에서 시작한 실행에 적용합니다.

설명은 칸 아래의 단추로 Copilot 이 만들 수 있습니다. 회사 또는 학교 계정에서 쓰며, 지원 지역에 대한민국이 들어 있습니다. 흐름 실행 로그를 보는 기능은 프리미엄 구독이 필요합니다.[^console]

## 디자이너의 구성

디자이너는 흐름을 만들고 디버그하는 별도의 창입니다.[^designer]

| 영역 | 위치 | 하는 일 |
|---|---|---|
| 작업 창 | 왼쪽 | 작업 찾기와 놓기 |
| 작업 영역 | 가운데 | 흐름을 이루는 작업을 차례로 놓는 칸. 줄 번호가 실행 순서 |
| 탭 줄 | 작업 영역 위 | Main · 하위 흐름 탭 · + 새로운 |
| 변수 창 | 오른쪽 | 입력 · 출력 · 흐름 변수. 상세는 [P6](p06-variable-pane.html) |
| 세로 막대 | 맨 오른쪽 | {x} 변수 창과 UI 요소 창 여닫기 |
| 도구 모음 | 위쪽 | 저장 · 게시 · 실행 · 중지 · 다음 작업 실행 · 기록기 |
| 메뉴 | 맨 위 | 파일: 초안 저장 · 게시 · 다른 이름으로 저장 · 종료 |
| 상태 표시줄 | 아래쪽 | 흐름 상태 · 선택한 작업 수 · 전체 작업과 하위 흐름 수 · 오류 수 · 실행 지연 |

실행과 디버그 도구는 [P9](p09-debug.html)에서 다룹니다.

## 작업 창

| 조작 | 방법 | 조건 |
|---|---|---|
| 찾기 | 맨 위 검색 칸에 이름 입력 | 두 글자 이상. 부분 일치. 모듈 이름과 맞으면 그 모듈의 작업을 모두 펼침 |
| 놓기 | 두 번 클릭 · 작업 영역으로 끌어다 놓기 | 놓으면 대화 상자가 열림 |
| 즐겨찾기 | 작업 오른쪽의 별 아이콘 | 즐겨찾기 묶음에 같은 구조로 표시. 그 PC의 모든 흐름에 적용 |
| 추천 작업 | 줄에 마우스를 올리거나 줄을 고를 때 나오는 추가 단추 | 회사 또는 학교 계정. 지원 지역에 대한민국 포함. 관리자가 끌 수 있음 |

검색 결과는 모듈 이름 아래에 묶여 나옵니다.[^actions] `폴더 만들기` 를 입력하면 폴더 묶음과 SharePoint 묶음의 작업이 함께 나오므로 묶음 이름을 보고 고릅니다.

## 작업 대화 상자

작업은 세 부분으로 설정합니다.[^actions]

| 부분 | 내용 | 조건 |
|---|---|---|
| 입력 칸 | 글자 칸 · 드롭다운 · 토글 | 칸마다 받는 자료형이 있음. 맞지 않으면 오류. 칸 오른쪽 위 {x} 로 변수 선택 |
| 변수 생성됨 | 작업 결과가 담기는 변수 | 토글을 끄면 만들어지지 않음. 이름을 바꿀 수 있음 |
| 오류 | 작업이 실패했을 때의 처리 | 대화 상자 왼쪽 아래. 상세는 [P18](p18-errors.html) |

일부 칸에는 기본값이 들어 있습니다. 설정이 끝나면 **저장**을 누릅니다.

## 작업 영역 조작

| 조작 | 방법 |
|---|---|
| 순서 바꾸기 | 줄을 끌어 옮김 |
| 여러 줄 고르기 | `Ctrl` + 클릭 · `Shift` + 클릭(첫 줄과 끝 줄) · `Ctrl` + `A`(전체) |
| 복사 · 잘라내기 · 붙여넣기 | 오른쪽 단추 메뉴 · `Ctrl` + `X` · `Ctrl` + `V` |
| 끄기 · 켜기 | 오른쪽 단추 › 작업 사용 안 함 · 작업 사용 |
| 지우기 | `Delete` · 오른쪽 단추 › 삭제 |
| 흐름 안에서 찾기 | 오른쪽 위 검색 칸 · `Ctrl` + `F`. 결과를 두 번 클릭하면 그 줄 강조 |
| 줄 번호로 가기 | 편집 › 줄로 이동 |

복사하면 매개 변수 · 이미지 · UI 요소가 함께 복사됩니다. 같은 하위 흐름, 다른 하위 흐름, 다른 디자이너 창에 붙여넣을 수 있으며, 다른 창에 붙일 때는 양쪽 버전이 같아야 합니다.[^workspace]

끈 작업은 실행할 때 건너뜁니다. 그 작업이 만든 변수는 변수 창에서 숨겨지고, 그 변수를 쓰는 다른 작업은 오류로 표시될 수 있습니다.[^actions]

## 하위 흐름

모든 흐름에는 Main 하위 흐름이 있고, 흐름을 시작하면 Main 부터 실행합니다. 다른 하위 흐름은 **하위 흐름 실행** 작업으로 부를 때만 실행합니다.[^workspace]

탭 줄 오른쪽의 **+ 새로운**으로 추가합니다. 추가 창에서 이름과 범위를 정하며, 범위는 만든 뒤 바꿀 수 없습니다.[^scoped] 하위 흐름의 쓰임은 [P19](p19-subflows.html)에서 다룹니다.

## 저장과 게시

| 명령 | 위치 | 결과 |
|---|---|---|
| 저장(초안 저장) | 도구 모음 저장 · `Ctrl` + `S` | 최신 초안 생성. 공식 버전은 바뀌지 않음 |
| 게시 | 도구 모음 게시 | 콘솔과 클라우드에서 실행되는 버전 생성. 켜진 작업이 하나 이상 있어야 누를 수 있음 |
| 다른 이름으로 저장 | 파일 › 다른 이름으로 저장 · `Ctrl` + `Shift` + `S` | 현재 상태를 새 흐름으로 저장 |
| 버전 기록 | 버전 기록 창 | 버전마다 날짜와 사용자 표시. 보기 · 비교 · 복원 |

이 동작은 버전 관리가 적용된 환경의 동작입니다. 버전 관리는 v2.62(2025년 11월)부터 지원하며 환경에 순차 적용합니다.[^version]

## 샘플

작업을 찾아 놓고, 끈 작업의 변수가 다른 줄에 주는 영향을 확인합니다. 흐름 `개념 연습_HGD` 를 씁니다. 없으면 [P2](p02-types.html)의 1·2번으로 만듭니다.

1. 콘솔 흐름 목록에서 `개념 연습_HGD` 의 **편집**을 누릅니다. 디자이너가 이미 열려 있으면 그 창을 씁니다.
2. **Main** 탭의 빈 곳을 한 번 누르고 `Ctrl` + `A` 로 전체를 고른 뒤 `Delete` 키를 누릅니다.
3. 작업 검색 칸에 `메시지 상자` 를 입력합니다.

    **완료 기준**: **메시지 상자** 묶음이 펼쳐지고 **메시지 표시**와 **입력 대화 표시**가 보인다.

4. **메시지 표시** 오른쪽의 별 아이콘을 누르고 작업 검색 칸을 비웁니다.

    **완료 기준**: 작업 창의 **즐겨찾기** 묶음에 **메시지 표시**가 있다.

5. 작업 검색 칸에 `변수 설정` 을 입력하고 **변수 설정**을 두 번 클릭합니다. **변수** 칸과 **값** 칸에 아래를 차례로 넣고 **저장**을 누릅니다.

    ```
    과정명
    ```

    ```
    PAD 기본
    ```

6. 작업 창의 **즐겨찾기** 묶음에서 **메시지 표시**를 1번 줄 아래로 끌어다 놓습니다. **표시할 메시지**에 아래를 넣고 **저장**을 누릅니다.

    ```
    %과정명% 과정입니다.
    ```

7. 도구 모음의 **실행**(▶)을 누르고 메시지 창의 **확인**을 누릅니다.

    **완료 기준**: `PAD 기본 과정입니다.` 가 뜨고, 변수 창의 **흐름** 묶음에 `과정명` 이 보인다.

8. 1번 줄을 마우스 오른쪽 단추로 눌러 **작업 사용 안 함**을 고릅니다.

    **완료 기준**: 1번 줄이 흐려지고, 2번 줄에 오류 아이콘이 붙고, 변수 창에 `과정명` 이 없다.

9. 창 아래 상태 표시줄의 오류 수를 누릅니다.

    **완료 기준**: 오류 창의 목록에 하위 흐름 `Main` 과 줄 번호 2가 보인다.

10. 1번 줄을 마우스 오른쪽 단추로 눌러 **작업 사용**을 고릅니다.

    **완료 기준**: 2번 줄의 오류 아이콘이 사라진다.

11. 도구 모음의 **저장**을 누릅니다.
