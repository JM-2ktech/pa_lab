> **다루는 것**: 데스크톱 흐름의 변수가 담을 수 있는 자료형과 만드는 방법
>
> **쓰는 곳**: Lab 4 `%CurrentItem%` · `%CurrentItem2['등급']%` · Lab 5 `%DataFromWebPage%` · Lab 6 `%공고[4]%` · Lab 7 `%요청['수량']%`

## 자료형은 값이 정합니다

변수를 만들 때 형식을 고르는 칸은 없습니다. Power Automate 가 들어온 값을 보고 형식을 정합니다.[^types]

| 분류 | 자료형 | 담는 것 |
|---|---|---|
| 단순 | 텍스트 값 | 글자 |
| 단순 | 숫자 값 | 수. 수학 연산은 이 형식으로만 됨 |
| 단순 | 부울 값 | True · False |
| 고급 | 목록 | 항목의 나열. 1차원 배열 |
| 고급 | 데이터 테이블 | 행과 열이 있는 표. 2차원 배열 |
| 고급 | 데이터 행 | 데이터 테이블의 한 행 |
| 고급 | 사용자 지정 개체 | 속성과 값의 쌍. JSON으로 변환 가능 |
| 인스턴스 | 웹 브라우저 · 창 · Excel · Outlook 인스턴스 | 열려 있는 대상의 참조 |
| 연결 | SQL · Exchange · FTP 연결 | 열어 둔 연결 |
| 기타 | 날짜/시간 | 날짜와 시각 |
| 기타 | 파일 · 폴더 | 경로와 속성 |
| 기타 | 일반 값 | 설계할 때 형식을 정할 수 없는 값. 실행할 때 정해짐 |
| 기타 | SensitiveValue | 민감으로 지정된 텍스트 |
| 기타 | 오류 | 마지막 오류의 정보 |

## 만드는 방법

| 자료형 | 변수 설정의 값 칸 | 값을 내놓는 작업 |
|---|---|---|
| 텍스트 값 | 표기 없이 글자를 입력 | 입력 대화 표시 |
| 숫자 값 | 표기 없이 수를 입력 | 텍스트를 숫자로 변환 |
| 부울 값 | `%True%` · `%False%` | 비교 식 |
| 목록 | — | 새 목록 만들기 · 폴더의 파일 가져오기 · 파일에서 텍스트 읽기 |
| 데이터 테이블 | `%{['A', '1'], ['B', '2']}%` | 새 데이터 테이블 만들기 · Excel 워크시트에서 읽기 · 웹 페이지에서 데이터 추출 · SQL 문 실행 |
| 데이터 행 | — | 데이터 테이블을 도는 For each 의 현재 항목 |
| 사용자 지정 개체 | `%{ '속성': '값' }%` | — |
| 날짜/시간 | `%d"2026-03-25"%` | 현재 날짜 및 시간 가져오기 |

데이터 테이블에 열 이름을 달려면 첫 줄을 `^['열1', '열2']` 로 시작합니다.[^types]

## 샘플

흐름 하나를 만들어 자료형마다 변수를 만들고 변수 창에서 값을 확인합니다.

1. Power Automate 콘솔 왼쪽 막대의 **흐름**을 누르고 **새 흐름**을 누릅니다.
2. **흐름 이름**에 아래를 입력합니다. `HGD` 대신 본인 이니셜을 넣습니다. **Power Fx 사용**은 끈 채로 두고 **만들기**를 누릅니다.

    ```
    개념 연습_HGD
    ```

3. 작업 검색 칸에 `변수 설정` 을 입력하고 **변수 설정**을 작업 영역으로 끌어다 놓습니다. **변수** 칸과 **값** 칸에 아래를 차례로 넣고 **저장**을 누릅니다.

    ```
    공고명
    ```

    ```
    교육 위탁 운영
    ```

4. **변수 설정**을 하나 더 놓고 아래를 넣습니다. 수를 표기 없이 넣으면 숫자 값이 됩니다.

    ```
    건수
    ```

    ```
    16
    ```

5. **변수 설정**을 하나 더 놓고 아래를 넣습니다.

    ```
    진행중
    ```

    ```
    %True%
    ```

6. 작업 검색 칸에 `새 목록` 을 입력하고 **새 목록 만들기**를 놓고 **저장**을 누릅니다. 결과는 **변수 생성됨**의 `List` 에 담깁니다.
7. 작업 검색 칸에 `목록에 항목` 을 입력하고 **목록에 항목 추가**를 놓습니다. **항목 추가**에 아래를 넣고 **저장**을 누릅니다. 같은 작업을 하나 더 놓아 `교육` 을 넣습니다.

    ```
    용역
    ```

8. **변수 설정**을 하나 더 놓고 아래를 넣습니다. 첫 줄이 열 이름입니다.

    ```
    공고표
    ```

    ```
    %{^['공고번호', '추정가격'], ['A-1', '1000'], ['A-2', '2000']}%
    ```

9. **변수 설정**을 하나 더 놓고 아래를 넣습니다.

    ```
    요청
    ```

    ```
    %{ '거래처': 'V1003', '자재': 'M-1001' }%
    ```

10. **변수 설정**을 하나 더 놓고 아래를 넣습니다.

    ```
    기준일
    ```

    ```
    %d"2026-03-25"%
    ```

11. 도구 모음의 **실행**(▶)을 누릅니다.
12. 오른쪽 세로 막대의 **{x}** 를 눌러 변수 창을 엽니다. 변수마다 두 번 클릭해 값을 봅니다.

    **완료 기준**: `공고표` 는 행과 열이 있는 표로, `List` 는 항목 두 개로, `요청` 은 속성과 값의 쌍으로 보인다.

---

## 데이터 행은 반복 안에서 생깁니다

데이터 테이블을 **각각의 경우**로 돌면 현재 항목 변수에 데이터 행이 담깁니다.[^types] 값은 `%CurrentItem['열 이름']%` 또는 `%CurrentItem[번호]%` 로 읽습니다. 읽는 표기는 [P4](p04-index.html)에서 다룹니다.
