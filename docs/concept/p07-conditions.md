## If 의 구조

If 는 조건이 참일 때만 If 와 End 사이의 작업을 실행합니다. 거짓이면 그 작업들을 건너뜁니다.[^use] 조건은 피연산자 둘과 연산자 하나로 이뤄집니다.

| 칸 | 넣는 것 |
|---|---|
| 첫 번째 피연산자 | 변수 · 텍스트 · 숫자 · 식 |
| 연산자 | 아래 표에서 선택. 기본값 같음 (=) |
| 두 번째 피연산자 | 변수 · 텍스트 · 숫자 · 식 |

---

## 연산자

| 화면 표기 | 영문 | 참이 되는 경우 |
|---|---|---|
| 같음 (=) | Equal to | 두 값이 같음 |
| 같지 않음 (`<>`) | Not equal to | 두 값이 다름 |
| 보다 큼 (>) | Greater than | 첫 값이 큼 |
| 크거나 같음 (>=) | Greater than or equal to | 첫 값이 크거나 같음 |
| 보다 작음 (`<`) | Less than | 첫 값이 작음 |
| 보다 작거나 같음 (`<=`) | Less than or equal to | 첫 값이 작거나 같음 |
| 포함 | Contains | 첫 값이 둘째 값을 포함 |
| 포함하지 않음 | Does not contain | 첫 값이 둘째 값을 포함하지 않음 |
| 비어 있음 | Is empty | 비어 있음 |
| 비어 있지 않음 | Is not empty | 비어 있지 않음 |
| 사용하여 시작 | Starts with | 첫 값이 둘째 값으로 시작 |
| 사용하여 시작하지 않음 | Does not start with | 첫 값이 둘째 값으로 시작하지 않음 |
| 사용하여 종료 | Ends with | 첫 값이 둘째 값으로 끝남 |
| 사용하여 종료하지 않음 | Does not end with | 첫 값이 둘째 값으로 끝나지 않음 |
| 공백임 | Is blank | 변수의 값이 Blank |
| 공백이 아님 | Is not blank | 변수의 값이 Blank 가 아님 |

Blank 와 글자가 없는 텍스트의 구분은 [P3](p03-percent.html)에서 다룹니다.[^vars]

## 자료형을 맞춥니다

피연산자는 같은 자료형이어야 합니다. 자료형이 다른 변수를 비교하면 조건은 항상 거짓입니다.[^use]

| 첫 번째 | 두 번째 | 결과 |
|---|---|---|
| 숫자 `50000000` | 숫자 `50000000` | 비교됨 |
| 숫자 10 | 텍스트 `%'10'%` | 항상 거짓 |
| `%공고[4]%` 의 `120,000,000` | 숫자 | 텍스트이므로 숫자로 변환해 비교 |

웹에서 읽은 금액을 숫자로 바꾸는 순서는 [P17](p17-convert.html)에서 다룹니다.

## Else if 와 Else

| 작업 | 실행되는 경우 | 놓는 곳 |
|---|---|---|
| If | 자기 조건이 참 | 블록의 처음 |
| Else if | 앞의 If 와 Else if 가 모두 거짓이고 자기 조건이 참 | If 와 End 사이, Else 앞 |
| Else | 앞의 조건이 모두 거짓 | If 와 End 사이, Else if 뒤 |
| End | — | 블록의 끝 |

Else if 와 Else 는 선택입니다.[^use] 작업 영역에서 Else 는 **Else 그 밖의 경우**로 보입니다.

## 여러 조건을 묶는 방법

| 방법 | 설정 | 특징 |
|---|---|---|
| If 를 겹침 | If 블록 안에 If 를 놓음 | 안쪽 작업은 두 조건이 모두 참일 때만 실행. 두 If 사이에 다른 작업을 둘 수 있음. 확인이 많아지면 흐름이 복잡해짐 |
| 논리식 하나 | 첫 번째 피연산자에 식, 연산자 같음 (=), 두 번째 피연산자에 `%True%` | 줄이 줄어듦. 거짓을 확인하려면 두 번째를 `%False%` 로 둠 |

논리식은 `%` 로 감쌉니다.[^logical] 괄호로 순서를 바꿀 수 있습니다.

```
%A = 10 AND B = 5%
```

```
%(A = 10 OR A = 20) AND B = 5%
```

연산자와 함수는 [P3](p03-percent.html)에 있습니다.

## 상태를 확인하는 If 변형

값을 비교하지 않고 대상의 상태를 확인하는 작업입니다.[^use] 구조는 If 와 같습니다.

| 영문 | 한국어판 문서 표기 | 확인하는 것 |
|---|---|---|
| If file exists | 파일 존재 여부 | 파일이 있는지 |
| If folder exists | 폴더가 있는 경우 | 폴더가 있는지 |
| If service | 서비스 여부 | 서비스가 실행 · 일시 중지 · 중지 상태인지 |
| If process | 프로세스 여부 | Windows 프로세스가 실행 중인지 |
| If window | 창 여부 | 창이 열려 있는지 |
| If window contains | 창에 포함 여부 | 창에 텍스트나 UI 요소가 있는지 |
| If image | 이미지 여부 | 화면에 이미지가 있는지 |
| If web page contains | 웹 페이지가 다음을 포함하는 경우 | 웹 페이지에 요소나 텍스트가 있는지 |
| If text on screen (OCR) | 화면의 텍스트(OCR) | OCR 엔진으로 화면에서 텍스트를 찾았는지 |

## Switch

값 하나를 여러 값과 비교해 실행 경로를 가릅니다.[^use] 모든 종류의 조건에는 If 를, 변수 하나를 여러 값과 비교할 때는 Switch 를 씁니다.[^ref]

| 작업 | 칸 | 뜻 |
|---|---|---|
| Switch | 확인할 값 | 블록의 시작. 비교할 변수 · 텍스트 · 숫자 |
| Case | 연산자 · 비교할 값 | 조건이 참이면 이 아래 작업을 실행. 연산자는 If 와 같은 16종 |
| Default case | — | 모든 Case 가 거짓일 때 실행. 선택 |
| End | — | 블록의 끝 |

## 샘플

같은 분기를 If 와 Switch 로 만들고, 논리식과 자료형 조건을 확인합니다. 작업은 작업 검색 칸에 이름을 입력해 찾습니다. 흐름 `개념 연습_HGD` 를 씁니다. 없으면 [P2](p02-types.html)의 1·2번으로 만듭니다.

1. 콘솔 흐름 목록에서 `개념 연습_HGD` 의 **편집**을 누릅니다. 디자이너가 이미 열려 있으면 그 창을 씁니다.
2. **Main** 탭의 빈 곳을 한 번 누르고 `Ctrl` + `A` 로 전체를 고른 뒤 `Delete` 키를 누릅니다.
3. 작업 검색 칸에 `입력 대화` 를 입력하고 **입력 대화 표시**를 작업 영역으로 끌어다 놓습니다. **입력 대화 제목**과 **입력 대화 메시지**에 아래를 차례로 넣고 **저장**을 누릅니다. 입력한 글자는 `UserInput` 에 담깁니다.

    ```
    등급 확인
    ```

    ```
    등급을 입력하세요. (A, B, C)
    ```

4. 작업 검색 칸에 `if` 를 입력하고 **조건** 아래 **If**를 맨 아래로 끌어다 놓습니다. **첫 번째 피연산자**와 **두 번째 피연산자**에 아래를 차례로 넣고 **저장**을 누릅니다. **연산자**는 **같음 (=)** 그대로 둡니다.

    ```
    %UserInput%
    ```

    ```
    A
    ```

5. **메시지 표시**를 **If** 와 **End** 사이로 끌어다 놓습니다. **표시할 메시지**에 아래를 넣고 **저장**을 누릅니다.

    ```
    If: 우수 등급
    ```

6. 작업 검색 칸에 `else` 를 입력하고 **조건** 아래 **Else if**를 5번의 메시지 표시 아래, **End** 위로 끌어다 놓습니다. **첫 번째 피연산자**와 **두 번째 피연산자**에 아래를 차례로 넣고 **저장**을 누릅니다.

    ```
    %UserInput%
    ```

    ```
    B
    ```

7. **메시지 표시**를 **Else if** 와 **End** 사이로 끌어다 놓습니다. **표시할 메시지**에 아래를 넣고 **저장**을 누릅니다.

    ```
    Else if: 보통 등급
    ```

8. **조건** 아래 **Else**를 7번의 메시지 표시 아래, **End** 위로 끌어다 놓습니다.
9. **메시지 표시**를 **Else** 와 **End** 사이로 끌어다 놓습니다. **표시할 메시지**에 아래를 넣고 **저장**을 누릅니다.

    ```
    Else: 확인 필요
    ```

10. **실행**(▶)을 누르고 입력 창에 `A` 를 넣습니다.

    **완료 기준**: `If: 우수 등급` 이 뜬다.

11. 다시 **실행**하고 입력 창에 `B` 를 넣습니다.

    **완료 기준**: `Else if: 보통 등급` 이 뜬다.

12. 다시 **실행**하고 입력 창에 `C` 를 넣습니다.

    **완료 기준**: `Else: 확인 필요` 가 뜬다.

13. 작업 검색 칸에 `조건` 을 입력합니다. **조건** 묶음의 **Switch**를 맨 아래로 끌어다 놓습니다. **확인할 값**에 아래를 넣고 **저장**을 누릅니다.

    ```
    %UserInput%
    ```

14. **조건** 묶음의 **Case**를 **Switch** 와 **End** 사이로 끌어다 놓습니다. **비교할 값**에 아래를 넣고 **저장**을 누릅니다.

    ```
    A
    ```

15. **메시지 표시**를 14번의 **Case** 아래로 끌어다 놓습니다. **표시할 메시지**에 아래를 넣고 **저장**을 누릅니다.

    ```
    Case: 우수 등급
    ```

16. **Case**를 15번의 메시지 표시 아래로 끌어다 놓습니다. **비교할 값**에 아래를 넣고 **저장**을 누릅니다.

    ```
    B
    ```

17. **메시지 표시**를 16번의 **Case** 아래로 끌어다 놓습니다. **표시할 메시지**에 아래를 넣고 **저장**을 누릅니다.

    ```
    Case: 보통 등급
    ```

18. **Default case**를 17번의 메시지 표시 아래, **End** 위로 끌어다 놓습니다.
19. **메시지 표시**를 **Default case** 와 **End** 사이로 끌어다 놓습니다. **표시할 메시지**에 아래를 넣고 **저장**을 누릅니다.

    ```
    Default: 확인 필요
    ```

20. **실행**을 누르고 입력 창에 `B` 를 넣습니다.

    **완료 기준**: `Else if: 보통 등급` 다음에 `Case: 보통 등급` 이 뜬다.

21. 다시 **실행**하고 입력 창에 `Z` 를 넣습니다.

    **완료 기준**: `Else: 확인 필요` 다음에 `Default: 확인 필요` 가 뜬다.

22. **If**를 맨 아래로 끌어다 놓습니다. **첫 번째 피연산자**와 **두 번째 피연산자**에 아래를 차례로 넣고 **저장**을 누릅니다. **연산자**는 **같음 (=)** 그대로 둡니다.

    ```
    %UserInput = 'A' OR UserInput = 'B'%
    ```

    ```
    %True%
    ```

23. **메시지 표시**를 22번의 **If** 와 **End** 사이로 끌어다 놓습니다. **표시할 메시지**에 아래를 넣고 **저장**을 누릅니다.

    ```
    논리식: A 또는 B
    ```

24. **실행**을 누르고 입력 창에 `A` 를 넣습니다.

    **완료 기준**: 마지막에 `논리식: A 또는 B` 가 뜬다.

25. 다시 **실행**하고 입력 창에 `C` 를 넣습니다.

    **완료 기준**: `논리식: A 또는 B` 가 뜨지 않는다.

26. **변수 설정**을 맨 아래로 끌어다 놓습니다. **변수** 칸과 **값** 칸에 아래를 차례로 넣고 **저장**을 누릅니다.

    ```
    숫자값
    ```

    ```
    10
    ```

27. **변수 설정**을 하나 더 놓고 아래를 넣습니다. 따옴표로 감싸 텍스트로 만듭니다.

    ```
    글자값
    ```

    ```
    %'10'%
    ```

28. **If**를 맨 아래로 끌어다 놓습니다. **첫 번째 피연산자**와 **두 번째 피연산자**에 아래를 차례로 넣고 **저장**을 누릅니다.

    ```
    %숫자값%
    ```

    ```
    %글자값%
    ```

29. **메시지 표시**를 28번의 **If** 와 **End** 사이로 끌어다 놓습니다. **표시할 메시지**에 아래를 넣고 **저장**을 누릅니다.

    ```
    자료형 비교: 같음
    ```

30. **Else**를 29번의 메시지 표시 아래, **End** 위로 끌어다 놓습니다. **메시지 표시**를 **Else** 와 **End** 사이로 끌어다 놓습니다. **표시할 메시지**에 아래를 넣고 **저장**을 누릅니다.

    ```
    자료형 비교: 다름
    ```

31. **실행**을 누르고 입력 창에 `A` 를 넣습니다.

    **완료 기준**: 마지막에 `자료형 비교: 다름` 이 뜬다.
