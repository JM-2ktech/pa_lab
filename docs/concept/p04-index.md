# P4. 인덱스와 슬라이싱

> **다루는 것**: 목록 · 데이터 테이블 · 데이터 행에서 값 하나나 일부를 읽는 표기
>
> **쓰는 곳**: Lab 4 `%CurrentItem2['등급']%` · Lab 6 `%공고[4]%` · `%공고[7]%` · `%키워드행['키워드']%` · Lab 7 `%요청['수량']%`

---

## 번호는 0부터 셉니다

목록의 첫 항목, 데이터 테이블의 첫 행과 첫 열은 번호가 0 입니다.[^types] 변수 값 창의 행 번호(#)도 0 부터 나옵니다.

| 번호 | 0 | 1 | 2 | 3 |
|---|---:|---:|---:|---:|
| 위치 | 첫째 | 둘째 | 셋째 | 넷째 |

---

## 표기 모음

| 자료형 | 표기 | 읽는 값 |
|---|---|---|
| 목록 | `%목록[0]%` | 첫 항목 |
| 목록 | `%목록[2:4]%` | 셋째 · 넷째 항목 |
| 목록 | `%목록[:4]%` | 처음부터 넷째 항목까지 |
| 목록 | `%목록[2:]%` | 셋째 항목부터 끝까지 |
| 데이터 테이블 | `%표[0][1]%` | 첫 행의 둘째 열 |
| 데이터 테이블 | `%표[0]['추정가격']%` | 첫 행의 `추정가격` 열. 머리글이 있는 표에 사용 |
| 데이터 테이블 | `%표[0]%` | 첫 행 |
| 데이터 테이블 | `%표[2:4]%` | 셋째 · 넷째 행 |
| 데이터 테이블 | `%표[:4]%` | 첫 행부터 넷째 행까지 |
| 데이터 테이블 | `%표[2:]%` | 셋째 행부터 끝까지 |
| 데이터 행 | `%행[4]%` | 다섯째 열 |
| 데이터 행 | `%행['수량']%` | `수량` 열 |

---

## 슬라이싱

슬라이싱은 목록이나 표의 일부를 읽습니다. 표기는 `[시작번호:끝번호]` 입니다.[^types]

| 표기 | 시작 | 끝 |
|---|---|---|
| `[2:4]` | 번호 2 | 번호 3. 끝번호 4 의 항목은 결과에 들지 않음 |
| `[:4]` | 처음 | 번호 3 |
| `[2:]` | 번호 2 | 마지막 |

데이터 테이블에 쓰면 행 단위로 읽습니다. 열 일부를 읽는 표기는 문서에 없습니다.

---

## 데이터 테이블과 데이터 행

데이터 테이블은 데이터 행을 항목으로 가진 목록으로 볼 수 있습니다.[^types] 데이터 테이블을 **각각의 경우**로 돌면 현재 항목 변수에 데이터 행이 담기므로 행 번호 없이 열만 지정합니다.

| 변수 | 자료형 | 칸 하나를 읽는 표기 |
|---|---|---|
| `DataFromWebPage` | 데이터 테이블 | `%DataFromWebPage[0][4]%` |
| `공고` | 데이터 행 | `%공고[4]%` |

---

## 열 번호와 열 이름

| 방식 | 예 | 조건 |
|---|---|---|
| 열 번호 | `%공고[4]%` | 머리글이 없어도 됨. 열 순서가 바뀌면 다른 값을 읽음 |
| 열 이름 | `%요청['수량']%` | 표에 머리글이 있어야 함. 이름은 원본 데이터 테이블이 정함 |

표에 머리글이 들어가는 경로는 셋입니다.

| 만드는 작업 | 설정 |
|---|---|
| Excel 워크시트에서 읽기 | 고급 › 범위의 첫 번째 행을 열 이름으로 사용 켬 |
| 변수 설정 | 표의 첫 줄을 `^['열1', '열2']` 로 시작 |
| 웹 페이지에서 데이터 추출 | 전체 HTML 테이블 추출. 머리글이 열 이름이 됨 |

---

## 모의 공고 사이트 표의 번호

**웹 페이지에서 데이터 추출**로 읽은 표를 `공고` 라는 현재 항목으로 돌 때의 표기입니다.

| 번호 | 열 | 표기 |
|---:|---|---|
| 0 | 공고번호 | `%공고[0]%` |
| 1 | 공고명 | `%공고[1]%` |
| 2 | 수요기관 | `%공고[2]%` |
| 3 | 분류 | `%공고[3]%` |
| 4 | 추정가격(원) | `%공고[4]%` |
| 5 | 공고일 | `%공고[5]%` |
| 6 | 마감일 | `%공고[6]%` |
| 7 | 상태 | `%공고[7]%` |

---

## 발주 요청 표의 열 이름

`발주요청.xlsx` 를 첫 행을 열 이름으로 읽어 `요청` 이라는 현재 항목으로 돌 때의 표기입니다.

| 번호 | 열 | 열 이름 표기 | 열 번호 표기 |
|---:|---|---|---|
| 0 | 거래처 | `%요청['거래처']%` | `%요청[0]%` |
| 1 | 자재 | `%요청['자재']%` | `%요청[1]%` |
| 2 | 수량 | `%요청['수량']%` | `%요청[2]%` |

---

## 흔한 실패

| 증상 | 원인 | 고치는 방법 |
|---|---|---|
| 한 칸 옆의 값이 나옴 | 번호를 1 부터 셈 | 0 부터 셈 |
| 슬라이스 결과가 하나 모자람 | 끝번호의 항목은 들지 않음 | 끝번호를 하나 늘림 |
| 열 이름을 찾지 못함 | 머리글 없이 읽음 · 이름이 머리글과 다름 | 첫 행을 열 이름으로 읽음 · 이름을 맞춤 |
| 실행 중 오류로 멈춤 | 목록의 범위를 벗어난 번호 | 번호를 고침. 오류 처리는 [P18](p18-errors.html) |
| 여러 줄이 든 칸이 첫 줄만 보임 | 변수 값 창의 알려진 제한 | 문서에 해결 방법 없음 |

범위를 벗어난 번호는 문서에서 예기치 않은 논리 오류의 예로 듭니다.[^errors]

## 샘플

작업은 작업 검색 칸에 이름을 입력해 찾습니다. 흐름 `개념 연습_HGD` 를 씁니다. 없으면 [P2](p02-types.html)의 1·2번으로 만듭니다.

1. 콘솔 흐름 목록에서 `개념 연습_HGD` 의 **편집**을 누릅니다. 디자이너가 이미 열려 있으면 그 창을 씁니다.
2. **Main** 탭의 빈 곳을 한 번 누르고 `Ctrl` + `A` 로 전체를 고른 뒤 `Delete` 키를 누릅니다.
3. 작업 검색 칸에 `새 목록` 을 입력하고 **새 목록 만들기**를 작업 영역으로 끌어다 놓고 **저장**을 누릅니다. 결과는 **변수 생성됨**의 `List` 에 담깁니다.
4. 작업 검색 칸에 `목록에 항목` 을 입력하고 **목록에 항목 추가**를 놓습니다. **항목 추가**에 아래를 넣고, **목록으로**가 `%List%` 인지 확인하고 **저장**을 누릅니다.

    ```
    용역
    ```

5. **목록에 항목 추가**를 하나 더 놓아 아래를 넣습니다.

    ```
    물품
    ```

6. **목록에 항목 추가**를 하나 더 놓아 아래를 넣습니다.

    ```
    공사
    ```

7. **목록에 항목 추가**를 하나 더 놓아 아래를 넣습니다.

    ```
    교육
    ```

8. 작업 검색 칸에 `변수 설정` 을 입력하고 **변수 설정**을 맨 아래로 끌어다 놓습니다. **변수** 칸과 **값** 칸에 아래를 차례로 넣고 **저장**을 누릅니다.

    ```
    첫항목
    ```

    ```
    %List[0]%
    ```

9. **변수 설정**을 하나 더 놓고 아래를 넣습니다.

    ```
    가운데
    ```

    ```
    %List[1:3]%
    ```

10. **변수 설정**을 하나 더 놓고 아래를 넣습니다.

    ```
    앞부분
    ```

    ```
    %List[:2]%
    ```

11. **변수 설정**을 하나 더 놓고 아래를 넣습니다.

    ```
    뒷부분
    ```

    ```
    %List[2:]%
    ```

12. **변수 설정**을 하나 더 놓고 아래를 넣습니다. 첫 줄이 열 이름입니다.

    ```
    공고표
    ```

    ```
    %{^['공고번호', '공고명', '추정가격'], ['A-1', '교육 위탁', '1000'], ['A-2', '클라우드 구축', '2000'], ['A-3', '자동화 컨설팅', '3000']}%
    ```

13. **변수 설정**을 하나 더 놓고 아래를 넣습니다.

    ```
    번호로읽기
    ```

    ```
    %공고표[0][1]%
    ```

14. **변수 설정**을 하나 더 놓고 아래를 넣습니다.

    ```
    이름으로읽기
    ```

    ```
    %공고표[1]['추정가격']%
    ```

15. **변수 설정**을 하나 더 놓고 아래를 넣습니다.

    ```
    행둘
    ```

    ```
    %공고표[1:3]%
    ```

16. 작업 검색 칸에 `각각의` 를 입력하고 **각각의 경우**를 맨 아래로 끌어다 놓습니다. **반복할 값**과 **저장 위치**에 아래를 차례로 넣고 **저장**을 누릅니다.

    ```
    %공고표%
    ```

    ```
    공고
    ```

17. **변수 설정**을 **각각의 경우**와 **End** 사이로 끌어다 놓고 아래를 넣습니다. 현재 항목이 데이터 행이어서 행 번호를 적지 않습니다.

    ```
    마지막공고명
    ```

    ```
    %공고[1]%
    ```

18. **변수 설정**을 하나 더 **End** 위로 끌어다 놓고 아래를 넣습니다.

    ```
    마지막금액
    ```

    ```
    %공고['추정가격']%
    ```

19. 도구 모음의 **실행**(▶)을 누릅니다. 오른쪽 세로 막대의 **{x}** 를 눌러 변수 창을 엽니다. 목록과 표 변수는 두 번 클릭한 뒤 **변수 값** 오른쪽 **보기**로 엽니다.

    **완료 기준**: `첫항목` 용역 · `가운데` 물품, 공사 · `앞부분` 용역, 물품 · `뒷부분` 공사, 교육 · `번호로읽기` 교육 위탁 · `이름으로읽기` 2000 · `행둘` A-2, A-3 두 행 · `마지막공고명` 자동화 컨설팅 · `마지막금액` 3000 이 보인다.

20. **변수 설정**을 맨 아래로 끌어다 놓고 아래를 넣습니다. `List` 의 항목은 4개이고 번호는 3 까지 있습니다.

    ```
    범위밖
    ```

    ```
    %List[9]%
    ```

21. **실행**을 누릅니다.

    **완료 기준**: 마지막 줄에서 실행이 멈추고 오류 창에 그 줄 번호가 보인다.
