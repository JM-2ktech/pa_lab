## 변수 작업의 종류

변수를 다루는 작업은 여섯 가지입니다.[^variables]

| 작업 | 영문 이름 | 하는 일 | 대상 유형 | 필수 칸 |
|---|---|---|---|---|
| 변수 초기화 | Initialize variable | 이름 · 유형 · 초기값을 정함 | 전체 | 이름 · 유형 |
| 변수 설정 | Set variable | 다른 값을 넣음. 새 값은 변수와 같은 유형 | 전체 | 이름 · 값 |
| 변수 증가 | Increment variable | 값을 더함. 기본 1 | 정수 · 부동 소수점 | 이름 |
| 변수 감소 | Decrement variable | 값을 뺌. 기본 1 | 정수 · 부동 소수점 | 이름 |
| 문자열 변수에 추가 | Append to string variable | 끝에 글자를 붙임 | 문자열 | 이름 · 값 |
| 배열 변수에 추가 | Append to array variable | 마지막 항목으로 더함. 값은 어떤 유형이든 가능 | 배열 | 이름 · 값 |

---

## 변수 유형과 초기값

변수를 만들 때 유형을 정합니다.[^variables]

| 유형 | 초기값 예 |
|---|---|
| 문자열 | `lorem ipsum` |
| 정수 | `0` |
| 부동 소수점 | `3.14` |
| 부울 | `false` |
| 배열 | `[1, 2, 3]` · `["red", "orange", "yellow"]` |
| 개체 | `{"결과":"이상"}` |

자료형 자체는 [C7](c07-types.html)에서 다룹니다.

---

## 변수 초기화의 조건

| 조건 | 내용 |
|---|---|
| 놓는 곳 | 전역 수준만. 범위 · 조건 · 반복 안에 둘 수 없음 |
| 작업 하나당 | 변수 하나 |
| 값 칸 | 비워도 되지만 시작값을 정해 두도록 문서가 권함 |
| 한 흐름의 변수 수 | 250개까지 |
| 쓰는 범위 | 만든 흐름 안에서만. 반복 사이에 값이 유지됨 |
| 흐름 시작 조건 | 트리거가 먼저 있어야 함 |
| 모바일 | 모바일 장치에서는 변수를 추가할 수 없음 |

바꾸는 작업(설정 · 증가 · 감소 · 추가)은 범위 · 조건 · 반복 안에 둘 수 있습니다. 초기화만 바깥에 두고, 안에서 값을 바꿉니다.[^variables][^limits]

---

## 변수를 읽는 표기

변수는 변수 이름으로 읽습니다. 작업의 출력은 카드 이름으로 읽습니다. 변수는 동적 콘텐츠 창의 변수 묶음에서 고르거나 식으로 적습니다.[^variables]

| 식 | 값 |
|---|---|
| `variables('합계')` | 변수 `합계` 의 값 |
| `string(variables('순서'))` | 배열 변수를 문자열로 바꾼 값 |
| `length(variables('순서'))` | 배열 변수의 항목 수 |
| `outputs('작성')` | 작성 카드의 출력. 카드 이름으로 읽음 |

---

## 작성과 변수 중에서 고르기

작성(Compose)은 입력 칸의 값을 그대로 출력으로 내는 데이터 작업입니다. 값이 바뀌는지가 첫 기준입니다.[^data-guide]

| 기준 | 작성 | 변수 |
|---|---|---|
| 값 | 한 번 정해지면 고정 | 실행 중에 여러 번 바꿈 |
| 준비 | 필요 없음 | 변수 초기화가 먼저 필요 |
| 놓는 곳 | 범위 · 조건 · 반복 안에도 가능 | 초기화는 전역 수준만 |
| 읽는 식 | `outputs('카드 이름')` | `variables('변수 이름')` |
| 작업 수 | 카드 하나 | 초기화 하나 + 바꾸는 작업마다 하나 |
| 실행 기록 | 카드를 눌러 입력과 출력을 봄 | 바꾸는 카드마다 봄 |

쓰는 경우별 선택입니다.[^data-guide][^troubleshoot]

| 쓰는 경우 | 고를 작업 |
|---|---|
| 긴 식을 나눠 적기 | 작성 |
| 바뀌지 않는 값을 여러 번 읽기 | 작성 |
| 나중에 고치지 않는 중간 계산 | 작성 |
| 실행 기록에서 값 확인하기 | 작성 |
| 반복 횟수 세기 · 합계 내기 | 변수 |
| 반복마다 결과를 모으기 | 배열 변수 |
| 조건 가지에 따라 값을 바꾸고 뒤에서 읽기 | 변수 |
| 출력이 큰 작업에서 속성 하나만 여러 번 쓰기 | 변수 |

작업의 출력에서 속성 하나만 읽어도 출력 전체가 뒤 작업의 입력으로 넘어갑니다. 큰 출력의 속성 하나를 여러 번 쓸 때는 변수에 담습니다.[^faq]

---

## 개체 변수 하나로 묶기

같은 곳에서 함께 바뀌는 값은 개체 변수 하나에 담으면 작업 수가 줄어듭니다.[^data-guide]

| 구성 | 필요한 작업 |
|---|---|
| 변수 두 개 | 변수 초기화 2개 + 변수 설정 2개 |
| 개체 변수 하나 | 변수 초기화 1개 + 변수 설정 1개 |

---

## 반복과 함께 쓸 때

각각에 적용을 동시 실행으로 돌리면 변수 값을 예측할 수 없을 수 있습니다. 변수를 쓰는 반복은 순차로 둡니다.[^variables] 상세는 [C18](c18-loops.html)에서 다룹니다.

## 흔한 실패

변수와 작성에서 나오는 오류와 고치는 곳입니다.[^variables][^errref]

| 증상 | 원인 | 고치는 곳 |
|---|---|---|
| 조건이나 반복 안에 변수 초기화를 놓을 수 없음 | 전역 수준에서만 가능 | 트리거 가까운 최상위로 옮김 |
| 변수 설정에서 유형 오류 | 새 값과 변수의 유형이 다름 | 변환 함수 `int()` · `string()` |
| 변수 증가 · 변수 감소가 되지 않음 | 변수 유형이 정수 · 부동 소수점이 아님 | 변수 초기화의 유형 |
| 실행 결과가 매번 다름 | 동시 실행 반복 안의 변수 | 순차 실행 |
| `outputs('...')` 가 저장되지 않음 | 카드 이름 오타나 공백 | 공백은 `_`. [C9](c09-references.html) |

## 샘플

흐름 `식 연습장_HGD` 를 씁니다. 없으면 [C7](c07-types.html)의 샘플로 만듭니다.

1. [Power Automate — {{ site.pa.environment }}]({{ site.pa.powerautomate_url }}){:target="_blank"}를 엽니다. 왼쪽 메뉴 **내 흐름**에서 `식 연습장_HGD` 를 열고 **편집**을 누릅니다.
2. 트리거와 **작성** 카드 사이의 화살표에 포인터를 올려 **+** › **작업 추가**를 고릅니다. 검색란에 `변수 초기화` 를 입력하고 **변수 초기화**를 고릅니다.
3. **이름** 칸에 아래를 넣고, **유형**에서 **문자열**을 고릅니다. **값** 칸에 그 아래를 넣습니다.

    ```
    상태
    ```

    ```
    접수
    ```

4. 그 아래 **+** › **작업 추가**에서 `변수 설정` 을 검색해 **변수 설정**을 고릅니다. **이름**에서 `상태` 를 고릅니다. **값** 칸에 아래를 넣습니다.

    ```
    처리중
    ```

5. 그 아래 **+** › **작업 추가**에서 `문자열 변수` 를 검색해 **문자열 변수에 추가**를 고릅니다. **이름**에서 `상태` 를 고릅니다. **값** 칸에 아래를 넣습니다. 앞에 공백이 있습니다.

    ```
     완료
    ```

6. 맨 아래 **작성** 카드를 누릅니다. **입력** 칸을 비우고 ***fx*** 를 누른 뒤 아래 식을 붙여넣고 **추가**를 누릅니다.

    ```
    variables('상태')
    ```

7. **저장**을 누르고 **테스트** › **수동** › **테스트**를 누릅니다. **흐름 실행**을 누르고 **완료**를 누릅니다.
8. 실행 화면에서 **작성** 카드를 누릅니다.

    **완료 기준**: 출력이 `처리중 완료` 다.

9. 실행 화면에서 **변수 설정** 카드를 누릅니다.

    **완료 기준**: 이 카드 시점의 값 `처리중` 이 보인다.

10. **편집**을 누릅니다. **작성** 카드 아래 **+** › **작업 추가**를 고릅니다. **기본 제공 도구**에서 **데이터 작업**을 누르고 **작성**을 고릅니다.
11. 새 카드의 **입력** 칸에서 ***fx*** 를 누르고 아래 식을 붙여넣은 뒤 **추가**를 누릅니다. 앞 작성 카드의 출력을 카드 이름으로 읽습니다.

    ```
    concat(outputs('작성'), ' 확인')
    ```

12. 7~8번을 되풀이하고 새 작성 카드를 누릅니다.

    **완료 기준**: 출력이 `처리중 완료 확인` 이다.

13. **편집**을 누릅니다. 새 작성 카드를 누르고 구성 창의 **⋮**(추가 명령) › **삭제**를 고릅니다.
14. **작성** 카드의 **입력** 칸을 비우고 아래를 넣습니다.

    ```
    연습
    ```

15. **문자열 변수에 추가** · **변수 설정** · **변수 초기화**를 차례로 13번과 같은 방법으로 지웁니다. **저장**을 누릅니다.

    **완료 기준**: 트리거 아래에 **작성** 카드 하나만 남아 있다.
