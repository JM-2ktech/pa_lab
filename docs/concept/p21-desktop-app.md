## UI 자동화 작업의 전제

UI 자동화 작업은 UI 요소로 창과 구성 요소를 찾습니다. 이미지 인식이나 화면 좌표를 쓰지 않습니다.[^elements] 작업의 전제는 아래와 같습니다.[^desktop][^uia][^system]

| 항목 | 내용 |
|---|---|
| 받는 UI 요소 | 데스크톱 UI 요소만. 웹 페이지에서 잡아도 선택기는 데스크톱 요소 |
| 창의 상태 | 대상 창이 전경에 있어야 함. 없으면 자동으로 전경으로 가져옴 |
| 권한 | 앱과 같거나 높은 권한 필요. 관리자 권한으로 도는 앱에는 Power Automate 도 관리자 권한으로 실행 |
| 만드는 방법 | 작업을 직접 놓거나 기록기 사용 |
| UI 요소 잡기 | 작업의 **UI 요소 추가** 또는 UI 요소 창 → 대상을 강조 표시 → `Ctrl` + 왼쪽 클릭 |
| 앱 실행 | **응용 프로그램 실행**. 메모장처럼 일부 Windows 기본 앱은 이름만으로 실행 |

앱 창 안의 구성 요소를 잡으면 UI 요소가 둘 생깁니다. 부모 요소는 앱 창을 가리키고, 자식 요소는 창 안의 구성 요소를 가리킵니다.[^uia]

## UIA · MSAA · UIA3 Raw

데스크톱 UI 요소를 잡는 선택기는 세 종류입니다.[^elements]

| 종류 | 대상 앱 | 특징 | 쓰는 경우 |
|---|---|---|---|
| UIA(UI Automation) | WPF · WinForms · UWP 같은 최신 프레임워크 앱 | MSAA 를 대체한 최신 접근성 프레임워크. 요소 정보와 계층이 상세함 | 기본값. 가능하면 이것 |
| MSAA(Microsoft Active Accessibility) | VB6 · 클래식 Win32 같은 레거시 앱 | UIA 이전 기술. 정보와 구조가 적음 | 앱이 UIA 요소를 노출하지 않을 때 |
| UIA3 Raw | 사용자 지정 렌더링 컨트롤 · Electron 기반 앱 | 필터링하지 않은 원시 요소 트리. 중간 계층 · 비대화형 · 프레임워크 수준 요소까지 노출 | UIA 로 안정적으로 잡지 못할 때 |

UI 요소 선택 화면의 오른쪽 위 메뉴에서 캡처 모드를 바꿉니다. 기본값은 UIA 입니다. MSAA 나 UIA3 Raw 로 바꾸면 선택 화면에 안내 띠가 표시됩니다. UI 요소 창에는 요소마다 `UIA` 처럼 어느 종류로 잡았는지 표시됩니다.[^elements]

| 창의 확인란 상태 설정 | 확인란 선택 · 해제 |
| 창의 드롭다운 목록 값 설정 | 이름 · 순서로 항목 선택. 선택 지우기 |

|---|---|---|
| 텍스트 상자 | UI 요소 | — |

## 창 선택기

선택기는 `>` 로 포함 관계를 적습니다. 오른쪽 요소가 왼쪽 요소 안에 있습니다. 앱 창의 선택기는 늘 `:desktop` 으로 시작합니다.[^uia]

UI 요소 창에서 요소 오른쪽 ⋮ 를 눌러 **편집**을 고르면 선택기 화면이 열립니다. 창 요소의 특성은 아래와 같습니다.

| 특성 | 값의 예 |
|---|---|
| Class | 창 클래스 이름 |
| Enabled | `True` |
| Id | 앱이 정한 창 식별자 |
| Name | 창 제목 |
| Ordinal | `0` |
| Process | 프로세스 이름 |
| Visible | `True` |

체크한 특성만 찾는 조건이 됩니다. 조건은 **미리 보기 선택기**에서 확인합니다.

창 제목이 실행 중에 바뀌면 `Name` 조건으로는 창을 찾지 못합니다. 대응 방법은 셋입니다.[^uia]

| 방법 | 내용 |
|---|---|
| 특성 교체 | `Name` 체크를 풀고 `Id` · `Process` 처럼 바뀌지 않는 특성을 체크 |
| 연산자 변경 | **같음**을 다른 연산자나 정규식으로 변경 |
| 변수 | 값이 앞 작업의 결과로 정해지면 값 칸에 변수 사용 |

UI 요소 하나에 선택기를 여러 개 둘 수 있습니다. 앞의 선택기가 실패하면 정한 순서로 다음 선택기를 씁니다.[^elements] 자세한 표기는 [P12](p12-selectors.html)에서 다룹니다.

| UI 요소 창 조작 | 방법 |
|---|---|
| 정렬 | **정렬** |
| 쓰지 않는 요소 제거 | **정렬** 옆 점 아이콘 → **사용하지 않는 UI 요소 제거** |
| 이름 변경 · 삭제 | 요소를 마우스 오른쪽 단추로 누름 |
| 쓰는 작업 찾기 | 요소를 마우스 오른쪽 단추로 누름 → **사용법 찾기** |
| 글자로 선택기 만들기 | 잡는 화면에서 요소를 마우스 오른쪽 단추로 누름 → **텍스트에 따라 캡처**. 데스크톱은 `Name` 특성 사용 |

## 샘플

흐름 `개념 연습_HGD` 를 씁니다. 없으면 [P2](p02-types.html)의 1·2번으로 만듭니다. 대상 앱은 Windows 메모장입니다.

1. **Main** 탭의 빈 곳을 한 번 누르고 `Ctrl` + `A` 를 누른 뒤 `Delete` 를 눌러 줄을 지웁니다.
2. 작업 검색 칸에 `응용 프로그램` 을 입력하고 **시스템** 아래 **응용 프로그램 실행**을 작업 영역으로 끌어다 놓습니다. **응용 프로그램 경로**에 아래를 넣습니다. **응용 프로그램 시작 후**를 **응용 프로그램 로드 대기**로 바꾸고 **저장**을 누릅니다.

    ```
    notepad
    ```

3. 도구 모음의 **실행**(▶)을 누릅니다.

    **완료 기준**: 메모장 창이 열린다. 다음 스텝부터 이 창의 요소를 잡으므로 닫지 않고 둔다.

4. 작업 검색 칸에 `텍스트 필드` 를 입력하고 **UI 자동화** › **양식 채우기** 아래 **창에서 텍스트 필드 채우기**를 1번 줄 아래로 끌어다 놓습니다.
5. **텍스트 상자** 드롭다운을 열고 **UI 요소 추가**를 누릅니다. 메모장 본문에 빨간 테두리가 뜬 상태로 `Ctrl` + 왼쪽 클릭합니다.

    **완료 기준**: **텍스트 상자**에 `로컬 컴퓨터 > Window` 로 시작하는 요소가 들어간다.

6. **채울 텍스트**에 아래를 넣고 **저장**을 누릅니다.

    ```
    UI 자동화 연습
    ```

7. 작업 검색 칸에 `창의 세부` 를 입력하고 **창의 세부 정보 가져오기**를 2번 줄 아래로 끌어다 놓습니다. **창** 드롭다운에서 5번에서 함께 생긴 `Window` 요소를 고릅니다. **창 속성**은 **창 제목 가져오기** 그대로 두고 **저장**을 누릅니다. 결과는 `WindowProperty` 에 담깁니다.
8. 메모장을 저장하지 않고 닫은 뒤 **실행**합니다.

    **완료 기준**: 메모장 본문에 `UI 자동화 연습` 이 있고, 변수 창의 `WindowProperty` 에 메모장 창 제목이 있다.

9. 오른쪽 세로 막대의 **UI 요소** 단추를 눌러 UI 요소 창을 엽니다.

    **완료 기준**: `Window` 요소 아래에 본문 요소가 있고, 본문 요소 옆에 `UIA` 표시가 있다.

10. `Window` 요소 오른쪽 ⋮ 를 눌러 **편집**을 고릅니다.

    **완료 기준**: 특성 목록에서 `Name` 과 `Process` 가 체크되어 있고, **미리 보기 선택기**가 `:desktop > window` 로 시작한다.

11. **Name** 체크를 풀고 **저장**을 누릅니다.

    **완료 기준**: **미리 보기 선택기**에 `Name` 이 없다.

12. 메모장을 저장하지 않고 닫은 뒤 **실행**합니다.

    **완료 기준**: 8번과 같이 본문에 글자가 들어간다.

13. UI 요소 창 위쪽의 **+** 를 누릅니다. 선택 화면 오른쪽 위 메뉴에서 **MSAA** 를 고릅니다. 메모장 본문을 `Ctrl` + 왼쪽 클릭으로 잡고 **완료**를 누릅니다.

    **완료 기준**: 잡는 동안 선택 화면에 MSAA 안내 띠가 보이고, UI 요소 창의 새 요소 옆에 `MSAA` 표시가 있다.

14. 같은 방법으로 **UIA3 Raw** 를 골라 메모장 본문을 잡습니다. 메뉴를 **UIA** 로 되돌립니다.

    **완료 기준**: 같은 본문을 잡은 요소가 표시만 다른 세 줄로 UI 요소 창에 있다.

15. 메모장을 저장하지 않고 닫습니다.
