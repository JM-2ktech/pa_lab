## 화면 구성

디자이너는 클라우드 흐름을 만들고 시험하는 화면입니다.[^designer]

| 영역 | 위치 | 하는 일 |
|---|---|---|
| ←(뒤로) | 왼쪽 위 | 이전 페이지로 이동 |
| 흐름 이름 | 위쪽 | 이름을 눌러 고친 뒤 **저장** |
| 실행 취소 · 다시 실행 | 명령 모음 | 수정을 되돌리거나 복원 |
| 흐름 검사기 | 명령 모음 | 오류와 경고 확인 |
| 저장 | 명령 모음 | 흐름 저장 |
| 테스트 | 명령 모음 | 저장한 흐름 시험 실행 |
| Copilot | 명령 모음 | Copilot 창 표시와 숨김 |
| 새 디자이너 토글 | 오른쪽 위 | 새 디자이너 · 구 디자이너 전환 |
| 구성 창 | 왼쪽 | 고른 카드의 값과 설정 |
| 캔버스 | 가운데 | 카드를 놓아 흐름을 만듦 |
| Copilot 창 | 오른쪽 | 대화로 흐름 수정. 흐름과 제품 질문 |

## 구성 창의 탭

카드를 고르면 왼쪽에 구성 창이 열립니다. 창 위쪽 ⋮(추가 명령)에는 메모 추가 · 작업 고정 · 삭제가 있습니다. `<<` 로 창을 접습니다.[^designer]

| 탭 | 하는 일 |
|---|---|
| 매개 변수 | 작업의 입력 칸. 번개와 ***fx*** 단추로 값을 넣음 |
| 설정 | 시간 제한 · 재시도 · 실행 후 · 보안 · 추적 |
| 코드 보기 | 카드의 JSON 정의. 읽기 전용 |
| 테스트 | 정적 결과 설정 |

설정 탭의 항목입니다.[^designer]

| 묶음 | 칸 | 내용 |
|---|---|---|
| 일반 | 작업 시간 제한 | 재시도와 비동기 응답 사이의 최대 기간. 요청 하나의 시간 제한은 바꾸지 않음 |
| 네트워킹 | 재시도 정책 | 일시적 실패의 재시도. 기본값은 지수 간격이고 낮은 프로필 2회, 중간 · 높은 프로필은 프리미엄 커넥터가 없으면 8회 · 있으면 12회. 사용자 지정 또는 없음 선택 가능 |
| 이후 실행 | 실행 후 | 앞 작업이 성공 · 시간 초과 · 건너뜀 · 실패한 뒤 실행할지 |
| 보안 | 보안 입력 · 보안 출력 | 입력과 출력 숨김 |
| 추적 | 추적 속성 | 키와 값 |

실행 후는 [C17](c17-error-handling.html), 보안 입력과 출력은 [C24](c24-secure.html)에서 다룹니다.

## 저장

저장 결과는 왼쪽 위 알림으로 확인합니다.[^designer][^work]

| 결과 | 화면 |
|---|---|
| 오류 없음 | 왼쪽 위 녹색 체크와 「흐름을 진행할 준비가 되었습니다」 알림 |
| 오류 있음 | 왼쪽 위 오류 설명과 빨간 **X**. 오류를 낸 카드에도 표시 |
| 트리거만 있음 | 저장되지 않음. 트리거와 작업이 하나 이상 있어야 함 |
| 경고만 있음 | 저장됨. 흐름 검사기 창이 열림 |

**흐름 검사기**는 명령 모음의 청진기 아이콘입니다. 저장할 때 오류나 경고가 있으면 자동으로 열리고, 항목을 고르면 해당 작업으로 갑니다. 오류와 경고가 없으면 오류 없음 메시지가 뜹니다.[^checker]

저장에 실패한 흐름을 그대로 두고 나가면 새 디자이너가 사본을 브라우저 저장소에 둡니다.[^designer]

| 항목 | 내용 |
|---|---|
| 다시 열 때 | 마지막으로 저장한 버전이 열림 |
| 흐름 복구 | 명령 모음에서 저장되지 않은 사본을 불러옴 |
| 사본을 저장할 때 | 저장한 버전을 덮어쓰고 브라우저 저장소를 비움 |
| 브라우저 캐시 삭제 | 사본도 삭제 |

솔루션 안의 흐름은 명령 모음에 초안 저장과 게시가 더 있습니다. 초안은 오류가 있어도 저장됩니다.[^designer] 솔루션은 [C23](c23-solutions.html)에서 다룹니다.

## 테스트

테스트는 저장한 뒤에 쓸 수 있습니다.[^designer][^test]

| 방식 | 내용 | 조건 |
|---|---|---|
| 수동 | 트리거가 될 동작을 직접 수행 | 없음 |
| 자동 | 최근에 사용한 트리거로 이전 실행을 반복 | 수동 테스트를 한 번 이상 한 뒤 |

수동 트리거 흐름은 **흐름 실행** 창에서 연결을 확인하고 입력값을 넣어 실행합니다. 실행이 끝나면 카드마다 초록 체크와 걸린 초가 표시됩니다.[^designer] 실행 화면에서 디자이너로 돌아가는 단추는 편집입니다.

카드의 테스트 탭에서 정적 결과를 켜면 그 작업을 실제로 실행하지 않고 지정한 결과로 처리합니다. 켠 카드에는 비커 아이콘이 붙습니다. 긴 작업을 건너뛰거나 작업이 실패할 때의 동작을 볼 때 씁니다.[^designer][^test] 실행 기록은 [C16](c16-run-history.html)에서 다룹니다.

## 캔버스와 카드

캔버스에서 카드를 놓고 옮기고 복사합니다.[^designer][^editor]

| 조작 | 방법 |
|---|---|
| 작업 추가 | 카드 아래 **+** › **작업 추가** |
| 카드 사이에 추가 | 카드 사이 선에 마우스를 올리면 **+** 가 보임 |
| 카드 옮기기 | 끌어서 파란 점선 드롭 영역에 놓음 |
| 복사 | 카드를 마우스 오른쪽 단추로 눌러 **작업 복사** |
| 붙여넣기 | **+** 를 마우스 오른쪽 단추로 눌러 **작업 붙여넣기** |
| 키보드 복사 | Ctrl + C · Ctrl + V |
| 메모 | 구성 창 **⋮** › 메모 추가. 카드 오른쪽 아래에 표시 |
| 작업 고정 | 카드를 마우스 오른쪽 단추로 눌러 고정. 다음 작업 창이 오른쪽에 열려 나란히 비교 |

조건이나 범위 카드도 복사할 수 있습니다. 붙여넣은 카드 이름 끝에는 번호가 붙습니다. 다른 흐름으로 붙여넣는 것과 트리거 복사는 문서끼리 설명이 다릅니다.[^designer][^classic][^peek]

구성 창을 닫으면 캔버스 왼쪽 아래에 도구가 나타납니다.[^designer]

| 도구 | 하는 일 |
|---|---|
| 확장 · 축소 | 작업 그룹 전체 펼치기와 접기 |
| 확대 · 축소 | 흐름의 크기 |
| 맞춤 보기 | 전체 흐름을 화면에 맞춤 |
| 미니맵 | 큰 흐름의 특정 구간으로 이동 |
| 검색 | 흐름 안의 작업 찾기 |
| 레이아웃 | 인라인(확장된 카드에 표시) · 패널(구성 창에 표시) 전환 |

## 새 디자이너와 구 디자이너

이 과정의 화면은 새 디자이너입니다. 새로 만드는 흐름은 새 디자이너로 열립니다. 기존 흐름은 환경 설정과 마지막 편집 시점에 따라 달라질 수 있습니다.[^classic]

| 항목 | 새 디자이너 | 구 디자이너 |
|---|---|---|
| 카드 | 작은 카드. 값은 왼쪽 구성 창에서 편집 | 큰 카드. 제목을 눌러 펼쳐 편집 |
| Copilot | 사용 가능 | 사용 불가 |
| 식 편집기 | 자동 완성과 매개 변수 안내 | 일반 입력 상자 |
| 코드 보기 | 구성 창의 코드 보기 | 카드 메뉴의 Peek code |
| 앞으로 | 새 기능이 들어옴 | 유지 관리 모드. 보안과 치명적 오류 수정만 |

두 디자이너는 같은 흐름 정의를 편집합니다. 흐름의 런타임은 디자이너 버전과 관계가 없습니다.[^classic] 일부 트리거와 작업이 있는 흐름은 새 디자이너에서 열리지 않습니다. 문서의 목록에는 Power Apps v1 트리거, Dataverse 의 변경 집합 요청 등이 있습니다.[^designer]

## 흔한 실패

문서의 자주 묻는 질문과 알려진 문제에서 옮겼습니다.[^designer][^classic]

| 증상 | 원인 | 조치 |
|---|---|---|
| 저장했는데 다음에 열면 수정이 없음 | 저장이 조용히 실패한 경우 | 저장 후 초록 알림을 확인. 없으면 다시 저장. 응답이 없으면 탭을 닫지 않고 기다림 |
| 저장 단추가 빨간 오류로 끝남 | 필수 칸이 비었거나 식 오류 | 흐름 검사기에서 항목 고르기 |
| 새 SharePoint 열이 동적 콘텐츠에 없음 | 디자이너가 예전 열 정보를 씀 | 작업을 지우고 다시 추가 |
| `O.split(...).at is not a function` | 2년이 넘은 브라우저 | 브라우저 업데이트 |
| 조건 · 반복이 모두 접혀서 열림 | 복잡한 흐름의 기본 표시 | 확장 도구 또는 카드별로 펼침 |
| 큰 흐름에서 식 편집기가 느림 | 작업 50개 이상 또는 동적 값이 많음 | 메모장에서 식을 쓴 뒤 붙여넣기 |
