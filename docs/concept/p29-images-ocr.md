> **다루는 것**: UI 요소를 쓸 수 없을 때 화면 조각과 화면 글자로 자동화하는 방법

## 쓰는 경우

웹이나 앱의 UI 요소에 접근할 수 없으면 브라우저 작업 · UI 작업 · 일반 기록기를 쓸 수 없습니다. 이때 이미지나 마우스 · 키보드로 자동화합니다. 문서는 가상 데스크톱(VDI) 자동화에 이 방법을 권합니다.[^ocr-howto]

| 방법 | 기준으로 삼는 것 | 쓰는 경우 |
|---|---|---|
| UI 요소 | 선택기 | 요소에 접근할 수 있을 때 |
| 이미지 | 캡처한 화면 조각 | UI 요소에 접근할 수 없을 때 |
| OCR | 화면에서 읽은 글자 | 이미지를 기준으로 삼을 수 없을 때 |
| 마우스 · 키보드 | 좌표 · 키 입력 | 이미지 · OCR 과 함께 화면을 움직일 때 |

기록기의 이미지 기록을 켜면 이미지와 OCR 로 된 작업을 기록으로도 만들 수 있습니다. 기록기 대화 상자 오른쪽의 점 아이콘에서 **이미지 기록**을 켭니다.[^recording]

## 이미지 캡처와 관리

이미지는 디자이너 오른쪽 창의 **이미지** 탭에서 다룹니다.[^images]

| 할 일 | 조작 |
|---|---|
| 캡처 | **이미지 캡처**를 누르고 대상 영역을 끎. 돋보기가 함께 보임. 이름을 넣고 **확인** |
| 시간 지연 캡처 | **이미지 캡처** 단추의 화살표에서 시간을 고름. 직접 정하려면 **사용자 지정 지연으로 이미지 캡처** |
| 폴더 만들기 | **새 폴더 추가**. 폴더를 연 채 캡처하면 그 폴더에 저장됨 |
| 안 쓰는 이미지 지우기 | **이미지 캡처** 옆 점 아이콘의 **사용하지 않는 이미지 제거**. 폴더 안에서 실행하면 그 폴더만 대상 |
| 이름 변경 · 삭제 | 항목을 마우스 오른쪽 단추로 눌러 고름 |
| 쓰는 작업 찾기 | 이미지를 마우스 오른쪽 단추로 눌러 **사용법 찾기**. 결과를 두 번 클릭하면 작업이 강조됨 |
| 이미지 보기 | 썸네일을 누름 |

## 이미지 일치 설정

이미지를 쓰는 작업의 고급 설정에서 정합니다.[^images][^keys]

| 설정 | 값 | 내용 |
|---|---|---|
| 이미지 일치 알고리즘 | 기본 | 200x200 픽셀 미만의 이미지에 맞음. 기본값 |
| 이미지 일치 알고리즘 | 고급 | 더 큰 이미지에 맞고 색 변화에 강함 |
| 허용 범위 | 숫자. 기본값 10 | 캡처한 이미지와 화면이 달라도 되는 정도. 값이 크면 인식 정밀도에 영향 |

## 이미지를 쓰는 작업

| 작업 | 하는 일 | 생성 변수 |
|---|---|---|
| 이미지로 마우스 이동 | 찾은 이미지 위로 마우스를 옮김. 클릭을 함께 보낼 수 있음 | `X` · `Y` |
| 이미지 대기 | 이미지가 나타나거나 사라질 때까지 흐름을 멈춤 | `X` · `Y` |
| If image | 이미지가 있는지 없는지로 갈라지는 조건 블록 | 없음 |

대기와 조건 작업은 UI 자동화 묶음에 있습니다.[^ui] 아래는 이미지로 마우스 이동의 주요 칸입니다.[^keys]

| 칸 | 기본값 | 내용 |
|---|---|---|
| 마우스를 옮길 이미지 | — | 이미지 목록 |
| 항목 | 1 | 같은 이미지가 여럿일 때 몇 번째로 옮길지 |
| 마우스를 옮긴 후 클릭 보내기 | 끔 | 켜면 클릭 종류를 고름 |
| 이미지가 나타나기까지 대기 | 켬 | 이미지를 찾지 못할 때 기다릴지 |
| 실패 시간 제한 | 0 | 실패로 처리할 시간(초) |
| 클릭 전 초 | 0 | 클릭 전에 기다릴 시간(초) |
| 이미지에 상대적인 마우스 위치 | 중앙 | 이미지의 어느 부분으로 옮길지 |
| 오프셋 X · 오프셋 Y | 0 | 위치에서 오른쪽 · 아래로 옮길 픽셀 |
| 다음에서 이미지 검색 | 전체 화면 | 전체 화면 또는 전경 창만 |

이미지가 화면에 또렷이 보이지 않으면 어느 쪽 검색도 찾지 못합니다. 전경 창에서 찾으면 `X` · `Y` 는 창의 왼쪽 위 모서리 기준입니다.[^keys]

## OCR 엔진

두 엔진 모두 Power Automate 에 미리 설치되어 있고 클라우드 연결 없이 로컬에서 동작합니다. 작업의 **OCR 엔진 설정**에서 언어와 이미지 승수를 정합니다.[^ocr]

| 엔진 | 언어 | 조건 |
|---|---|---|
| Windows OCR 엔진 | 한국어를 포함한 25개 언어 | 해당 언어의 Windows 언어 팩이 있어야 함. 없으면 설치하라는 오류가 남 |
| Tesseract 엔진 | 영어 · 독일어 · 스페인어 · 프랑스어 · 이탈리아어 | CPU 가 AVX2 를 지원해야 함 |

Tesseract 로 다른 언어를 읽으려면 **다른 언어 사용**을 켜고 언어 약어와 언어 데이터 경로를 넣습니다. 데이터 파일은 `.traineddata` 입니다. `eng.traineddata` 이면 약어는 `eng` 입니다.[^ocr]

이미지 너비 승수와 높이 승수는 이미지를 키워 인식을 돕습니다. 기본값은 1이고, 3보다 크면 결과가 잘못될 수 있습니다. OCR 엔진 변수 옵션은 사용 중단 예정입니다.[^ocr]

## OCR 작업

OCR 작업은 네 가지입니다.[^ocr][^keys]

| 작업 | 하는 일 | 생성 변수 |
|---|---|---|
| OCR로 텍스트 추출 | 글자를 읽어 변수에 담음 | `OcrText` |
| 화면에서 텍스트 대기(OCR) | 글자가 나타나거나 사라질 때까지 흐름을 멈춤 | `LocationOfTextFoundX` · `LocationOfTextFoundY` |
| 화면의 텍스트인 경우(OCR) | 글자가 있는지 없는지로 갈라지는 조건 블록 | `LocationOfTextFoundX` · `LocationOfTextFoundY` |
| 화면에서 텍스트로 마우스 이동(OCR) | 글자 위로 마우스를 옮김. 클릭을 함께 보낼 수 있음 | `LocationOfTextFoundX` · `LocationOfTextFoundY` · `WidthOfTextFound` · `HeightOfTextFound` |

아래는 OCR 작업의 주요 칸입니다.[^ocr]

| 칸 | 값 |
|---|---|
| OCR 소스(추출 작업) | 화면 · 전경 창 · 디스크의 이미지. 기본값 화면 |
| 검색 모드 | 지정된 소스 전체 · 특정 하위 영역만 · 이미지에 상대적인 하위 영역 |
| X1 · Y1 · X2 · Y2 | 하위 영역의 시작과 끝 좌표 |
| 정규식 여부(대기 · 조건 · 마우스 이동) | 찾을 글자를 .NET 정규식으로 해석할지 |
| 시간 제한(추출 작업) | 기본값 5초 |

## 마우스 · 키보드로 짜는 순서

| 순서 | 할 일 | 작업 |
|---:|---|---|
| 1 | 대상 창을 앞으로 가져와 최대화 | 창 포커스 · 창 상태 설정 |
| 2 | 화면이 준비되기를 기다림 | 대기 · 이미지 대기 · 화면에서 텍스트 대기(OCR) |
| 3 | 화면을 움직임 | 키 보내기 · 이미지로 마우스 이동 · 화면에서 텍스트로 마우스 이동(OCR) |
| 4 | 글자를 고름 | 키 보내기(`Ctrl` + `A`) 또는 마우스 클릭 보내기(왼쪽 단추 아래로, 왼쪽 단추 위로) |
| 5 | 글자를 복사해 변수로 받음 | 키 보내기(`Ctrl` + `C`) · 클립보드 텍스트 가져오기 |

5번 대신 OCR로 텍스트 추출을 쓸 수 있습니다.[^ocr-howto]

**화면을 쓰는 작업에는 조건이 둘 있습니다.** 대화형이 아닌 모드에서는 이미지 확인 · 화면 글자 확인 · 마우스 · 키 입력이 오류로 끝납니다. 키 보내기와 마우스 클릭 보내기로 높은 권한의 앱을 다루려면 Power Automate 도 관리자 권한으로 실행합니다.[^keys][^ocr]

## 샘플

흐름 `개념 연습_HGD` 를 씁니다. 없으면 [P2](p02-types.html)의 1·2번으로 만듭니다. Main 의 줄을 지우고 쌓습니다.

1. Edge 로 아래 주소를 엽니다. Edge 창과 디자이너 창을 겹치지 않게 둡니다.

    ```
    {{ site.url }}{{ site.baseurl }}/practice/bid/
    ```

2. 디자이너 오른쪽 세로 막대의 **이미지**를 누르고 **이미지 캡처**를 누릅니다.
3. Edge 창의 **검색** 단추 둘레를 끌어 영역을 잡습니다. 이름에 아래를 넣고 **확인**을 누릅니다.

    ```
    검색단추
    ```

    **완료 기준**: 이미지 창에 `검색단추` 가 보인다.

4. 작업 검색 칸에 `이미지로 마우스` 를 입력하고 **이미지로 마우스 이동**을 작업 영역으로 끌어다 놓습니다. **마우스를 옮길 이미지**에서 `검색단추` 를 고르고, **마우스를 옮긴 후 클릭 보내기**를 켜고 **저장**을 누릅니다.
5. 도구 모음의 **실행**(▶)을 누릅니다. 오른쪽 세로 막대의 **{x}** 를 눌러 변수 창을 엽니다.

    **완료 기준**: Edge 창에 `검색 결과` 건수가 표시되고, 변수 창의 `X` · `Y` 에 숫자가 있다.

6. 작업 검색 칸에 `OCR` 을 입력하고 **OCR로 텍스트 추출**을 맨 아래로 끌어다 놓습니다. **OCR 엔진**을 **Windows OCR 엔진**으로 바꾸고 **OCR 소스**는 **화면** 그대로 둡니다. **OCR 엔진 설정**을 펴서 **Windows OCR 언어**를 **한국어**로 바꾸고 **저장**을 누릅니다.
7. **실행**(▶)을 누릅니다. Edge 창이 화면에 보이는 상태로 둡니다.

    **완료 기준**: 변수 창의 `OcrText` 에 화면의 글자가 들어 있고 `검색` 이 포함되어 있다.
