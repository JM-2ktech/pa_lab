>

## % 사이의 내용은 계산합니다

변수 이름은 `%` 로 감쌉니다. `%` 와 `%` 사이의 내용은 식으로 계산합니다.[^manip] 칸 안에서 글자와 섞어 쓸 수 있습니다.

| 칸에 넣은 것 | 칸의 값 |
|---|---|
| `PA 실습` | 글자 그대로 |
| `%Course%` | 변수 `Course` 의 값 |
| `%Course% 과정을 시작합니다.` | 변수 값 뒤에 글자 |
| `C:\PA실습\결과\고객발굴_%오늘%.xlsx` | 경로 가운데에 변수 값 |
| `%다음행 - 2%` | 계산한 값 |
| `100%%` | `100%` |

식에는 고정값 · 변수 이름 · 산술 연산 · 논리 연산 · 비교 · 괄호를 함께 쓸 수 있습니다.[^manip]

---

## 고정값과 변수 이름

식 안에서 따옴표로 감싼 내용은 텍스트로 읽고, 따옴표 밖의 이름은 변수로 읽습니다.[^manip] 변수 이름에는 다른 표기를 붙이지 않습니다.

| 식 | 읽는 방법 |
|---|---|
| `%'Index'%` | 글자 Index |
| `%Index%` | 변수 `Index` 의 값 |
| `%'교육'%` | 글자 교육 |
| `%''%` | 글자가 없는 텍스트 |
| `%4 / Var%` | 수 4 와 변수 `Var` 의 값 |

문서의 예에는 작은따옴표(`'this is '`)와 큰따옴표(`"Four"`)가 모두 나옵니다.[^manip] 정의하지 않은 변수는 설계 시 오류가 되어 흐름이 실행되지 않습니다.[^errors]

---

## 빈 값

변수는 null 값을 담을 수 있습니다. 동적 변수와 중첩 속성을 포함한 모든 변수가 **Blank** 값을 가질 수 있습니다.[^manip]

| 확인할 것 | 쓰는 것 |
|---|---|
| 변수가 Blank 인가 | 조건 작업의 연산자 Is blank · Is not blank |
| 텍스트에 글자가 없는가 | `%IsEmpty(arg1)%` · 조건 작업의 연산자 Is empty |

작업의 입력 칸은 null 을 허용할 때만 빈 값을 받습니다. 받지 못하는 칸에 넣으면 오류가 납니다.[^manip]

---

## 산술 연산

연산자는 더하기 `+` · 빼기 `-` · 곱하기 `*` · 나누기 `/` 입니다.[^manip]

| 식 | 결과 | 결과 자료형 |
|---|---|---|
| `%5 * 3%` | 15 | 숫자 |
| `%4 / Var%` | 4 를 `Var` 의 값으로 나눈 값 | 숫자 |
| `%다음행 - 2%` | `다음행` 의 값에서 2 를 뺀 값 | 숫자 |
| `%'this is ' + 'text'%` | this is text | 텍스트 |
| `%'This is the number ' + 5%` | This is the number 5 | 텍스트 |

`+` 는 텍스트도 이어 붙입니다. 한 식에 숫자와 텍스트가 섞이면 숫자를 텍스트로 바꿔 이어 붙입니다.[^manip]

---

## 비교 연산

| 연산자 | 뜻 |
|---|---|
| `=` · `<>` | 같음 · 같지 않음 |
| `<` · `<=` | 작음 · 작거나 같음 |
| `>` · `>=` | 큼 · 크거나 같음 |

비교의 결과는 True 또는 False 입니다. 비교는 같은 자료형의 값끼리만 됩니다.[^manip] 형식을 바꾸는 방법은 [P17](p17-convert.html)에서 다룹니다.

---

## 논리 연산

지원하는 연산자는 `AND` · `OR` · `NOT` 입니다.[^manip] 한 식에서 여러 조건을 함께 확인합니다.

| 식 | 결과 |
|---|---|
| `%Index = 1 OR Index = 2%` | `Index` 가 1 또는 2 이면 True, 그 밖에는 False |
| `%Index = 4 AND Text = "Four"%` | `Index` 가 4 이고 `Text` 가 Four 이면 True, 그 밖에는 False |
| `%NOT(4 <> 4)%` | 괄호 안의 논리값을 뒤집음. 이 식은 True |

한국어판 문서는 이 식을 `인덱스` · `또는` · `및` 로 번역해 적어 두었습니다. 연산자는 영어 표기로 씁니다.

---

## 텍스트를 확인하는 함수

결과는 모두 True 또는 False 입니다.[^manip]

| 식 | True 가 되는 경우 |
|---|---|
| `%StartsWith(arg1,arg2,arg3)%` | arg2 로 시작 |
| `%NotStartsWith(arg1,arg2,arg3)%` | arg2 로 시작하지 않음 |
| `%EndsWith(arg1,arg2,arg3)%` | arg2 로 끝남 |
| `%NotEndsWith(arg1,arg2,arg3)%` | arg2 로 끝나지 않음 |
| `%Contains(arg1,arg2,arg3)%` | arg2 를 포함 |
| `%NotContains(arg1,arg2,arg3)%` | arg2 를 포함하지 않음 |
| `%IsEmpty(arg1)%` | 글자가 하나도 없음 |
| `%IsNotEmpty(arg1)%` | 글자가 하나 이상 있음 |

| 인수 | 뜻 |
|---|---|
| arg1 | 찾아볼 대상 텍스트. `IsEmpty` · `IsNotEmpty` 에서는 확인할 텍스트 |
| arg2 | 찾을 텍스트 |
| arg3 | 대소문자 무시 여부. `True` · `False` |

---

## 괄호

연산 순서를 바꾸려면 괄호를 씁니다. 대수나 프로그래밍 언어와 같게 처리합니다.[^manip]

| 식 | 먼저 계산하는 것 |
|---|---|
| `%2 + 3 * 4%` | `3 * 4` |
| `%(2 + 3) * 4%` | `2 + 3` |

---

## % 글자 쓰기

`%` 는 변수와 식을 나타내는 특수 문자입니다. 글자 `%` 를 쓰려면 `%%` 로 적습니다.[^manip]

---

## 흔한 실패

| 증상 | 원인 | 고치는 방법 |
|---|---|---|
| 줄에 설계 시 오류 표시 · 실행 안 됨 | 따옴표를 빠뜨려 `%교육%` 이 변수 이름으로 읽힘 | `%'교육'%` 로 고침 |
| 합계가 `01000` 같은 이어 붙인 글자 | 식의 한쪽이 텍스트 | 숫자로 변환한 뒤 계산 |
| 조건이 항상 거짓 | 자료형이 다른 값을 비교 | 두 값을 같은 자료형으로 맞춤 |
| 값에 든 `%` 때문에 표기가 깨짐 | `%` 하나를 글자로 씀 | `%%` 로 적음 |

## 샘플

2. **Main** 탭의 빈 곳을 한 번 누르고 `Ctrl` + `A` 로 전체를 고른 뒤 `Delete` 키를 누릅니다.
