## 작업의 구성

많은 양의 구조화된 데이터를 추출할 때 **웹 페이지에서 데이터 추출**을 씁니다.[^autoweb] 값 하나만 필요하면 웹 페이지 요소의 세부 정보 가져오기로도 됩니다.

| 단계 | 하는 곳 | 정하는 것 |
|---|---|---|
| 1 | 라이브 웹 도우미 | 무엇을 추출할지. 페이지 선택기 |
| 2 | 작업 대화 상자 | 몇 쪽을 읽을지. 어디에 저장할지 |

## 라이브 웹 도우미

작업 대화 상자를 열어 둔 채 브라우저 창을 앞으로 가져오면 뜹니다.[^lab] 페이지의 요소를 고르거나 오른쪽 단추로 누르면 메뉴가 나옵니다.

| 메뉴 | 하는 일 |
|---|---|
| 요소 값 추출 | 그 요소의 값 하나. 하위 메뉴에서 HTML 특성을 고름 |
| 전체 HTML 테이블 추출 | HTML 표 전체. PAD 가 HTML 표로 인식한 요소에만 나옴 |
| 요소를 페이지 선택기로 설정 | 다음 쪽으로 가는 요소를 지정 |
| 상위 UI 요소 선택 | 고른 요소의 부모로 올라감 |

고른 결과는 추출 미리 보기에 표로 보입니다. 완료로 대화 상자에 돌아오고 취소로 버립니다. 값을 고른 뒤 도우미를 닫으려 하면 확인 창이 뜹니다.[^rel]

## 추출 종류

| 종류 | 고르는 방법 | 결과 |
|---|---|---|
| 단일 값 | 요소 값 추출 한 번 | 값 하나 |
| 직접 고른 값 | 요소 값 추출 여러 번. 값마다 다른 선택기 | 값 여러 개(데이터 행) |
| 목록 | 같은 모양의 요소를 두 개 이상 고름 | 목록 |
| 테이블 | 표 모양 데이터의 요소를 두 개 이상 고름 | 데이터 테이블 |
| 전체 HTML 테이블 | 표에서 전체 HTML 테이블 추출 | 데이터 테이블 |

요소를 두 개 이상 고르면 PAD 가 목록이나 표를 자동으로 알아냅니다.[^autoweb] 표 모양이지만 HTML 표로 인식되지 않으면 전체 추출 메뉴가 없으니 처음 두 요소를 고릅니다.

전체 HTML 테이블 추출은 머리글을 열 이름으로 씁니다.[^lab] 생성 변수 `DataFromWebPage` 의 값은 추출 종류에 따라 단일 값 · 목록 · 데이터 행 · 데이터 테이블입니다.[^web]

## CSS 선택기로 지정

라이브 웹 도우미의 **고급 설정**에서 추출 대상과 페이지 선택기를 CSS 선택기로 직접 쓸 수 있습니다.[^autoweb]

| 구성 요소 | 내용 |
|---|---|
| 트리 구조 | HTML 요소의 경로 |
| 특성 | 그 요소에서 추출할 특성 |
| 정규식 | 선택 사항. 값의 일부를 고를 때 |

## 대화 상자의 칸

| 칸 | 값 | 기본값 |
|---|---|---|
| 웹 브라우저 인스턴스 | `%Browser%` | 없음 |
| 데이터 추출 | 첫 번째만 · 사용 가능한 모든 항목 | 첫 번째만 |
| 처리할 최대 웹 페이지 수 | 쪽 수. 사용 가능한 모든 항목을 고르면 칸이 사라짐 | 0 |
| 다음 페이지로 실제 클릭 보내기 | 마우스를 옮겨 실제로 클릭. 창을 앞으로 가져옴 | 끔 |
| 추출 시 데이터 처리 | 화면 표시대로 정리. iframe 안의 정보 표시, 숨긴 요소 거름 | 끔 |
| 시간 제한 | 추출이 끝날 때까지 기다릴 초 | 60 |
| 데이터 저장 모드 | 변수 · Excel 스프레드시트 | 변수 |

추출 시 데이터 처리는 데이터가 많으면 추출 시간이 늘어나 문서가 권하지 않습니다.[^web] 데이터 저장 모드를 Excel 스프레드시트로 두면 `ExcelInstance` 가 함께 만들어집니다. 저장하고 닫는 일은 Excel 작업으로 합니다.[^web]

## 페이지 매김

같은 구조의 페이지가 여러 쪽으로 나뉘어 있으면 페이지 선택기를 지정합니다.[^autoweb] 다음 쪽으로 가는 단추를 라이브 웹 도우미에서 오른쪽 단추로 누르고 **요소를 페이지 선택기로 설정**을 고릅니다.

| 확인할 곳 | 페이지 선택기가 들어갔을 때의 표시 |
|---|---|
| 추출 미리 보기 맨 아래 | 「다음 페이지의 상응하는 값...」 행 |
| 대화 상자의 시놉시스 | 「여러 웹 페이지의 HTML 테이블 레코드를 8열 테이블 형식으로 추출합니다.」 |
| 작업 영역의 줄 요약 | 「사용 가능한 모든 웹 페이지에서 페이징을 사용하여」 |

| 데이터 추출 | 읽는 범위 |
|---|---|
| 첫 번째만 | 처리할 최대 웹 페이지 수에 적은 만큼. 0 이면 첫 쪽 |
| 사용 가능한 모든 항목 | 다음 쪽 요소를 찾지 못할 때까지 |

마지막 쪽에서 다음 단추가 문서에서 없어져야 멈춥니다. 단추를 숨기거나 비활성으로만 두는 사이트에서는 멈추지 않습니다.[^lab] 사례와 대응은 [P16](p16-wait-timeout.html)에서 다룹니다.

| 표기 | 값 |
|---|---|
| `%DataFromWebPage.RowsCount%` | 행 수 |
| `%DataFromWebPage.Columns%` | 열 이름 목록 |

읽는 표기는 [P4](p04-index.html), 속성은 [P5](p05-properties.html)에서 다룹니다.[^types]

추정가격은 `120,000,000` 처럼 쉼표가 든 텍스트로 추출됩니다. 수로 쓰려면 쉼표를 지우고 숫자로 바꿉니다. 변환은 [P17](p17-convert.html)에서 다룹니다. 머리글 `추정가격(원)` 처럼 괄호가 든 열은 번호로 읽습니다.[^lab]

## 흔한 실패

| 증상 · 예외 | 원인 | 고치는 방법 |
|---|---|---|
| 첫 쪽 10행만 읽힘 | 데이터 추출이 첫 번째만 | 사용 가능한 모든 항목으로 바꿈 |
| 실행이 끝나지 않음 | 마지막 쪽에도 다음 요소가 있음 | [P16](p16-wait-timeout.html)의 대응을 씀 |
| 전체 HTML 테이블 추출 메뉴가 없음 | HTML 표로 인식되지 않음 | 처음 두 요소를 골라 표를 만듦 |
| 미리 보기가 빈 상태 | 잘못된 화면에서 도우미를 염 | 브라우저를 추출할 화면으로 옮긴 뒤 다시 고름 |
| 다음 단추를 눌러도 쪽이 안 넘어감 | 에뮬레이트된 클릭에 페이지가 반응하지 않음 | 다음 페이지로 실제 클릭 보내기를 켬 |
| Failed to extract data | 데이터를 추출하는 데 문제 | 선택기와 페이지 상태를 확인 |

## 샘플

흐름 `개념 연습_HGD` 를 씁니다. 없으면 [P2](p02-types.html)의 1·2번으로 만듭니다.

1. Power Automate 콘솔에서 `개념 연습_HGD` 의 **편집**을 눌러 디자이너를 엽니다.
2. 작업 영역의 빈 곳을 한 번 누르고 `Ctrl` + `A` 를 누른 뒤 `Delete` 를 눌러 **Main** 의 줄을 지웁니다.
3. Edge 주소창에 아래 주소를 넣고 엽니다. 「검색 결과 36건」과 「1 / 4」가 보입니다. 이 창은 닫지 않습니다.

    ```
    {{ site.url }}{{ site.baseurl }}/practice/bid/
    ```

4. 작업 검색 칸에 `Edge` 를 입력하고 **새 Microsoft Edge 시작**을 작업 영역으로 끌어다 놓습니다. **이니셜 URL**에 아래를 넣고 **저장**을 누릅니다.

    ```
    {{ site.url }}{{ site.baseurl }}/practice/bid/
    ```

5. 작업 검색 칸에 `데이터 추출` 을 입력하고 **브라우저 자동화 › 웹 데이터 추출** 아래 **웹 페이지에서 데이터 추출**을 1번 줄 아래로 끌어다 놓습니다.
6. 대화 상자를 열어 둔 채 3번의 Edge 창을 앞으로 가져옵니다.

    **완료 기준**: **라이브 웹 도우미** 창이 뜨고 추출 미리 보기에 「선택한 추출이 없습니다」가 보인다.

7. 표의 **공고번호** 머리글에서 마우스 오른쪽 단추를 누르고 **전체 HTML 테이블 추출**을 고릅니다.

    **완료 기준**: 추출 미리 보기에 여덟 열짜리 표가 보인다.

8. 라이브 웹 도우미의 **완료**를 누릅니다. 대화 상자에서 **저장**을 누릅니다.
9. 도구 모음의 **실행**(▶)을 누릅니다. 끝나면 오른쪽 세로 막대의 **{x}** 를 눌러 변수 창을 엽니다. 흐름이 연 Edge 창을 닫습니다.

    **완료 기준**: `DataFromWebPage` 옆에 `10개 행, 8 열` 이 보인다.

10. 2번 줄을 두 번 클릭해 엽니다. 3번의 Edge 창을 앞으로 가져옵니다.
11. 표 아래 **다음** 단추에서 마우스 오른쪽 단추를 누르고 **요소를 페이지 선택기로 설정**을 고릅니다.

    **완료 기준**: 추출 미리 보기 맨 아래에 「다음 페이지의 상응하는 값...」이 흐리게 보인다.

12. **완료**를 누릅니다. 대화 상자의 **처리할 최대 웹 페이지 수**에 아래를 넣고 **저장**을 누릅니다.

    ```
    2
    ```

13. **실행**(▶)을 누릅니다. 끝나면 변수 창을 보고 흐름이 연 Edge 창을 닫습니다.

    **완료 기준**: `DataFromWebPage` 옆에 `20개 행, 8 열` 이 보인다.

14. 2번 줄을 두 번 클릭해 열고 **데이터 추출**을 **사용 가능한 모든 항목**으로 바꾼 뒤 **저장**을 누릅니다.

    **완료 기준**: **처리할 최대 웹 페이지 수** 칸이 사라진다.

15. **실행**(▶)을 누릅니다. 흐름이 연 Edge 창이 쪽을 넘깁니다.

    **완료 기준**: 그 창이 「4 / 4」에서 멈추고 **다음** 단추가 없다. `DataFromWebPage` 옆에 `36개 행, 8 열` 이 보인다.

16. 작업 검색 칸에 `변수 설정` 을 입력하고 **변수 설정**을 2번 줄 아래로 끌어다 놓습니다. **변수**와 **값**에 아래를 차례로 넣고 **저장**을 누릅니다.

    ```
    첫공고
    ```

    ```
    %DataFromWebPage[0]['공고번호']%
    ```

17. **변수 설정**을 3번 줄 아래로 하나 더 놓고 아래를 차례로 넣은 뒤 **저장**을 누릅니다.

    ```
    행수
    ```

    ```
    %DataFromWebPage.RowsCount%
    ```

18. **웹 페이지에서 데이터 추출**을 4번 줄 아래로 하나 더 놓습니다. 3번의 Edge 창을 앞으로 가져옵니다.
19. 「검색 결과 36건」 글자에서 마우스 오른쪽 단추를 누르고 **요소 값 추출**에서 글자 값을 고릅니다. **완료**를 누르고 대화 상자에서 **저장**을 누릅니다.
20. **실행**(▶)을 누릅니다. 끝나면 변수 창을 보고 흐름이 연 Edge 창을 닫습니다.

    **완료 기준**: `첫공고` 는 `R26BK01326`, `행수` 는 `36`, `DataFromWebPage2` 는 `검색 결과 36건` 이다.
