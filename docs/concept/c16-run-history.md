## 확인하는 단계

| 단계 | 도구 | 잡는 것 |
|---|---|---|
| 저장 전 | 흐름 검사기 | 빈 필수 칸 · 연결 · 식 오류 · 성능 경고 |
| 저장 | 저장 | 식 문법 · 없는 카드 이름 · 상수 식의 형식 오류 |
| 실행 | 테스트 · 실행 기록 | 실제 값에서 나는 실패 · 결과가 틀린 흐름 |

**흐름 검사기**는 명령 모음에 있고, 저장할 때 오류나 경고가 있으면 자동으로 열립니다. 항목을 누르면 그 카드의 오류를 볼 수 있습니다.[^checker] 경고만 있으면 저장은 됩니다.

저장에 성공하면 왼쪽 위에 준비 알림이 뜹니다. 오류가 있으면 빨간 X와 설명이 뜨고, 오류를 낸 카드에도 표시됩니다.[^designer]

| 증상 | 나눠 보는 곳 |
|---|---|
| 저장되지 않음 | 빨간 칸 · 비어 있는 필수 칸 · 식의 괄호와 따옴표[^trouble] |
| 저장했지만 실행 기록이 없음 | 트리거 · 트리거 조건 · 흐름 켜짐 상태[^trouble] |
| 실행했지만 카드가 실패 | 아래 「실패를 읽는 순서」[^trouble] |
| 전부 초록인데 결과가 틀림 | 아래 「결과가 틀린 흐름」[^trouble] |

## 테스트 창

명령 모음의 **테스트**를 누르면 흐름 테스트 창이 열립니다. 흐름을 저장해야 테스트할 수 있습니다.[^test]

| 옵션 | 동작 | 조건 |
|---|---|---|
| 수동 | 트리거를 직접 일으켜 실행 | 저장 후 |
| 자동 | 최근 쓴 트리거로 다시 실행 · 이전 테스트 반복 | 수동 테스트 1회 이상[^test] |

카드의 테스트 탭에서 **정적 결과 사용**을 켜면 작업을 실제로 실행하지 않고 지정한 결과로 처리합니다. 비커 모양 아이콘이 카드에 붙습니다. 승인처럼 오래 걸리는 카드를 건너뛸 때 씁니다.[^test]

## 실행 기록

왼쪽 메뉴 내 흐름에서 흐름을 열면 세부 정보 페이지에 **28일 실행 기록**이 있습니다. 시작 · 기간 · 상태 열을 기본으로 보여 줍니다.[^fix] 열 편집으로 트리거 출력을 열에 더할 수 있습니다.[^fix]

실행 하나를 누르면 카드마다 결과가 표시됩니다.

| 표시 | 뜻 |
|---|---|
| 초록 체크와 걸린 시간 | 성공[^designer] |
| 빨간 표시 | 실패[^fix] |
| 건너뜀 | 실행되지 않음. 조건의 다른 가지 등 |
| 파란 원 | 실행 중. 승인을 기다리는 카드 포함 |

카드를 누르면 입력과 출력이 보입니다. 출력 칸 오른쪽 위 **원시 출력 표시**를 누르면 전체를 JSON으로 볼 수 있습니다. 읽는 표기는 [C8](c08-json.html)에서 다룹니다.

실행 기록은 시작 시각부터 30일 보관됩니다. 트리거나 작업이 14일 동안 계속 실패한 흐름은 꺼집니다.[^limits]

## 실패를 읽는 순서

1. 실행 기록에서 실패한 실행의 날짜를 누릅니다.
2. 빨간 표시가 붙은 카드를 찾습니다. 여러 개면 먼저 실패한 카드부터 봅니다.[^trouble]
3. 카드를 눌러 오류 코드와 메시지를 읽습니다. 메시지에 고치는 방법이 적혀 있기도 합니다.[^fix]
4. **입력**을 펼쳐 실제로 보낸 값을 봅니다. 요청 주소 · 행 ID 같은 값입니다.[^fix]
5. **출력**을 펼쳐 상대 서비스가 돌려준 메시지와 상태 코드를 봅니다.[^fix]
6. 입력의 값이 이상하면 그 값을 만든 앞 카드의 출력으로 거슬러 올라갑니다.[^trouble]
7. **편집**으로 고치고 저장한 뒤 다시 테스트합니다.[^fix]

| 코드 · 메시지 | 뜻 | 보는 곳 |
|---|---|---|
| `InvalidTemplate` | 식 문법 · 없는 카드 이름 · 상수 식의 형식 오류. 저장 때 나옴 | 빨간 카드의 식[^errors] |
| `ExpressionEvaluationFailed` | 실행 중 실제 값이 식과 맞지 않음 | 실패 카드의 식과 입력[^errors] |
| 400 · Bad request | 입력 형식 · 필수 값 오류 | 입력[^errors] |
| 401 · 403 · Unauthorized | 인증 · 권한 | 연결 · 대상의 권한[^fix] |
| 404 · Not found | 목록 · 파일의 이름 변경이나 삭제 | 입력의 주소와 이름[^trouble] |
| 429 | 호출 제한 | 재시도 설정 · 지연[^trouble] |
| 500 · 502 | 일시적 서비스 오류 | 다시 제출[^fix] |

코드 전체는 [C22](c22-error-codes.html)에서 다룹니다.

## 식 오류가 나는 시점

식의 값이 상수뿐이면 엔진이 저장할 때 검사합니다. 동적 값이 들어 있으면 저장은 되고 실행할 때 실패합니다.[^errors]

| 식 | 검사 시점 | 결과 |
|---|---|---|
| `int('abc')` | 저장 | `InvalidTemplate`. 저장되지 않음[^errors] |
| `int('3.14')` | 저장 | `InvalidTemplate`. 저장되지 않음[^cookbook] |
| `int(triggerBody()?['text'])` 에 입력 `abc` | 실행 | 그 카드가 실패[^errors] |

`int()` 는 소수 문자열에서 오류를 냅니다. 소수가 올 수 있으면 `float()` 를 먼저 씁니다.[^cookbook]

```
int(float(triggerBody()?['text']))
```

값이 숫자인지 먼저 확인하는 식은 아래입니다.[^errors]

```
if(isInt(triggerBody()?['text']), int(triggerBody()?['text']), 0)
```

## 결과가 틀린 흐름

모든 카드가 초록인데 결과가 다르면 카드마다 입력과 출력을 기대값과 대조합니다.[^trouble]

| 확인 | 흔한 원인 |
|---|---|
| 조건 카드의 비교 값 | 끝 공백 · 대소문자 · 숫자 `1` 과 문자열 `"1"` |
| 칸의 값이 온 곳 | 다른 카드의 같은 이름 출력 · 반복의 다른 항목 |
| 반복의 입력 건수 | 앞 작업에 필터가 필요함 |
| 쓴 값을 바로 읽음 | 읽기가 이전 값을 돌려줌. 사이에 지연 |

중간값을 보려면 그 값을 입력으로 둔 **작성** 카드를 넣고 실행 기록에서 출력을 봅니다.[^trouble]

## 다시 제출과 다른 도구

실행 기록에서 실행을 고르고 **다시 제출**로 같은 입력을 다시 돌리거나 취소로 멈춥니다.[^test]

| 다시 제출하기 전에 볼 것 | 이유 |
|---|---|
| 항목 만들기 · 메일 보내기 카드 | 항목과 메일이 한 번 더 생김 |
| 입력 데이터 | 삭제된 파일 · 항목이면 결과가 달라짐 |
| 원래 실행 뒤에 고친 내용 | 결과가 달라질 수 있음 |

흐름이 실패하면 소유자에게 복구 팁 메일이 옵니다. 실패 시각 · 일어난 일 · 해결 방법 · 다시 시도 링크가 들어 있습니다.[^fix] 새 디자이너에서는 Copilot이 오류를 요약하고 해결책을 제안하기도 합니다.[^fix]

## 샘플

흐름 `식 연습장_HGD` 를 씁니다. 없으면 [C7](c07-types.html)의 샘플로 만듭니다. 텍스트 입력의 값을 숫자로 바꾸는 식을 넣고, 숫자가 아닌 값으로 실패시킨 뒤 실행 기록을 읽습니다.

1. [Power Automate — {{ site.pa.environment }}]({{ site.pa.powerautomate_url }}){:target="_blank"}를 엽니다. 왼쪽 메뉴 **내 흐름**에서 `식 연습장_HGD` 를 열고 **편집**을 누릅니다.
2. **작성** 카드를 누릅니다. **입력** 칸을 비우고 ***fx*** 단추를 누릅니다. 식 편집기에 아래를 붙여넣고 **추가**를 누릅니다.

    ```
    int(triggerBody()?['text'])
    ```

3. **저장**을 누릅니다.

    **완료 기준**: 오류 없이 저장 알림이 뜬다.

4. **테스트** › **수동** › **테스트**를 누릅니다. **흐름 실행** 창의 입력 칸에 아래를 넣고 **흐름 실행**을 누른 뒤 **완료**를 누릅니다.

    ```
    42
    ```

5. 실행 화면에서 **작성** 카드를 누릅니다.

    **완료 기준**: 카드에 초록 체크가 있고 출력이 `42` 다.

6. 오른쪽 위 **편집**을 누릅니다. **테스트** › **수동** › **테스트**를 누릅니다. 입력 칸에 아래를 넣고 **흐름 실행**을 누른 뒤 **완료**를 누릅니다.

    ```
    abc
    ```

    **완료 기준**: **작성** 카드가 실패로 표시된다.

7. **작성** 카드를 누릅니다.

    **완료 기준**: 오류 코드와 메시지가 보인다.

8. **입력**과 **출력**을 차례로 펼쳐 무엇이 있는지 봅니다.
9. 트리거 카드를 누르고 **출력**을 엽니다.

    **완료 기준**: 출력에 입력한 값 `abc` 가 있다.

10. 화면 왼쪽 위 **←**(뒤로)를 눌러 흐름 세부 정보 페이지로 갑니다.

    **완료 기준**: **28일 실행 기록** 맨 위가 실패이고, 바로 아래가 성공이다.

11. **편집**을 누릅니다. **작성** 카드의 **입력**을 비우고 ***fx***로 아래 식을 넣은 뒤 **저장**을 누릅니다.

    ```
    int('abc')
    ```

    **완료 기준**: 저장되지 않고 오류 설명이 뜬다. **작성** 카드에도 오류가 표시된다.

12. **작성** 카드의 **입력**을 비우고 ***fx***로 아래 식을 넣은 뒤 **저장**을 누릅니다.

    ```
    if(isInt(triggerBody()?['text']), int(triggerBody()?['text']), 0)
    ```

13. 6번과 같이 입력 `abc` 로 실행합니다. **작성** 카드를 누릅니다.

    **완료 기준**: 카드에 초록 체크가 있고 출력이 `0` 이다.
