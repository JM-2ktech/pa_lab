## 고치는 순서

문서 네 개의 내용을 순서로 묶었습니다.[^test][^repair][^custom][^fallback]

| 순서 | 할 일 | 기능 |
|---:|---|---|
| 1 | 선택기가 요소를 찾는지 확인 | 선택기 테스트 |
| 2 | 다시 잡아 자동으로 고침 | 복구 |
| 3 | 복구가 안 되면 직접 고침 | 선택기 빌더 · 텍스트 편집기 |
| 4 | 선택기를 하나 더 둠 | 재캡처 · 복사본 생성 |
| 5 | 선택기가 실패할 때를 대비 | 이미지 대체 |

---

## 선택기 테스트

선택기 빌더 창의 **선택기 테스트**는 지정한 선택기로 화면의 요소를 찾습니다. 대상 앱이나 페이지가 화면에 열려 있어야 합니다. 웹 요소는 웹 브라우저 탭 드롭다운에서 탭을 고릅니다. 단추 옆 화살표의 모든 선택기 테스트는 꺼진 선택기를 빼고 전부 시험합니다.[^test]

| 결과 | 뜻 | 조치 |
|---|---|---|
| 성공 | 요소를 찾음 | — |
| 실패함 | 요소를 찾지 못함. 찾지 못한 수준이 요소 목록에 강조됨 | 그 수준을 고침 |
| 여러 UI 요소가 발견됨 | 여럿을 찾음. 실행할 때는 화면 왼쪽 위부터 첫 요소를 씀 | 특성을 더해 하나로 좁힘 |

선택기를 고치면 결과 표시가 지워져 다시 시험합니다. 변수가 든 선택기는 변수 값을 넣어 시험합니다. 데스크톱 요소의 화면을 찾지 못하면 **화면 선택기 열기**로 화면 선택기를 고칩니다.[^test]

## 선택기 복구

복구는 대상 요소를 다시 잡아 고친 선택기를 자동으로 만드는 기능입니다. 데스크톱 · 웹 UI 요소와 화면 선택기에 쓸 수 있습니다.[^repair]

| 순서 | 조작 |
|---:|---|
| 1 | 선택기 빌더 또는 텍스트 편집기에서 선택기를 고르고 **복구**를 누름 |
| 2 | UI 요소 선택 도구에서 대상 요소에 테두리가 뜨면 `Ctrl` + 왼쪽 클릭 |
| 3 | 바뀐 부분이 강조된 제안을 보고 **확인** |
| 4 | **저장**. **취소**를 누르면 원래 선택기가 남음 |

| 조건 | 내용 |
|---|---|
| 잡을 수 있는 요소 | 복구하는 선택기의 종류만. 데스크톱은 데스크톱, 웹은 웹 |
| 변수가 든 선택기 | 복구할 수 없음. 값을 고정하거나 직접 고침 |
| 복구가 실패할 때 | 요소를 바르게 잡았는지 확인하고, 그래도 안 되면 직접 고침 |

직접 고치는 표기는 [P12](p12-selectors.html)에서 다룹니다.

---

## 선택기 여러 개

UI 요소 하나에 선택기를 여럿 둘 수 있습니다. 선택기가 실패하면 정해진 순서로 다음 선택기를 씁니다. 재캡처 단추로 새 선택기를 만들거나, 기존 선택기를 마우스 오른쪽 단추로 눌러 **복사본 생성**을 고릅니다.[^custom]

---

## 이미지 대체

선택기가 실행 중에 요소를 찾지 못하면 지정한 이미지로 찾게 하는 기능입니다. UI 자동화와 브라우저 자동화 작업에 씁니다.[^fallback]

선택기 빌더 창에서 **대체로 이미지 설정**을 누르고, UI 요소 선택 도구에서 요소를 `Ctrl` + 왼쪽 클릭합니다. 요소의 이미지가 캡처되고 선택기 목록에 이미지 선택기가 생깁니다.[^fallback]

| 이미지 선택기에서 할 일 | 내용 |
|---|---|
| 삭제 | 필요 없을 때 지움 |
| 이름 변경 | 알아보기 쉬운 이름으로 바꿈 |
| 테스트 | 이미지를 화면에서 찾는지 확인. 대상이 맨 앞에 보여야 함 |
| 복구 | 현재 이미지를 새 이미지로 바꿈 |

| 제한 | 내용 |
|---|---|
| 개수 | UI 요소당 이미지 선택기 하나. 만든 뒤에는 단추가 꺼짐 |
| 지원하지 않는 작업 | 데이터 추출 · 웹 데이터 추출 |
| 텍스트 조건 | 창이 포함하는 경우 · 창 콘텐츠 대기 · 웹 페이지가 포함하는 경우 · 웹 페이지 콘텐츠 대기를 텍스트 포함 · 미포함 조건으로 쓸 때 |
| 이전 버전 | v2.44 이하에서 흐름을 열어 저장하면 이미지 선택기가 영구 삭제됨. 다시 캡처해야 함 |

## 샘플

흐름 `개념 연습_HGD` 를 씁니다. 없으면 [P2](p02-types.html)의 1·2번으로 만듭니다. Main 의 줄을 지우고 쌓습니다.

1. 작업 검색 칸에 `Edge` 를 입력하고 **새 Microsoft Edge 시작**을 작업 영역으로 끌어다 놓습니다. **이니셜 URL**에 아래를 넣고 **저장**을 누릅니다.

    ```
    {{ site.url }}{{ site.baseurl }}/practice/bid/
    ```

2. 도구 모음의 **실행**(▶)을 누릅니다. 열린 Edge 창은 닫지 않고, 디자이너와 겹치지 않게 둡니다.
3. 작업 검색 칸에 `버튼 누르기` 를 입력하고 **웹 페이지 버튼 누르기**를 맨 아래로 끌어다 놓습니다. **UI 요소** 칸의 드롭다운을 열고 **UI 요소 추가**를 누릅니다. Edge 창의 **검색** 단추를 `Ctrl` + 왼쪽 클릭으로 잡습니다.
4. **UI 요소** 칸 오른쪽의 연필 아이콘을 누릅니다. **특성** 목록에서 **Id** 값을 아래로 바꿉니다.

    ```
    btnSearchX
    ```

5. **웹 브라우저 탭**에서 모의 공고 조회 탭을 고르고 **선택기 테스트**를 누릅니다.

    **완료 기준**: 선택기 옆에 실패 표시가 있다.

6. **복구**를 누릅니다. UI 요소 선택 도구가 뜨면 Edge 창의 **검색** 단추를 `Ctrl` + 왼쪽 클릭합니다. 제안을 보고 **확인**을 누릅니다.
7. **선택기 테스트**를 다시 누릅니다.

    **완료 기준**: 선택기 옆에 성공 표시가 있다.

8. **대체로 이미지 설정**을 누르고 Edge 창의 **검색** 단추를 `Ctrl` + 왼쪽 클릭합니다.

    **완료 기준**: 선택기 목록에 이미지 선택기가 생기고 **대체로 이미지 설정** 단추가 꺼져 있다.

9. 기존 선택기의 **Id** 값을 아래로 다시 바꾸고 **저장**을 누릅니다. 작업 대화 상자에서도 **저장**을 누릅니다.

    ```
    btnSearchX
    ```

10. Edge 창을 닫고 **실행**(▶)을 누릅니다. 새로 열린 Edge 창이 화면에 보이는 상태로 둡니다.

    **완료 기준**: 오류 없이 실행이 끝나고 Edge 창에 `검색 결과` 건수가 표시된다.

11. 열린 Edge 창을 닫습니다.
