> **다루는 것**: 데이터 테이블에 행을 더하는 표기와 행 · 열 · 표 전체를 바꾸는 작업
>
> **쓰는 곳**: 랩에서 쓰지 않음

---

## `+` 로 행 더하기

**변수 설정**의 변수 칸에 테이블 이름을 넣고, 값 칸에 테이블 이름 · `+` · 대괄호로 묶은 새 행의 값을 씁니다.[^types] 값의 개수는 열 개수에 맞춥니다.

```
%공고표 + ['A-4', '공사', '5000']%
```

**데이터 테이블에 행 삽입** 작업도 같은 일을 합니다. 행을 끝이 아닌 위치에 넣을 때는 이 작업을 씁니다.[^vars]

---

## 데이터 테이블 작업

전부 **변수** 묶음의 데이터 테이블 작업입니다.[^vars] 입력 칸의 괄호에서 첫 값이 기본값입니다. 결과 변수가 없는 작업은 데이터 테이블 칸에 넣은 변수의 내용을 바꿉니다.

### 행

| 작업 | 하는 일 | 입력 | 결과 변수 |
|---|---|---|---|
| 데이터 테이블에 행 삽입 | 행 추가 | 삽입할 위치(데이터 테이블 끝 · 행 색인 이전) · 행 색인 · 새로운 값. 새로운 값은 열 수가 같은 목록 또는 데이터 행 | 없음 |
| 데이터 테이블에서 행 삭제 | 지정한 행 삭제 | 행 색인 | 없음 |
| 데이터 테이블에서 빈 행 삭제 | 모든 셀이 빈 행 삭제 | 데이터 테이블 | 없음 |
| 데이터 테이블에서 중복 행 삭제 | 같은 행을 하나만 남김 | 데이터 테이블 | 없음 |
| 데이터 테이블 지우기 | 모든 행 삭제. 머리글은 유지 | 데이터 테이블 | 없음 |

### 열

| 작업 | 하는 일 | 입력 | 결과 변수 |
|---|---|---|---|
| 데이터 테이블에 열 삽입 | 열 추가 | 삽입할 위치(데이터 테이블 끝 · 열 인덱스 앞) · 열 이름 · 열 색인 | 없음 |
| 데이터 테이블에서 열 삭제 | 지정한 열 삭제 | 다음의 열 지정(이름 · 색인) · 열 이름 또는 열 색인 | 없음 |
| 목록으로 데이터 테이블 열 검색 | 한 열을 목록으로 복사 | 열 이름 또는 인덱스 | `ColumnAsList` |

how-to 문서는 Excel 을 거쳐 열을 지우는 우회 방법을 적고 있습니다.[^delcol] 작업 참조에는 위의 **데이터 테이블에서 열 삭제**가 있습니다.

### 값

| 작업 | 하는 일 | 입력 | 결과 변수 |
|---|---|---|---|
| 데이터 테이블 항목 업데이트 | 한 칸의 값 변경 | 열 이름 또는 색인 · 행 색인 · 새로운 값 | 없음 |
| 데이터 테이블에서 찾기 또는 바꾸기 | 값 찾기 · 바꾸기 | 검색 모드(찾기 · 찾기 및 바꾸기) · 모든 일치(켬) · 찾을 텍스트 · 정규식을 사용하여 찾기(끔) · 대/소문자 구분(끔) · 전체 셀 콘텐츠 일치(끔) · 바꿀 텍스트 · 검색 기준(모든 위치 · 열에서) | `DataTableMatches` |

`DataTableMatches` 에는 일치한 칸의 행 색인과 열 색인이 담깁니다.

### 표 전체

| 작업 | 하는 일 | 입력 | 결과 변수 |
|---|---|---|---|
| 새 데이터 테이블 만들기 | 시각적 빌더로 표 작성 | 새 테이블 | `DataTable` |
| 데이터 테이블 정렬 | 지정한 열 기준 정렬. 그 열의 값이 같은 형식일 때 | 다음의 열 지정(이름 · 색인) · 열 이름 또는 색인 · 순서(오름차순 · 내림차순) | 없음 |
| 데이터 테이블 필터링 | 규칙에 맞는 행으로 새 표 작성 | 적용할 필터 · 대/소문자 구분(켬) | `FilteredDataTable` |
| 데이터 테이블 병합 | 둘째 표를 첫째 표에 붙임 | 병합 모드(추가 열 추가 · 추가 열 무시 · 추가 열 오류) | 없음. 첫째 표에 담김 |
| 데이터 테이블 조인 | 규칙에 맞는 행을 이어 새 표 작성 | 조인 작업(안쪽 · 왼쪽 · 전체) · 조인 규칙 | `JoinedDataTable` |

**데이터 테이블 필터링**은 열 · 연산자 · 값으로 이루어진 규칙을 여러 개 넣을 수 있습니다. 규칙은 AND 와 OR 로 잇고, AND 를 먼저 계산합니다.[^vars]

### CSV 텍스트와 변환

| 작업 | 하는 일 | 입력 | 결과 변수 |
|---|---|---|---|
| CSV 텍스트 변수에서 읽기 | CSV 텍스트로 표 작성 | CSV 텍스트 · 필드 자르기(켬) · 첫째 줄에 열 이름 포함(끔) · CSV 필드를 텍스트로 가져오기(끔) · 열 구분 기호(미리 정의됨 · 사용자 지정 · 고정 열 너비) | `CSVTable` |
| 텍스트로 데이터 테이블 변환 | 표를 CSV 텍스트로 변환 | 열 이름 포함(끔) · 사용자 지정 열 구분 기호 사용(끔) · 구분 기호(시스템 기본값 · 쉼표 · 세미콜론 · 탭) | `CSVText` |

## 실패하는 조건

| 오류 | 조건 |
|---|---|
| 항목 색인이 범위를 벗어남 | 행 번호가 표 밖. 번호는 0부터 |
| 열 이름이 없음 | 표에 없는 열 이름 |
| 열 색인이 범위를 벗어남 | 열 번호가 표 밖. 번호는 0부터 |
| 호환되지 않는 유형 오류 | 입력 값의 형식이 맞지 않음 |
| 열의 셀에 입력 불일치 발생 | 한 열에 형식이 다른 값이 섞임. 정렬 · 필터링 · 중복 행 삭제에서 발생 |
| 열 이름 복제 | 열 삽입에서 이미 있는 이름 사용 |
| 스키마 누락 | 병합에서 두 표의 열 수가 다름 |

줄바꿈이 든 칸은 변수 뷰어에 첫 줄만 표시됩니다.[^types] 행 수와 열 이름은 `%표.RowsCount%` · `%표.Columns%` 로 읽습니다. 속성은 [P5](p05-properties.html), 칸을 읽는 표기는 [P4](p04-index.html)에서 다룹니다.

## 샘플

흐름 `개념 연습_HGD` 를 씁니다. 없으면 [P2](p02-types.html)의 1·2번으로 만듭니다.

1. **Main** 탭의 빈 곳을 한 번 누르고 `Ctrl` + `A` 를 누른 뒤 `Delete` 를 눌러 줄을 지웁니다.
2. 작업 검색 칸에 `변수 설정` 을 입력하고 **변수 설정**을 작업 영역으로 끌어다 놓습니다. **변수**와 **값**에 아래를 차례로 넣고 **저장**을 누릅니다.

    ```
    공고표
    ```

    ```
    %{^['공고번호', '분류', '추정가격'], ['A-1', '용역', '3000'], ['A-2', '물품', '1000'], ['A-3', '용역', '2000']}%
    ```

3. **변수 설정**을 1번 줄 아래로 하나 더 놓습니다. **변수**에 같은 이름을 넣고 **값**에 아래를 넣은 뒤 **저장**을 누릅니다.

    ```
    공고표
    ```

    ```
    %공고표 + ['A-4', '공사', '5000']%
    ```

4. 도구 모음의 **실행**(▶)을 누릅니다. 오른쪽 세로 막대의 **{x}** 를 눌러 변수 창을 열고 `공고표` 를 두 번 클릭합니다.

    **완료 기준**: 4행이고 마지막 행이 `A-4` 다.

5. 작업 검색 칸에 `데이터 테이블 필터링` 을 입력하고 **데이터 테이블 필터링**을 맨 아래로 끌어다 놓습니다. **데이터 테이블**에 `%공고표%` 를 넣습니다. **적용할 필터**에 규칙을 하나 넣습니다. 열은 첫째 값, 연산자는 같음, 값은 둘째 값입니다. **저장**을 누릅니다. 결과는 `FilteredDataTable` 에 담깁니다.

    ```
    분류
    ```

    ```
    용역
    ```

6. 작업 검색 칸에 `데이터 테이블 정렬` 을 입력하고 **데이터 테이블 정렬**을 맨 아래로 끌어다 놓습니다. **데이터 테이블**에 `%공고표%` 를 넣고, **열 이름**에 아래를 넣고, **순서**를 **내림차순**으로 바꾼 뒤 **저장**을 누릅니다.

    ```
    추정가격
    ```

7. 작업 검색 칸에 `항목 업데이트` 를 입력하고 **데이터 테이블 항목 업데이트**를 맨 아래로 끌어다 놓습니다. **데이터 테이블**에 `%공고표%` 를 넣습니다. **열** · **행** · **새로운 값**에 아래를 차례로 넣고 **저장**을 누릅니다. 행 번호는 0부터 셉니다.

    ```
    분류
    ```

    ```
    0
    ```

    ```
    용역
    ```

8. 작업 검색 칸에 `열 삽입` 을 입력하고 **데이터 테이블에 열 삽입**을 맨 아래로 끌어다 놓습니다. **데이터 테이블**에 `%공고표%` 를 넣고 **열 이름**에 아래를 넣은 뒤 **저장**을 누릅니다.

    ```
    비고
    ```

9. 작업 검색 칸에 `열 삭제` 를 입력하고 **데이터 테이블에서 열 삭제**를 맨 아래로 끌어다 놓습니다. **데이터 테이블**에 `%공고표%` 를 넣고 **열 이름**에 아래를 넣은 뒤 **저장**을 누릅니다.

    ```
    추정가격
    ```

10. 작업 검색 칸에 `데이터 테이블 열` 을 입력하고 **목록으로 데이터 테이블 열 검색**을 맨 아래로 끌어다 놓습니다. **데이터 테이블**에 `%공고표%` 를 넣고 **열 이름 또는 인덱스**에 아래를 넣은 뒤 **저장**을 누릅니다. 결과는 `ColumnAsList` 에 담깁니다.

    ```
    공고번호
    ```

11. **메시지 표시**를 맨 아래로 끌어다 놓습니다. **표시할 메시지**에 아래를 넣고 **저장**을 누릅니다.

    ```
    행 %공고표.RowsCount%개
    ```

12. **실행**합니다.

    **완료 기준**: 메시지 창에 `행 4개` 가 뜬다.

13. 메시지 창을 닫고 변수 창에서 변수를 두 번 클릭해 값을 봅니다.

    **완료 기준**: `공고표` 는 열이 `공고번호` · `분류` · `비고` 이고 공고번호 순서가 `A-4` · `A-1` · `A-3` · `A-2` 이며 첫 행의 분류가 `용역` 이다. `FilteredDataTable` 은 `A-1` · `A-3` 두 행이다. `ColumnAsList` 는 항목 넷이고 순서가 `공고표` 와 같다.
