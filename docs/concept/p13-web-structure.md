## 작업의 순서

브라우저 자동화는 웹 요소를 다루는 UI 자동화의 특수한 경우입니다.[^autoweb] 다른 브라우저 작업을 놓기 전에 브라우저 시작 작업으로 인스턴스를 먼저 만듭니다.

```
새 Microsoft Edge 시작           이니셜 URL → %Browser%
웹 페이지의 텍스트 필드 채우기    %Browser% · UI 요소 · 텍스트
웹 페이지 버튼 누르기             %Browser% · UI 요소
웹 페이지에서 데이터 추출         %Browser% → %DataFromWebPage%
웹 브라우저 닫기                 %Browser%
```

| 갖출 것 | 없을 때 | 다루는 곳 |
|---|---|---|
| 브라우저 확장(또는 WebDriver) | 웹 UI 요소를 잡지 못하고 작업이 브라우저와 통신하지 못함 | 이 페이지 |
| 웹 브라우저 인스턴스 | 작업의 필수 칸인 인스턴스 칸을 채우지 못함 | [P10](p10-instances.html) |
| 웹 UI 요소 | 어느 구성 요소를 다룰지 정할 수 없음 | [P11](p11-ui-elements.html) · [P12](p12-selectors.html) |

이 과정은 Microsoft Edge 하나만 씁니다.

## 브라우저 확장

PAD 설치가 끝날 때 설치 프로그램이 확장 설치를 안내합니다. 건너뛰었으면 아래 경로로 설치합니다.[^ext]

| 방법 | 경로 |
|---|---|
| 디자이너 메뉴 | 도구 › 브라우저 확장 |
| 스토어 | PAD v2.27 이상용 [Microsoft Power Automate 확장](https://microsoftedge.microsoft.com/addons/detail/microsoft-power-automate/kagpabjoboikccfdghpdlaaopmgpgfdc){:target="_blank"} |
| 설치 폴더의 파일 | `C:\Program Files (x86)\Power Automate Desktop\BrowserExtensions` 의 파일을 `edge://extensions/` 에 끌어다 놓음. 개발자 모드 필요 |
| 확인 | Edge 주소창에 `edge://extensions/` 입력. Microsoft Power Automate 가 켜져 있는지 봄 |

v2.26 이하용 확장은 따로 있습니다. 문서가 링크를 나눠 둡니다.[^ext]

흐름이 예상대로 동작하도록 Edge 설정 › 시스템의 **Microsoft Edge를 닫았을 때 백그라운드 앱을 계속 실행**을 끕니다.[^ext]

## 브라우저 상호 작용 메서드

시작 작업에 PAD 가 브라우저와 통신하는 방식을 고르는 칸이 있습니다. 기본값은 브라우저 확장입니다.[^web]

WebDriver 를 쓰려면 브라우저 버전에 맞는 x64 실행 파일을 `%LocalAppData%\Microsoft\Power Automate Desktop\WebDrivers` 에 둡니다. 파일 이름을 바꾸거나 하위 폴더에 넣지 않습니다.[^ext]

| WebDriver 의 제한 | 내용 |
|---|---|
| 브라우저에 연결 | 흐름이 띄운 브라우저에만 연결. 손으로 연 브라우저는 안 됨 |
| 페이지 대기 | 서버가 느리면 설정한 시간 제한을 지키지 않고 응답까지 멈출 수 있음 |
| 병렬 실행 | 부모와 하위 흐름에서 다른 브라우저를 동시에 다루면 문제가 생길 수 있음 |
| 하위 흐름 | 부모가 띄운 브라우저에는 인스턴스를 입력으로 넘겨야 함 |
| 로그인 정책 | 브라우저 로그인을 강제하는 정책에서 동작하지 않음 |
| Internet Explorer | 쓸 수 없음 |

## 새 Microsoft Edge 시작의 칸

| 칸 | 값 | 기본값 |
|---|---|---|
| 시작 모드 | 새 인스턴스 시작 · 실행 중인 인스턴스에 연결 | 새 인스턴스 시작 |
| Microsoft Edge 탭에 연결 | 제목 사용 · URL 기준 · 전경 창 사용 | 제목 사용 |
| 이니셜 URL | 처음 열 주소 | 없음 |
| 탭 제목 · 탭 URL | 연결할 탭의 제목이나 주소. 일부만 적어도 됨 | 없음 |
| 창 상태 | 일반 · 최대화됨 · 최소화됨 | 일반 |
| 대상 데스크톱 | 로컬 컴퓨터 · 가상 데스크톱 | 로컬 컴퓨터 |
| 브라우저 상호 작용 메서드 | 브라우저 확장 · WebDriver | 브라우저 확장 |
| 캐시 지우기 · 쿠키 지우기 | 켬 · 끔 | 끔 |
| 페이지가 로드될 때까지 대기 | 켬 · 끔 | 켬 |
| 웹 페이지 로드 시간 제한 | 초 | 60 |
| 팝업 대화창이 나타날 경우 | 닫기 · 단추 누르기 · 아무 작업도 안 함 | 아무 작업도 안 함 |
| 시간 제한 | 브라우저가 시작될 때까지 기다릴 초 | 60 |

탭 URL 로 연결하면 시간 제한의 절반 동안 정확히 같은 주소를 찾고, 남은 시간 동안 일부가 같은 주소를 찾습니다.[^web] 시간 제한은 [P16](p16-wait-timeout.html)에서 다룹니다.

## 에뮬레이트와 물리적 입력

브라우저 자동화 작업은 기본적으로 마우스 포인터를 움직이지 않습니다. 브라우저가 최소화되어 있거나 대상 탭이 앞에 없어도 실행됩니다.[^autoweb]

페이지가 에뮬레이트된 입력에 반응하지 않으면 물리적 입력을 켭니다. 켜면 브라우저 창을 앞으로 가져옵니다. 창을 최소화해 둘 수 없고 대상 탭이 앞에 있어야 합니다.[^autoweb]

| 작업 | 칸 | 켜면 |
|---|---|---|
| 웹 페이지의 텍스트 필드 채우기 | 물리적 키 입력을 사용하여 텍스트 채우기 | 키보드로 치듯 입력 |
| 웹 페이지에서 링크 클릭 | 물리적 클릭 보내기 | 마우스를 요소 위로 옮겨 클릭 |
| 웹 페이지에서 데이터 추출 | 다음 페이지로 실제 클릭 보내기 | 다음 단추를 실제로 클릭 |
| 웹 페이지 요소 마우스로 가리키기 | 마우스를 움직여 가리키기 | 마우스를 요소 위로 옮김 |

물리적 키 입력의 기본값은 문서에 False 로 적혀 있고, 2026-10-05 화면에서는 켜져 있었습니다.[^lab] 작업을 놓을 때 값을 확인합니다.

**입력 에뮬레이트**는 물리적 키 입력을 끄면 나타나는 칸입니다. 켜면 한 글자씩 보내고, 끄면 칸의 값을 한 번에 넣습니다. 한 글자씩 보내는 쪽이 느리고, 일부 복잡한 페이지는 이 방식이어야 입력됩니다.[^web] 자동 완성 목록을 읽는 페이지에서는 텍스트 상자 채운 후 포커스 해제를 끕니다.[^web]

## 브라우저 자동화 작업

| 묶음 | 작업 |
|---|---|
| 시작과 이동 | 새 Microsoft Edge 시작 · 새 탭 만들기 · 웹 페이지로 이동 · 웹 브라우저 닫기 |
| 웹 양식 채우기 | 웹 페이지의 텍스트 필드 채우기 · 웹 페이지의 텍스트 필드에 포커스 설정 · 웹 페이지 확인란 상태 설정 · 웹 페이지 라디오 버튼 선택 · 웹 페이지 드롭다운 목록 값 설정 · 웹 페이지 버튼 누르기 |
| 웹 데이터 추출 | 웹 페이지에서 데이터 추출 · 웹 페이지의 세부 정보 가져오기 · 웹 페이지 요소의 세부 정보 가져오기 · 웹 페이지의 스크린샷 캡처 |
| 조건과 대기 | 웹 페이지가 다음을 포함하는 경우 · 웹 페이지 콘텐츠 대기 |
| 그 밖 | 웹 페이지에서 링크 클릭 · 웹 페이지 요소 마우스로 가리키기 · 웹 페이지에서 JavaScript 함수 실행 |

**웹 페이지에서 다운로드 링크 클릭**은 Internet Explorer 에서만 동작합니다. 파일을 받을 때는 HTTP 작업을 씁니다.[^web]

| 웹 페이지의 세부 정보 가져오기 | 돌려주는 값(`WebPageProperty`) |
|---|---|
| 웹 페이지 설명 | 페이지 설명 |
| 웹 페이지 메타 키워드 | 메타 키워드 |
| 웹 페이지 제목 | 페이지 제목 |
| 웹 페이지 텍스트 | 페이지의 글자 |
| 웹 페이지 원본 | 페이지의 원본 |
| 웹 브라우저의 현재 URL 주소 | 지금 주소 |

## 흔한 실패

| 증상 · 예외 | 원인 | 고치는 방법 |
|---|---|---|
| 페이지 위에 테두리가 뜨지 않음 | 확장이 없거나 꺼짐 | `edge://extensions/` 에서 켬 |
| Failed to launch Microsoft Edge | Edge 를 시작하는 데 문제 | Edge 가 손으로 열리는지 확인 |
| Invalid URL | 이니셜 URL 이 잘못됨 | 주소를 고침 |
| Element with specified CSS selector not found | 선택기가 요소를 찾지 못함 | [P12](p12-selectors.html)의 테스트로 확인 |
| 브라우저에 연결하지 못함 | 다른 Windows 사용자로 연 브라우저 | 같은 사용자로 다시 염 |
| 흐름 실행 중 입력칸이 비어 있음 | 페이지가 에뮬레이트된 입력에 반응하지 않음 | 물리적 키 입력을 켬 |
| 글자가 다른 창으로 감 | 물리적 입력 중 다른 창을 누름 | 실행 중에 입력 장치를 쓰지 않음 |

## 샘플

흐름 `개념 연습_HGD` 를 씁니다. 없으면 [P2](p02-types.html)의 1·2번으로 만듭니다.

1. Edge 주소창에 아래를 넣고 엽니다.

    ```
    edge://extensions/
    ```

    **완료 기준**: **Microsoft Power Automate** 확장이 켜져 있다.

2. Edge 주소창에 아래 주소를 넣고 엽니다. 이 창은 닫지 않습니다.

    ```
    {{ site.url }}{{ site.baseurl }}/practice/bid/
    ```

3. Power Automate 콘솔에서 `개념 연습_HGD` 의 **편집**을 눌러 디자이너를 엽니다.
4. 작업 영역의 빈 곳을 한 번 누르고 `Ctrl` + `A` 를 누른 뒤 `Delete` 를 눌러 **Main** 의 줄을 지웁니다.
5. 작업 검색 칸에 `Edge` 를 입력하고 **브라우저 자동화** 아래 **새 Microsoft Edge 시작**을 작업 영역으로 끌어다 놓습니다. **이니셜 URL**에 아래를 넣습니다.

    ```
    {{ site.url }}{{ site.baseurl }}/practice/bid/
    ```

6. **창 상태**를 **최소화됨**으로 바꾸고 **저장**을 누릅니다.
7. 작업 검색 칸에 `텍스트 필드` 를 입력하고 **브라우저 자동화 › 웹 양식 채우기** 아래 **웹 페이지의 텍스트 필드 채우기**를 1번 줄 아래로 끌어다 놓습니다.
8. **UI 요소** 드롭다운에서 **UI 요소 추가**를 누릅니다. 2번의 Edge 창에서 **공고명** 입력칸을 `Ctrl` + 왼쪽 클릭합니다.
9. **텍스트**에 아래를 넣습니다.

    ```
    교육
    ```

10. **고급**을 펼쳐 **물리적 키 입력을 사용하여 텍스트 채우기**를 끄고 **저장**을 누릅니다.
11. 작업 검색 칸에 `버튼` 을 입력하고 **웹 양식 채우기** 아래 **웹 페이지 버튼 누르기**를 2번 줄 아래로 끌어다 놓습니다.
12. **UI 요소** 드롭다운에서 **UI 요소 추가**를 누릅니다. 2번의 Edge 창에서 **검색** 단추를 `Ctrl` + 왼쪽 클릭하고 **저장**을 누릅니다.
