## 버전 제어의 조건

버전 제어는 흐름의 초안과 게시 버전을 Dataverse 에 저장합니다. v2.62(2025-11 릴리스)부터 지원하고, 환경별로 차례로 적용됩니다.[^version]

| 항목 | 내용 |
|---|---|
| 스키마 | 환경과 흐름이 v2 스키마 |
| 권한 | 버전을 보고 복원하려면 `prvReadcomponentchangesetpayload` 필요 |
| 선택 권한 | `ComponentChangesetVersion` 읽기 · 쓰기. Environment Maker 역할에 기본 포함 |
| 끄기 | 환경에 적용된 뒤에는 끌 수 없음 |
| 버전 수 | 제한 없음. 최대 개수를 설정할 수 없음 |
| 보존 기간 | 12개월. 오래된 버전은 자동 삭제. 최신 게시 버전은 제외 |

관리자는 Power Platform 관리 센터의 환경 › 설정 › 제품 › 기능에서 **데스크톱 흐름 버전 제어** 항목을 다룹니다.[^version]

## 초안 저장과 게시

| 동작 | 만들어지는 버전 | 실행 |
|---|---|---|
| 초안 저장 | 최신 버전 | 공식 버전이 바뀌지 않음 |
| 게시 | 게시된 버전 | 콘솔과 클라우드에서 실행되는 공식 버전이 됨 |

작업 영역에 켜진 작업이 하나도 없으면 **게시**는 꺼져 있습니다. 시험을 마친 버전만 게시하고, 초안은 자주 저장합니다.[^version]

---

## 버전 기록 창

| 표시 | 뜻 |
|---|---|
| 날짜와 시각 | 버전을 만든 시점 |
| 사용자 | 작업한 사용자 |
| 최신 버전 | 가장 최근 초안 |
| 게시됨 | 현재 공식 버전 |
| 이전에 게시됨 | 지금은 공식이 아닌 과거 게시 버전 |

버전의 메뉴에는 세 가지가 있습니다.[^version]

| 메뉴 | 동작 |
|---|---|
| 보기 | 읽기 전용으로 엶. 작업 · UI 요소 · 이미지를 고칠 수 없음 |
| 이 버전 비교 | 비교 대상으로 표시. 두 번째 버전까지 고르면 비교 창이 열림 |
| 복원 | 고른 버전을 초안으로 저장하고 최신 버전으로 표시 |

흐름을 다시 만들지 않고 복원으로 되돌립니다.[^version]

## 버전 비교

저장한 버전 둘을 비교합니다. 저장하지 않은 변경은 비교할 수 없습니다. 비교 창이 열려 있는 동안 디자이너는 읽기 전용입니다. 타임스탬프가 늦은 버전을 기준으로 추가 · 제거 · 편집을 판단합니다.[^version]

| 비교 대상 | 확인하는 것 |
|---|---|
| 작업 | 작업 영역의 표시와 오른쪽 목록. 고르면 매개 변수 차이가 보임 |
| 하위 흐름 | 추가 · 제거 · 이름 변경과 내부 변경 |
| 변수 | 추가 · 제거 · 수정 |
| UI 요소 | 두 번 클릭해 이름과 선택기의 차이를 봄 |
| 이미지 | 미리 보기로 확인 |

## 전달 경로 세 가지

경로마다 쓰는 경우가 다릅니다.[^share][^premium]

| 경로 | 쓰는 경우 | 조건 |
|---|---|---|
| 작업을 복사한 텍스트 | 계정과 무관하게 작업을 전달 | 하위 흐름 하나씩 복사. 양쪽 PAD 버전을 맞춤 |
| 포털에서 공유 | 같은 조직 사용자에게 권한 부여 | 소유자 · 공동 소유자가 실행. 프리미엄 RPA 기능 |
| 솔루션 내보내기 | 환경에서 환경으로 이동 | 흐름을 솔루션에 넣어 내보냄. 환경 권한과 거버넌스 설정을 따름 |

작업을 복사하면 매개 변수 · 이미지 · UI 요소가 함께 복사됩니다. 받은 쪽은 텍스트를 디자이너에 붙여넣습니다. 작업의 내부 구조는 PAD 버전마다 달라질 수 있어, 버전이 다르면 작업이나 UI 요소 · 이미지를 인식하지 못할 수 있습니다.[^share][^designer]

솔루션은 [C23](c23-solutions.html)에서 다룹니다.

## 포털에서 공유

Power Automate 포털의 내 흐름 › 데스크톱 흐름에서 흐름을 고르고 **공유**를 누릅니다. 사용자 추가로 상대를 넣고 권한을 고른 뒤 저장합니다. 상대로 Dataverse 팀 이름도 넣을 수 있고, Microsoft Entra 그룹은 Dataverse 그룹 팀을 먼저 만듭니다.[^manage]

| 권한 | 할 수 있는 일 | 할 수 없는 일 |
|---|---|---|
| 공동 소유자 | 편집 · 공유 · 삭제. 공유 뒤의 실행을 봄 | 공유 전에 끝난 실행 보기 |
| 사용자 | 클라우드 흐름에서 사용 · 로컬 실행 · **다른 이름으로 저장**으로 복사본 만들기 | 편집 · 이름 변경 · 삭제 · 공유 |

**액세스 관리**에서 사용자의 권한을 바꾸거나 지웁니다.[^manage]

| 상황 | 내용 |
|---|---|
| 프로세스 테이블의 모든 레코드를 읽는 보안 역할 | 그 환경 모든 데스크톱 흐름의 공동 소유자로 표시됨. 역할을 고치지 않으면 지울 수 없음. System Customizer 가 예 |
| 공유받은 흐름이 안 보임 | 새로 고침 단추를 누르면 **공유한 항목** 목록에 표시 |
| 환경을 떠난 사용자 | 비활성 사용자로 표시됨. 액세스를 지움 |
| 권한이 부족하다는 메시지 | 보안 역할에 읽기 권한을 줌. 솔루션 · 팀 테이블, v2.55 부터 태그 · 태그가 지정된 프로세스 테이블 |

## 복사와 재할당

포털과 디자이너의 경로입니다.[^manage][^designer]

| 할 일 | 경로 |
|---|---|
| 포털에서 복사 | **내 흐름** › **데스크톱 흐름** › 흐름 선택 › **다른 이름으로 저장** › 이름 입력 › **저장** |
| 디자이너에서 복사 | **파일** › **다른 이름으로 저장** |
| 다른 사용자에게 재할당 | **데이터** › **테이블** › **전체** 탭의 **프로세스** › **편집** › 흐름 선택 › **양식을 사용하여 행 편집** › **할당** |
| 실행 기록과 쓰는 앱 보기 | **내 흐름** › **데스크톱 흐름** › 흐름 이름 |

## 알려진 문제

버전 제어 문서가 적은 문제입니다.[^version]

| 문제 | 내용 |
|---|---|
| 자가 복구 | 최신 버전을 초안으로 저장한 흐름은 실행 중 자가 복구가 UI 요소를 고치지 못함 |
| 가져오기 실패 | 대상 환경에 같은 흐름의 게시되지 않은 초안이 있으면 게시 버전 가져오기가 실패할 수 있음 |

## 샘플

흐름 `개념 연습_HGD` 를 씁니다. 없으면 [P2](p02-types.html)의 1·2번으로 만듭니다. Main 의 줄을 지우고 쌓습니다.

1. 작업 검색 칸에 `변수 설정` 을 입력하고 **변수 설정**을 작업 영역으로 끌어다 놓습니다. **변수** 칸과 **값** 칸에 아래를 차례로 넣고 **저장**을 누릅니다.

    ```
    판
    ```

    ```
    1
    ```

2. 도구 모음의 **저장**을 누르고 **게시**를 누릅니다.
3. 1번 줄을 두 번 클릭합니다. **값** 칸을 아래로 바꾸고 **저장**을 누른 뒤 도구 모음의 **저장**을 누릅니다.

    ```
    2
    ```

4. 버전 기록 창을 엽니다.

    **완료 기준**: 맨 위 버전에 최신 버전, 그 아래 버전에 게시됨이 표시된다.

5. **게시됨** 버전의 메뉴에서 **보기**를 고릅니다.

    **완료 기준**: 1번 줄의 값이 `1` 이고 고칠 수 없다.

6. 읽기 전용 창을 닫습니다. 버전 두 개의 메뉴에서 차례로 **이 버전 비교**를 고릅니다.

    **완료 기준**: 비교 창이 열리고 변수 설정 줄에 편집 표시가 있다.

7. 비교 창을 닫습니다. **게시됨** 버전의 메뉴에서 **복원**을 고릅니다.

    **완료 기준**: 1번 줄의 값이 `1` 이고, 새 항목에 최신 버전이 표시된다.

8. 작업 영역의 빈 곳을 한 번 누르고 `Ctrl` + `A` · `Ctrl` + `C` 를 누릅니다. 메모장을 열고 `Ctrl` + `V` 를 누릅니다.

    **완료 기준**: 메모장에 변수 설정 작업이 텍스트로 보인다.
