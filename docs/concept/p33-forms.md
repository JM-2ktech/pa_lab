## 메시지 상자 작업

메시지 상자 묶음의 작업은 일곱 가지입니다.[^display]

| 작업 | 쓰임 | 생성 변수 |
|---|---|---|
| 메시지 표시 | 메시지를 보여 주고 단추를 받음 | `ButtonPressed` |
| 입력 대화 표시 | 글자 하나를 받음 | `UserInput` · `ButtonPressed` |
| 날짜 선택 대화 표시 | 날짜나 날짜 범위를 받음 | `SelectedDate` · `SecondSelectedDate` · `ButtonPressed` |
| 목록에서 선택 대화 표시 | 목록에서 고르게 함 | `SelectedItem` · `SelectedItems` · `SelectedIndex` · `SelectedIndexes` · `ButtonPressed` |
| 파일 선택 대화 표시 | 파일을 고르게 함 | `SelectedFile` · `SelectedFiles` · `ButtonPressed` |
| 폴더 선택 대화 표시 | 폴더를 고르게 함 | `SelectedFolder` · `ButtonPressed` |
| 사용자 지정 양식 표시 | 여러 입력을 한 창에서 받음 | `CustomFormData` · `ButtonPressed` |

---

## ButtonPressed 값

`ButtonPressed` 의 값은 PAD 의 언어 설정과 상관없이 항상 영어입니다. If 에서 비교할 때 영어 값을 씁니다.[^display]

| 작업 | 값 |
|---|---|
| 메시지 표시 | 고른 단추 묶음의 영어 이름. 아래 표 |
| 입력 · 날짜 · 목록 · 폴더 대화 | `OK` · `Cancel` |
| 파일 대화 | `Open` · `Cancel` |
| 사용자 지정 양식 표시 | 누른 단추의 ID |

메시지 표시의 단추 묶음은 여섯 가지입니다.[^display]

| 단추 묶음 | 값 |
|---|---|
| 확인 | `OK` |
| 확인 - 취소 | `OK` · `Cancel` |
| 예 - 아니요 | `Yes` · `No` |
| 예 - 아니요 - 취소 | `Yes` · `No` · `Cancel` |
| 중단 - 재시도 - 무시 | `Abort` · `Retry` · `Ignore` |
| 재시도 - 취소 | `Retry` · `Cancel` |

## 작업별 주요 칸

제목과 메시지 칸 말고 작업마다 있는 칸입니다.[^display]

| 작업 | 칸 | 내용 |
|---|---|---|
| 메시지 표시 | 메시지 상자 아이콘 | 없음 · 정보 · 질문 · 경고 · 오류. 기본값 없음 |
| 메시지 표시 | 기본 단추 | 강조할 단추. Enter 를 누르면 이 단추가 눌림 |
| 메시지 표시 | 메시지 상자를 항상 위에 유지 | 기본값 끔 |
| 메시지 표시 | 메시지 상자 자동으로 닫기 | 켜면 지정한 시간 뒤 기본 단추를 누른 것처럼 닫힘. 시간의 기본값 3초. 끄면 누를 때까지 대기 |
| 입력 대화 표시 | 입력 유형 | 한 줄 · 암호 · 여러 줄. 암호는 글자를 가림 |
| 입력 대화 표시 | 기본값 | 그대로 두면 이 글자를 씀 |
| 날짜 선택 대화 표시 | 대화 유형 | 날짜 하나 · 날짜 범위 |
| 날짜 선택 대화 표시 | 입력 범위 | 날짜만 · 날짜와 시간 |
| 목록에서 선택 대화 표시 | 목록으로 제한 | 기본값 켬. 끄면 직접 입력 허용 |
| 목록에서 선택 대화 표시 | 빈 선택 허용 · 여러 개 선택 | 기본값 끔. 여러 개면 목록으로 받음 |
| 목록에서 선택 대화 표시 | + 기호로 미리 선택 | 켜면 앞에 `+` 가 붙은 항목을 미리 고름 |
| 파일 선택 대화 표시 | 파일 필터 | `*.txt` · `document?.doc`. 세미콜론으로 나눠 여럿 지정 |
| 파일 선택 대화 표시 | 여러 개 선택 · 파일 있는지 확인 | 기본값 끔 |
| 폴더 선택 대화 표시 | 초기 폴더 | 처음 열 폴더 |

대화형이 아닌 모드에서는 메시지 상자 작업을 표시할 수 없어 예외가 납니다. 무인 실행은 [P23](p23-run-modes.html)에서 다룹니다.[^display]

## 사용자 지정 양식

입력을 하나 받을 때는 위의 대화 작업으로 충분합니다. 입력과 출력을 여러 개 한 창에 둘 때 **사용자 지정 양식 표시**를 씁니다. Adaptive Cards 기술을 기반으로 합니다.[^forms]

작업을 놓고 **사용자 지정 양식 디자이너**를 누르면 디자이너가 열립니다.[^forms]

| 영역 | 내용 |
|---|---|
| 왼쪽 목록 | 추가할 요소. 두 번 클릭하거나 작업 영역으로 끌어다 놓음 |
| 작업 영역 | 양식의 구조. 빈 곳을 누르면 양식 창 자체의 속성이 보임 |
| 오른쪽 창 | 고른 요소의 속성 |
| 아래 미리 보기 | 실행할 때의 모양 |

## 양식 요소

요소는 입력 · 표시 · 작업으로 나뉩니다.[^forms]

| 요소 | 구분 | 주요 속성 |
|---|---|---|
| 문자 입력 | 입력 | ID · 레이블 · 기본값 · 여러 줄 · 스타일 · 최대 길이 · 패턴 |
| 숫자 입력 | 입력 | ID · 레이블 · 기본값 · 최소값 · 최대값 |
| 날짜 입력 | 입력 | ID · 레이블 · 기본값 · 최소값 · 최대값 |
| 시간 입력 | 입력 | ID · 레이블 · 기본값 · 최소값 · 최대값 |
| 토글 입력 | 입력 | ID · 레이블 · 제목 · 기본값 · 켜짐 시 값 · 꺼짐 시 값 |
| 선택 집합 입력 | 입력 | ID · 레이블 · 기본값 · 다중 선택 허용 · 스타일 · 선택 |
| 파일 입력 | 입력 | ID · 레이블 · 기본값 |
| 텍스트 블록 | 표시 | ID · 텍스트 · 글꼴 · 크기 · 색상 |
| 이미지 | 표시 | ID · URL · 대체 텍스트 · 크기 |
| 제출 | 작업 | ID · 제목 · 제공된 입력 무시 |
| URL 열기 | 작업 | ID · 제목 · URL |

자주 쓰는 속성입니다.

| 속성 | 기본값 | 내용 |
|---|---|---|
| 유효성 검사 필요 | 끔 | 켜면 필수 입력 |
| 오류 메시지 | — | 입력이 잘못됐을 때 표시 |
| 패턴 | — | 문자 입력의 형식을 정하는 정규식 |
| 최대 길이 | 0 | 받을 글자 수. 0 은 제한 없음 |
| 최소값 · 최대값 | — | 날짜 · 시간은 머신의 지역 형식으로 적음 |
| 켜짐 시 값 · 꺼짐 시 값 | `True` · `False` | 토글이 돌려주는 값 |
| 선택 | — | 표시할 제목과 돌려줄 값의 쌍 |
| 제공된 입력 무시 | 끔 | 켜면 입력을 저장하지 않고 닫힘. 취소 단추로 씀 |
| 제목(제출) | `OK` | 단추 글자 |

작업 요소는 양식 구조의 맨 끝에만 추가합니다.[^forms]

## 값 읽기

입력은 사용자 지정 개체 변수 `CustomFormData` 에 담깁니다. 값은 요소의 ID 로 읽습니다.[^forms]

```
%CustomFormData['ElementID']%
```

| ID 규칙 | 내용 |
|---|---|
| 고유 | 요소마다 달라야 하고 비워 둘 수 없음 |
| 글자 | 문자로 시작. 라틴 문자 · 숫자 · 공백만 허용 |
| 변수 | ID 칸에는 변수를 쓸 수 없음 |
| 잘못된 ID | 디자이너를 저장하고 닫으면 마지막 유효 ID 로 돌아감 |

단추가 여럿이면 `ButtonPressed` 를 If 로 비교해 갈라집니다. 문서의 예는 ID `Save` 면 Excel 에 값을 쓰고, 그 밖이면 흐름 중지로 끝냅니다.[^handle]

URL 속성에 `%` 를 그대로 넣으면 변수로 해석해 **잘못된 값** 오류가 납니다. 앞 줄에서 주소를 변수에 담아 `%` 를 `%%` 로 쓰고, URL 속성에는 그 변수를 넣습니다. 미리 보기에는 이미지가 나오지 않고 실행할 때 나옵니다.[^forms]

## 샘플

흐름 `개념 연습_HGD` 를 씁니다. 없으면 [P2](p02-types.html)의 1·2번으로 만듭니다. Main 의 줄을 지우고 쌓습니다.

1. 작업 검색 칸에 `사용자 지정 양식` 을 입력하고 **사용자 지정 양식 표시**를 작업 영역으로 끌어다 놓습니다. **사용자 지정 양식 디자이너**를 누릅니다.
2. 왼쪽 목록의 **문자 입력**을 두 번 클릭합니다. 오른쪽 **ID** 와 **레이블**에 아래를 차례로 넣습니다.

    ```
    Keyword
    ```

    ```
    키워드
    ```

3. **숫자 입력**을 두 번 클릭합니다. **ID** · **레이블** · **기본값**에 아래를 차례로 넣습니다.

    ```
    MinPrice
    ```

    ```
    최소금액
    ```

    ```
    50000000
    ```

4. **제출**을 두 번 클릭합니다. **ID** 와 **제목**에 아래를 차례로 넣습니다.

    ```
    Save
    ```

    ```
    확인
    ```

5. **제출**을 하나 더 두 번 클릭합니다. **ID** 와 **제목**에 아래를 차례로 넣고 **제공된 입력 무시**를 켭니다.

    ```
    Cancel
    ```

    ```
    취소
    ```

    **완료 기준**: 아래 미리 보기에 입력칸 둘과 단추 둘이 보인다.

6. 디자이너를 저장하고 닫습니다. 작업 대화 상자에서 **저장**을 누릅니다.
7. 작업 검색 칸에 `if` 를 입력하고 **조건** 아래 **If**를 맨 아래로 끌어다 놓습니다. **첫 번째 피연산자**와 **두 번째 피연산자**에 아래를 넣고 **저장**을 누릅니다. **연산자**는 **같음 (=)** 그대로 둡니다.

    ```
    %ButtonPressed%
    ```

    ```
    Save
    ```

8. **메시지 표시**를 **If** 와 **End** 사이로 끌어다 놓습니다. **표시할 메시지**에 아래를 넣습니다. **변수 생성됨**을 펼쳐 `ButtonPressed` 로 시작하는 변수의 토글을 끄고 **저장**을 누릅니다.

    ```
    %CustomFormData['Keyword']% · %CustomFormData['MinPrice']%
    ```

9. 도구 모음의 **실행**(▶)을 누릅니다. 양식의 **키워드**에 `교육` 을 넣고 **확인**을 누릅니다.

    **완료 기준**: 메시지에 `교육 · 50000000` 이 보인다. 변수 창의 `ButtonPressed` 가 `Save` 다.

10. 메시지 창을 닫고 다시 **실행**(▶)을 누릅니다. 양식에서 **취소**를 누릅니다.

    **완료 기준**: 메시지 없이 실행이 끝나고, 변수 창의 `ButtonPressed` 가 `Cancel` 이다.
