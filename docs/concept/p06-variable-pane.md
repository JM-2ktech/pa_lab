## 창의 구성

오른쪽 세로 막대의 **{x}** 로 열고 닫습니다. 흐름의 입력 · 출력 변수와 흐름에서 쓰는 모든 변수를 보여 줍니다.[^manage]

| 구분 | 이름 | 담는 것 |
|---|---|---|
| 탭 | 전역 | 전역 하위 흐름에서 만든 변수. 흐름 전체에서 사용 |
| 탭 | 로컬 | 로컬 하위 흐름에서 만든 변수. 그 하위 흐름에서만 사용 |
| 묶음 | 입력 | 흐름 밖에서 받는 값 |
| 묶음 | 출력 | 흐름 밖으로 내보내는 값 |
| 묶음 | 흐름 | 흐름 안의 변수 |

**Main** 은 항상 전역입니다. 로컬 하위 흐름에서 전역 변수를 부르면 이름 앞에 `global.` 이 붙습니다. 범위 변수는 Power Fx 흐름에서 지원하지 않습니다.[^scoped]

## 창에서 하는 일

| 조작 | 방법 |
|---|---|
| 값 보기 | 실행 뒤 이름 옆의 값 · 두 번 클릭 |
| 값 지우기 | 창의 지우개 아이콘. 표시된 현재 값을 모두 지움 |
| 찾기 | 창의 검색 칸 |
| 이름 바꾸기 | 두 번 클릭 후 변수 이름 수정 · 오른쪽 단추 메뉴 |
| 쓰인 곳 찾기 | 오른쪽 단추 메뉴 |
| 민감으로 표시 | 오른쪽 단추 메뉴 · 변수 옆 아이콘 |
| 고정 · 유형별 필터 | 창의 메뉴. 고정한 변수에 필터를 적용할지 선택 |
| 입력 · 출력 변수 만들기 | 창 위쪽 + |

## 값 보기

실행하면 변수마다 이름 옆에 현재 값이 보입니다.[^manage]

| 화면 | 뜻 |
|---|---|
| 이름 앞 `#` | 숫자 값 |
| 이름 앞 {x} | 실행 전이어서 형식이 정해지지 않음 |
| `16개 행, 8 열` | 데이터 테이블의 크기 |

자세히 보려면 두 번 클릭합니다. 일부 자료형은 마우스를 올려도 보입니다. **흐름 변수 편집** 창이 열리면 변수 값 오른쪽의 보기 단추로 표 내용을 엽니다. 이때 열리는 변수 값 창에서 행 번호(#)는 0 부터 셉니다.

| 조건 | 동작 |
|---|---|
| 끈 작업이 만드는 변수 | 변수 창에서 빠짐 |
| 안에 다른 개체를 가진 사용자 지정 개체 | 자세히로 들어가고, 창 위쪽 화살표로 돌아옴 |
| 여러 줄이 든 데이터 테이블 · 데이터 행 칸 | 첫 줄만 표시. 해결 방법 없음[^types] |

## 흐름 변수 편집 창

| 칸 | 내용 |
|---|---|
| 변수 이름 | 변수 이름. 실행 중에는 읽기 전용 |
| 기본 데이터 형식 | 기본값의 자료형 |
| 기본값 | 기본값으로 실행할 때 쓰는 값 |
| 변수 값 | 현재 값. 실행 중에 고칠 수 있음. 되돌리기 아이콘 · 보기 |
| 민감으로 표시 | 값을 가림 |

저장 단추로 적용하고 취소 단추로 닫습니다.[^manage]

작업을 오른쪽 단추로 눌러 기본값으로 여기에서 실행(`Alt` + `F5`)을 고르면 그 작업부터 변수마다 기본값을 넣어 실행합니다. 앞 작업을 다시 돌리지 않습니다.[^manage]

## 디버깅 중 값 바꾸기

흐름이 멈춰 있는 동안 값을 바꾸고 이어서 실행할 수 있습니다.[^manage] 멈추는 방법은 [P9](p09-debug.html)에서 다룹니다.

| 자료형 | 고치는 방법 | 조건 |
|---|---|---|
| 숫자 값 | 직접 입력 · 입력칸 오른쪽의 증감 단추 | 숫자 외의 값은 넣을 수 없음 |
| 텍스트 값 | 직접 입력 · 줄 바꿈 표시 확인란 | 숫자를 넣어도 텍스트. 숫자만 받는 칸에 넘기면 그 줄에서 예외 |
| 부울 값 | 드롭다운에서 true · false 선택 | — |
| 날짜/시간 | 직접 입력 | 받을 수 없는 값이면 경고 표시 |

---

## 이름 바꾸기와 병합

이름을 바꾸면 흐름 안의 모든 사용처가 함께 바뀝니다. 이미 있는 이름으로 바꾸면 두 변수를 병합할지 묻습니다. 병합하면 흐름 동작이 달라지거나 오류가 날 수 있습니다.[^manage]

---

## 변수 이름 규칙

- 변수 이름에는 글자 · 숫자 · 밑줄(`_`)을 쓰고, 대소문자를 구분하지 않습니다.[^sap]
- 생성 변수의 이름에는 특수 문자 · 공백 · 라틴 문자가 아닌 글자를 쓸 수 없고, 산술 문자로 시작할 수 없다고 문서에 적혀 있습니다.[^actions]
- 실측에서는 한글 이름 `정리완료폴더` 가 저장되고 실행됐습니다.
- 예약 키워드는 변수 · 하위 흐름 · 라벨 · 오류 블록 이름에 쓸 수 없습니다.[^debug]

```
action and block call case default disable else end error exit FALSE
for foreach from function global goto if in input label loop main mod
next no not on or output repeat set step switch then throw times to TRUE
wait while xor yes
```

## 입력 · 출력 변수

창 위쪽 **+** 에서 입력 또는 출력을 고릅니다. 클라우드 흐름과 데스크톱 흐름 사이, 데스크톱 흐름끼리 값을 주고받을 때 씁니다.[^manage] 클라우드 흐름에서 쓰는 방법은 [P24](p24-from-cloud.html)에서 다룹니다.

| 칸 | 내용 | 조건 |
|---|---|---|
| 변수 이름 | 흐름 안의 이름 | 필수 |
| 데이터 유형 | 텍스트 · 숫자 · 부울 · 사용자 지정 개체 · 목록 · 데이터 테이블 · 인스턴스 · 세션 | 필수 |
| 기본값 | 디자이너 · 콘솔에서 실행할 때의 값 | 입력 변수만. 인스턴스 · 세션 유형은 기본값 없음 |
| 데이터 하위 유형 | Browser · Excel · Word · Outlook · Access · Terminal | 인스턴스 · 세션을 고를 때만 |
| 외부 이름 | 클라우드 디자이너와 흐름 입력 창에 보이는 이름 | 필수 |
| 설명 | 흐름을 호출할 때 보이는 설명 | — |
| 민감한 것으로 표시 | 값을 민감으로 처리 | — |
| 선택 사항으로 표시 | 값 없이 호출해도 오류가 나지 않고 Blank 를 받음 | 입력 변수만 |

- 입력 변수는 기본으로 필수이므로 기본값이 있어야 합니다. **선택 사항으로 표시**를 켜면 생략할 수 있습니다.
- 콘솔에서 실행하면 **흐름 입력** 창이 값을 묻습니다.
- 기존 흐름 변수 이름을 고르면 병합을 묻고, 기존 입력 · 출력 변수 이름은 쓸 수 없습니다.

## 민감 변수

값을 변수 창에서 가립니다. 변수 단위로 지정하므로 목록의 항목 하나나 표의 열 하나만 지정할 수는 없습니다. 민감한 값을 다루는 기준은 [P26](p26-sensitive.html)에서 다룹니다.[^manage]

## 샘플

작업은 작업 검색 칸에 이름을 입력해 찾습니다. 흐름 `개념 연습_HGD` 를 씁니다. 없으면 [P2](p02-types.html)의 1·2번으로 만듭니다.

1. 콘솔 흐름 목록에서 `개념 연습_HGD` 의 **편집**을 누릅니다. 디자이너가 이미 열려 있으면 그 창을 씁니다.
2. **Main** 탭의 빈 곳을 한 번 누르고 `Ctrl` + `A` 로 전체를 고른 뒤 `Delete` 키를 누릅니다.
3. 작업 검색 칸에 `변수 설정` 을 입력하고 **변수 설정**을 작업 영역으로 끌어다 놓습니다. **변수** 칸과 **값** 칸에 아래를 차례로 넣고 **저장**을 누릅니다.

    ```
    등급
    ```

    ```
    B
    ```

4. **변수 설정**을 하나 더 놓고 아래를 넣습니다.

    ```
    수량
    ```

    ```
    5
    ```

5. **변수 설정**을 하나 더 놓고 아래를 넣습니다.

    ```
    합계
    ```

    ```
    %수량 * 2%
    ```

6. 작업 검색 칸에 `메시지 표시` 를 입력하고 **메시지 표시**를 맨 아래로 끌어다 놓습니다. **표시할 메시지**에 아래를 넣고 **저장**을 누릅니다.

    ```
    %등급% 등급 · 합계 %합계%
    ```

7. 도구 모음의 **실행**(▶)을 누르고 메시지 창의 **확인**을 누릅니다.

    **완료 기준**: 메시지 창에 `B 등급 · 합계 10` 이 뜬다.

8. 오른쪽 세로 막대의 **{x}** 를 눌러 변수 창을 엽니다.

    **완료 기준**: **흐름** 묶음에 `등급` B · `수량` 5 · `합계` 10 이 보이고 `수량` 과 `합계` 앞에 `#` 이 있다.

9. `합계` 를 두 번 클릭합니다. **흐름 변수 편집** 창을 확인하고 **취소**를 누릅니다.

    **완료 기준**: **변수 이름** `합계` 와 **변수 값** 10 이 보인다.

10. 변수 창의 지우개 아이콘을 누릅니다.

    **완료 기준**: 이름 옆의 값이 사라진다.

11. `수량` 을 두 번 클릭합니다. **변수 이름**을 아래로 바꾸고 **저장**을 누릅니다.

    ```
    개수
    ```

    **완료 기준**: 작업 영역의 2번과 3번 줄에 `개수` 가 보인다.

12. 작업 영역 3번 줄의 번호 왼쪽을 누릅니다.

    **완료 기준**: 줄 번호 왼쪽에 빨간 점이 생긴다.

13. **실행**을 누릅니다.

    **완료 기준**: 3번 줄에서 멈추고 변수 창의 `개수` 가 5 이다.

14. `개수` 를 두 번 클릭합니다. **변수 값**을 아래로 바꾸고 **저장**을 누릅니다.

    ```
    20
    ```

15. **실행**을 눌러 이어서 돌립니다.

    **완료 기준**: 메시지 창에 `B 등급 · 합계 40` 이 뜬다.

16. 메시지 창의 **확인**을 누르고, 3번 줄의 빨간 점을 눌러 지웁니다.
17. 변수 창 위쪽 **+** 를 누르고 **입력**을 고릅니다. **변수 이름**과 **외부 이름**에 아래를 넣습니다. **데이터 유형**은 텍스트로 둡니다.

    ```
    담당자
    ```

18. **기본값**에 아래를 넣고 **저장**을 누릅니다.

    ```
    홍길동
    ```

    **완료 기준**: 변수 창 **입력** 묶음에 `담당자` 가 보인다.

19. 4번 줄을 두 번 클릭해 열고 **표시할 메시지**를 아래로 바꾼 뒤 **저장**을 누릅니다.

    ```
    %담당자% · %등급% 등급 · 합계 %합계%
    ```

20. **실행**을 누르고 메시지 창의 **확인**을 누릅니다.

    **완료 기준**: 메시지 창에 `홍길동 · B 등급 · 합계 10` 이 뜬다. 디자이너 실행에서는 입력 변수의 기본값을 씁니다.

21. **Main** 탭의 줄을 `Ctrl` + `A` 와 `Delete` 키로 모두 지웁니다. 변수 창의 `담당자` 를 마우스 오른쪽 단추로 눌러 **삭제**를 고릅니다.

    **완료 기준**: **입력** 묶음이 비어 있다.
