## JSON의 구조

대부분의 커넥터 작업은 출력을 구문 분석된 JSON으로 돌려줍니다.[^cookbook] 디자이너의 카드도 내부에서는 JSON으로 저장됩니다.[^peek]

| 모양 | 표기 | 예 | 자료형 |
|---|---|---|---|
| 객체 | `{ }` 안에 키와 값의 쌍 | `{"설비명":"공조기-1","결과":"이상"}` | object |
| 배열 | `[ ]` 안에 항목의 나열 | `["주의","이상"]` | array |
| 문자열 | `" "` 로 감싼 글자 | `"이상"` | string |
| 숫자 | 따옴표 없는 수 | `32` · `3.14` | integer · float |
| 부울 | `true` · `false` | `true` | boolean |
| 빈 값 | `null` | `null` | null |

작업의 출력은 이 모양들이 겹친 구조입니다. 표에 있는 행 나열의 본문은 객체이고, 그 안의 `value` 키에 행의 배열이 들어 있으며, 행 하나는 다시 객체입니다.

```
{
  "value": [
    { "점검월": "2026-09", "설비명": "공조기-1", "결과": "정상" },
    { "점검월": "2026-09", "설비명": "공조기-2", "결과": "이상" }
  ]
}
```

---

## 값을 읽는 표기

| 표기 | 읽는 값 | 없을 때 |
|---|---|---|
| `값['키']` | 객체에서 그 키의 값 | 오류 |
| `값?['키']` | 객체에서 그 키의 값 | null |
| `값?[0]` | 배열에서 그 번호의 항목. 첫 항목이 0 | null |
| `값?['a']?['b']?[0]` | 차례로 따라간 값 | 중간이 비면 null |

`?` 는 앞의 값이 비어 있을 때 실패하는 대신 null을 돌려줍니다.[^cookbook] 칸이 비어 있을 수 있는 데이터에서는 `?` 를 씁니다.

## 문자열과 JSON 사이의 변환

| 함수 | 입력 | 출력 | 조건 |
|---|---|---|---|
| `json()` | JSON 모양의 문자열 | 객체 · 배열 | 이미 JSON인 작업 출력에 쓰면 오류 |
| `string()` | 객체 · 배열 | 줄바꿈 없는 JSON 문자열 | 들여쓰기 옵션 없음 |
| `addProperty(객체, '키', 값)` | 객체 · 키 · 값 | 키를 더한 객체 | 키가 이미 있으면 오류 |
| `setProperty(객체, '키', 값)` | 객체 · 키 · 값 | 키의 값을 바꾼 객체 | 키가 없으면 추가 |

식 안에서 문자열을 이어 붙여 JSON을 만들면 값에 따옴표가 들어 있을 때 잘못된 JSON이 됩니다.[^cookbook] 키를 더하거나 바꿀 때는 `addProperty()` · `setProperty()` 를 씁니다.[^functions]

---

## 비어 있는 값 처리

| 함수 | 결과 | 조건 |
|---|---|---|
| `coalesce(값, 기본값)` | 첫 번째로 null이 아닌 값 | 빈 문자열 `''` 은 null이 아니므로 그대로 돌려줌 |
| `empty(값)` | 비어 있으면 true | null과 `''` 에 true. 숫자에 쓰면 오류 |

## 샘플

흐름 `식 연습장_HGD` 를 씁니다. 없으면 [C7](c07-types.html)의 샘플로 만듭니다.

1. `식 연습장_HGD` 의 **편집**을 눌러 디자이너를 엽니다.
2. **작성** 카드를 누릅니다. **입력** 칸을 비우고 ***fx*** 단추를 누릅니다.

    식 편집기에 아래를 붙여넣고 **추가**를 누릅니다.

    ```
    json('{"설비명":"공조기-2","결과":"이상","측정":[{"항목":"온도","값":71},{"항목":"압력","값":3}]}')
    ```

3. **저장**을 누르고 **테스트** › **수동** › **테스트**를 누릅니다. **흐름 실행**을 누르고 **완료**를 누릅니다.
4. 실행 화면에서 **작성** 카드를 누릅니다.

    **완료 기준**: 출력에 입력한 JSON이 객체 모양으로 보인다.

5. 실행 화면 오른쪽 위 **편집**을 눌러 디자이너로 돌아옵니다. **작성** 카드의 식을 아래로 바꿔 2~4번을 되풀이합니다.

    ```
    json('{"설비명":"공조기-2","결과":"이상"}')?['결과']
    ```

    **완료 기준**: 출력이 `이상` 이다.

6. 배열의 항목을 읽는 식으로 바꿔 되풀이합니다.

    ```
    json('{"측정":[{"항목":"온도","값":71},{"항목":"압력","값":3}]}')?['측정']?[1]?['항목']
    ```

    **완료 기준**: 출력이 `압력` 이다.

7. 없는 키를 읽는 식으로 바꿔 되풀이합니다.

    ```
    json('{"결과":"이상"}')?['조치내용']
    ```

    **완료 기준**: 실행이 성공하고 출력이 비어 있다.

8. `?` 를 뺀 식으로 바꿔 되풀이합니다.

    ```
    json('{"결과":"이상"}')['조치내용']
    ```

    **완료 기준**: **작성** 카드가 실패로 표시된다.

## 코드 보기

새 디자이너에서 카드를 고르고 **코드 보기**를 누르면 그 카드의 JSON 정의를 읽을 수 있습니다. 여기서 수정할 수는 없습니다. 동적 콘텐츠가 식으로 어떻게 저장됐는지 확인할 때 씁니다.[^peek]
