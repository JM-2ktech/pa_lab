## UI 요소가 하는 일

UI 요소는 창이나 페이지 안의 구성 요소 하나를 가리키는 정의입니다. 흐름이 이미지 인식이나 절대 좌표 없이 대상을 찾는 데 씁니다.[^ui] UI 요소 하나는 선택기 하나 이상으로 이루어집니다. 선택기는 [P12](p12-selectors.html)에서 다룹니다.

---

## 데스크톱 UI 요소와 웹 UI 요소

UI 요소는 잡은 곳에 따라 두 종류로 나뉩니다.[^ui]

| 구분 | 데스크톱 UI 요소 | 웹 UI 요소 |
|---|---|---|
| 잡는 대상 | Windows 앱, 브라우저의 앱 영역 | 브라우저에 로드된 페이지 |
| 받는 작업 묶음 | UI 자동화 | 브라우저 자동화 |
| 선택기의 뿌리 | `:desktop` | 웹 페이지 |
| 선택기의 특성 | 앱 설계에 따라 다름 | HTML 특성 |
| UI 요소 창의 아이콘 | 데스크톱 아이콘 | 웹 아이콘 |
| 브라우저 확장 | 필요 없음 | 필요함 |
| 캡처 모드 | UIA · MSAA · UIA3 Raw | 없음 |

데스크톱에서 창 안의 구성 요소를 잡으면 UI 요소가 둘 생깁니다. 부모는 창을 가리키고, 자식은 창 안의 구성 요소를 가리킵니다.[^uia] UI 요소 창에는 `Window 'PX-ERP 로그온'` 아래 `Edit '사용자'` 처럼 보입니다. 웹에서 잡으면 `Web Page` 아래 `Input text 'keyword'` 처럼 보입니다.

## 브라우저 창의 두 영역

브라우저 창 하나에 두 영역이 있고, 영역마다 자동화 방식이 다릅니다.[^ui]

| 영역 | 들어 있는 것 | UI 요소 | 작업 묶음 |
|---|---|---|---|
| 앱 영역 | 주소 표시줄 · 탭 | 데스크톱 UI 요소 | UI 자동화 |
| 페이지 영역 | 로드된 페이지 안의 입력칸 · 단추 · 표 | 웹 UI 요소 | 브라우저 자동화 |

UI 자동화 작업의 **UI 요소 추가**로 페이지 안을 잡을 수도 있습니다. 이때 만들어지는 것은 데스크톱 UI 요소이고 UI 자동화 작업에만 쓸 수 있습니다. 웹 UI 요소보다 안정성이 낮고 브라우저 버전 같은 앱 세부 사항의 영향을 받습니다. 문서는 웹 끌어서 놓기가 동작하지 않을 때의 우회 방법으로 이 방식을 듭니다.[^ui]

## 작업 묶음이 받는 것

| 작업 묶음 | 받는 UI 요소 | 인스턴스 칸 | 예 |
|---|---|---|---|
| 브라우저 자동화 | 웹 UI 요소만 | 웹 브라우저 인스턴스 | 웹 페이지의 텍스트 필드 채우기 · 웹 페이지 버튼 누르기 · 웹 페이지가 다음을 포함하는 경우 |
| UI 자동화 | 데스크톱 UI 요소 | 없음 | 창에서 텍스트 필드 채우기 · 창의 버튼 누르기 · 창의 UI 요소 클릭 · 창에서 UI 요소의 세부 정보 가져오기 |

브라우저 자동화 작업의 UI 요소 드롭다운에는 데스크톱 앱에서 잡은 요소가 보이지 않습니다.[^webauto] 작업 검색 결과에는 비슷한 이름의 두 작업이 함께 뜹니다. 묶음 이름을 보고 고릅니다.

| 찾는 말 | 페이지 안을 다룰 때 | 앱 창을 다룰 때 |
|---|---|---|
| `텍스트 필드` | 웹 페이지의 텍스트 필드 채우기 | 창에서 텍스트 필드 채우기 |
| `버튼` | 웹 페이지 버튼 누르기 | 창의 버튼 누르기 |
| `세부 정보` | 웹 페이지 요소의 세부 정보 가져오기 | 창에서 UI 요소의 세부 정보 가져오기 |
| `데이터 추출` | 웹 페이지에서 데이터 추출 | 창에서 데이터 추출 |

UI 자동화 작업은 Power Automate 가 대상 앱과 같거나 높은 권한으로 실행되어야 합니다. 대상 앱이 관리자 권한으로 실행되면 Power Automate 도 관리자로 실행합니다.[^uia]

## 물리 방식과 시뮬레이션

UI 자동화 작업의 다수는 두 방식으로 실행됩니다.[^uia]

| 방식 | 동작 | 켜는 방법 |
|---|---|---|
| 물리 | 마우스와 키보드를 제어. 창을 앞으로 가져옴 | 기본값 |
| 시뮬레이션 | 마우스와 키보드 없이 프로그램으로 실행. 창을 앞으로 가져오지 않음 | 작업 시뮬레이션 켜기 또는 맨 앞으로 가져오기 끄기 |

시뮬레이션은 모든 UI 요소에 적용되지 않습니다. 브라우저 자동화 쪽 동작은 [P13](p13-web-structure.html)에서 다룹니다.

## 데스크톱 캡처 모드

데스크톱 UI 요소를 잡을 때는 UI 요소 선택기 창 오른쪽 위 메뉴에서 모드를 고릅니다. 기본값은 UIA 입니다.[^ui]

| 모드 | 쓰는 경우 |
|---|---|
| UIA | 대부분의 Windows 앱(WPF · WinForms · UWP). 문서의 권장 모드 |
| MSAA | UIA 요소를 내놓지 않는 레거시 앱(VB6 · 클래식 Win32) |
| UIA3 Raw | UIA 로 잡히지 않는 앱(사용자 지정 렌더링 컨트롤 · Electron). 중간 계층까지 드러남 |

기본이 아닌 모드를 켜면 선택기 창에 안내 띠가 뜨고, UI 요소 창에 어느 모드로 잡았는지 표시됩니다. 모드별 쓰임은 [P21](p21-desktop-app.html)에서 다룹니다.

## 잡는 조작

작업 대화 상자의 UI 요소 드롭다운이나 UI 요소 창에서 **UI 요소 추가**를 누르면 선택기 창이 따로 뜹니다. 잡을 구성 요소에 마우스를 올리면 빨간 테두리와 형식 표시(`Input text` · `Button` · `Edit` · `Text`)가 뜹니다. 테두리가 뜬 상태에서 `Ctrl` + 왼쪽 클릭하면 잡힙니다.[^lab]

오른쪽 단추를 누르면 텍스트 값으로 잡는 메뉴가 나옵니다. 잡는 동안 데스크톱 · 웹 아이콘으로 요소 형식도 확인할 수 있습니다.[^ui]

비슷한 이름의 두 창이 있습니다.

| 창 이름 | 하는 일 | 여는 방법 |
|---|---|---|
| UI 요소 선택기 | 화면에서 구성 요소를 잡음 | UI 요소 추가 |
| `"…" UI 요소 의 선택기` | 잡은 요소의 선택기를 고침 | UI 요소 칸의 연필 아이콘 또는 UI 요소 창의 편집 |

## UI 요소 창의 조작

디자이너 오른쪽 세로 막대의 겹친 사각형 아이콘을 누르면 UI 요소 창이 열립니다. 잡은 요소는 모두 **흐름 리포지토리** 탭에 들어갑니다.[^ui] 옆의 컬렉션 탭은 여러 흐름이 함께 쓰는 프리미엄 기능입니다.[^coll]

| 조작 | 위치 | 결과 |
|---|---|---|
| UI 요소 추가 | 창 위쪽 | UI 요소 선택기가 열림 |
| 정렬 | 창 위쪽 | 이름순 정렬 |
| 이름 바꾸기 | 요소를 오른쪽 단추 | 표시 이름 변경 |
| 편집 | 요소를 오른쪽 단추 또는 ⋮ | 선택기 창이 열림 |
| 사용 위치 찾기 | 요소를 오른쪽 단추 | 그 요소를 쓰는 작업 목록. 결과를 두 번 클릭하면 작업 영역에서 강조 |
| 삭제 | 요소를 오른쪽 단추 | 요소 삭제 |
| 사용하지 않는 UI 요소 제거 | 정렬 옆 점 아이콘 | 작업이 쓰지 않는 요소를 모두 제거 |
| UI 요소 검사 | 창의 드롭다운 또는 메뉴 도구 | 화면 전체의 요소 트리와 특성 값을 봄 |

UI 요소 검사 도구는 웹과 데스크톱 요소를 트리로 보여 주고, 고른 요소의 특성과 값을 오른쪽에 표시합니다. 확인란으로 고른 요소를 흐름에 추가할 수도 있습니다.[^inspect]

| 도구에 안 보일 때 | 원인 | 조치 |
|---|---|---|
| 웹 페이지 트리 | 브라우저 창이 최소화됨 | 창을 최소화에서 되돌림 |
| 브라우저 전체 | Power Automate 확장이 없거나 꺼짐 | 확장을 설치하고 켬 |
| 특정 데스크톱 앱 | 앱이 높은 권한으로 실행 중 | Power Automate 를 높은 권한으로 다시 실행 |

## 흔한 실패

| 증상 | 원인 | 고치는 방법 |
|---|---|---|
| 브라우저 작업 드롭다운에 요소가 안 보임 | UI 자동화 작업으로 잡아 데스크톱 요소가 됨 | 브라우저 자동화 작업에서 다시 잡음 |
| 클릭해도 잡히지 않음 | 테두리가 뜨기 전에 누름 | 빨간 테두리를 확인한 뒤 누름 |
| 테두리가 페이지 위에 뜨지 않음 | 브라우저 확장이 없거나 꺼짐 | `edge://extensions/` 에서 켬 |
| 실행해도 입력칸이 비어 있음 | 입력칸 옆 글자(label)를 잡음 | `Input text` 표시가 뜨는 입력칸을 다시 잡음 |
| 표시 이름이 알아보기 어려움 | 빈 칸에서 잡아 내부 이름으로 표시됨 | 이름 바꾸기 |

## 샘플

흐름 `개념 연습_HGD` 를 씁니다. 없으면 [P2](p02-types.html)의 1·2번으로 만듭니다.

1. Power Automate 콘솔에서 `개념 연습_HGD` 의 **편집**을 눌러 디자이너를 엽니다.
2. 작업 영역의 빈 곳을 한 번 누르고 `Ctrl` + `A` 를 누른 뒤 `Delete` 를 눌러 **Main** 의 줄을 지웁니다.
3. Edge 주소창에 아래 주소를 넣고 엽니다. 이 창은 닫지 않습니다.

    ```
    {{ site.url }}{{ site.baseurl }}/practice/bid/
    ```

4. 작업 검색 칸에 `Edge` 를 입력하고 **브라우저 자동화** 아래 **새 Microsoft Edge 시작**을 작업 영역으로 끌어다 놓습니다. **이니셜 URL**에 아래를 넣고 **저장**을 누릅니다.

    ```
    {{ site.url }}{{ site.baseurl }}/practice/bid/
    ```

5. 작업 검색 칸에 `텍스트 필드` 를 입력하고 **브라우저 자동화 › 웹 양식 채우기** 아래 **웹 페이지의 텍스트 필드 채우기**를 1번 줄 아래로 끌어다 놓습니다.
6. **UI 요소** 드롭다운을 열고 **UI 요소 추가**를 누릅니다.
7. 3번의 Edge 창에서 **공고명** 입력칸에 빨간 테두리와 `Input text` 표시가 뜬 상태로 `Ctrl` + 왼쪽 클릭합니다.
8. **텍스트**에 아래를 넣고 **저장**을 누릅니다.

    ```
    교육
    ```

9. 작업 검색 칸에 `텍스트 필드` 를 입력하고 **UI 자동화 › 양식 채우기** 아래 **창에서 텍스트 필드 채우기**를 2번 줄 아래로 끌어다 놓습니다.
10. **텍스트 상자** 드롭다운을 열고 **UI 요소 추가**를 누릅니다.
11. 3번의 Edge 창에서 주소 표시줄에 빨간 테두리가 뜬 상태로 `Ctrl` + 왼쪽 클릭합니다.
12. **채울 텍스트**에 아래를 넣고 **저장**을 누릅니다.

    ```
    edge://version
    ```

13. **창에서 텍스트 필드 채우기**를 3번 줄 아래로 하나 더 놓습니다. **텍스트 상자** 드롭다운에서 **UI 요소 추가**를 누릅니다.
14. 3번의 Edge 창에서 **공고명** 입력칸을 `Ctrl` + 왼쪽 클릭합니다. 같은 입력칸을 UI 자동화 쪽에서 잡습니다.
15. **채울 텍스트**에 아래를 넣고 **저장**을 누릅니다.

    ```
    교육
    ```

16. 디자이너 오른쪽 세로 막대의 겹친 사각형 아이콘을 눌러 UI 요소 창을 엽니다.

    **완료 기준**: `Web Page` 아래에 `Input text 'keyword'` 가 있고, Edge 창 요소 아래에 주소 표시줄과 공고명 입력칸이 있다. 두 묶음의 아이콘이 다르다.

17. Edge 창 요소를 오른쪽 단추로 누르고 **편집**을 고릅니다.

    **완료 기준**: 미리 보기 선택기가 `:desktop` 으로 시작한다.

18. **취소**로 닫습니다. `Input text 'keyword'` 를 오른쪽 단추로 누르고 **편집**을 고릅니다.

    **완료 기준**: 미리 보기 선택기가 `input[Id="keyword"]` 이고 `:desktop` 이 없다.

19. **취소**로 닫습니다. 작업 영역 2번 줄을 두 번 클릭해 열고 **UI 요소** 드롭다운을 엽니다.

    **완료 기준**: `Input text 'keyword'` 만 보이고 주소 표시줄과 데스크톱으로 잡은 입력칸은 보이지 않는다.

20. 대화 상자의 **취소**를 누릅니다. UI 요소 창에서 `Input text 'keyword'` 를 오른쪽 단추로 누르고 **이름 바꾸기**를 고른 뒤 아래를 넣습니다.

    ```
    공고명 입력칸
    ```

    **완료 기준**: 작업 영역 2번 줄의 표시가 `공고명 입력칸` 으로 바뀐다.

21. 같은 요소를 오른쪽 단추로 누르고 **사용 위치 찾기**를 고릅니다. 결과를 두 번 클릭합니다.

    **완료 기준**: 작업 영역의 2번 줄이 강조된다.

22. 작업 영역의 3 · 4번 줄을 지웁니다. UI 요소 창 위쪽 점 아이콘을 누르고 **사용하지 않는 UI 요소 제거**를 고릅니다.

    **완료 기준**: UI 요소 창에 `공고명 입력칸` 만 남는다.
