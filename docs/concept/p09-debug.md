> **다루는 것**: 실행을 멈추고 한 줄씩 돌리며 변수 값을 확인하는 도구
>
> **쓰는 곳**: Lab 4 ③ 25번 **작업 사용 안 함**. 중단점 · 작업별 실행 · 여기에서 실행은 랩에서 쓰지 않음

---

## 실행 제어

| 단추 | 단축키 | 동작 |
|---|---|---|
| 실행 | `F5` | 흐름 실행. 일시 중지 중이면 이어서 실행 |
| 일시 중지 | `Ctrl` + `Pause` | 실행 중에 멈추고 그때까지의 변경 확인. 실행 중에는 실행이 일시 중지로 바뀜 |
| 다음 작업 실행 | `F10` | 작업 하나를 실행하고 멈춤 |
| 중지 | `Shift` + `F5` | 흐름을 완전히 멈춤 |

---

## 중단점

작업 영역에서 줄 번호의 왼쪽을 누르면 빨간 점이 찍힙니다. 흐름은 그 작업에서 멈춥니다. 실행이나 다음 작업 실행으로 이어 가고, 빨간 점을 누르면 지웁니다.[^debug]

---

## 작업별 실행

**다음 작업 실행**은 작업을 하나 실행할 때마다 멈춥니다. 멈춘 상태에서 변수 창을 열어 값을 봅니다.[^debug]

| 순서 | 조작 | 보는 것 |
|---:|---|---|
| 1 | 값이 의심되는 줄에 중단점 | — |
| 2 | 실행 | 그 줄에 도달했을 때의 변수 값 |
| 3 | 다음 작업 실행 | 한 줄 실행한 뒤 달라진 값 |
| 4 | 3번 반복 | 값이 처음 어긋나는 줄 |
| 5 | 중지 후 그 줄 수정 | 다시 실행한 결과 |

멈춘 상태에서 값을 바꿔 보는 방법은 [P6](p06-variable-pane.html)에서 다룹니다.

---

## 단계 모드

디자이너 **디버그** 메뉴의 Stepping Mode 토글을 켜면 명령 둘이 더 생깁니다. 흐름이 실행 중이 아니거나 멈춰 있을 때만 씁니다.[^debug]

| 명령 | 단축키 | 동작 |
|---|---|---|
| Step over | `F11` | 작업 하나를 실행하고 다음 작업에서 멈춤. 하위 흐름 실행 앞에서 쓰면 그 하위 흐름 전체를 실행하고 다음 작업에서 멈춤 |
| Step out | `Shift` + `F11` | 실행 중인 하위 흐름을 끝내고 호출한 곳의 다음에서 멈춤. Main 에서 쓰면 실행과 같음 |

흐름이 멈추는 경우는 일시 중지 · **다음 작업 실행** · 중단점 도달 · Step over · 하위 흐름 안에서의 Step out 입니다.

---

## 여기에서 실행

작업을 마우스 오른쪽 단추로 눌러 **여기에서 실행**을 고르면 앞 작업을 모두 무시하고 그 작업부터 실행합니다.[^debug]

| 조건 | 내용 |
|---|---|
| 쓸 수 없는 작업 | 반복 · 조건 · 블록 오류 시 안에 있는 작업[^workspace] |
| 기본값을 넣어 실행 | 기본값으로 여기에서 실행(`Alt` + `F5`)[^manage] |

---

## 실행 지연과 상태 표시줄

창 아래 상태 표시줄의 항목입니다.[^debug]

| 항목 | 내용 |
|---|---|
| 흐름 상태 | 실행 상태 |
| 선택 · 전체 수 | 선택한 작업 수, 전체 작업과 하위 흐름 수 |
| 실행 지연 | 디자이너에서 작업마다 실행 뒤 기다리는 시간(밀리초). 값을 바꿀 수 있음 |
| 오류 | 오류 수. 누르면 오류 창이 열림 |
| 검색 결과 수 | 흐름 안을 검색했을 때 표시. 누르면 코드에서 찾기 창이 열림 |

## 오류 창

| 열 | 내용 |
|---|---|
| 형식 | 오류 · 경고 |
| 설명 | 내용 |
| 하위 흐름 | 해당 작업이 든 하위 흐름 |
| 줄 | 해당 작업의 줄 번호 |

항목을 두 번 클릭하면 위치와 메시지를 자세히 봅니다. 위쪽 필터로 오류 · 경고 · 하위 흐름을 고릅니다. 오류의 종류와 처리는 [P18](p18-errors.html)에서 다룹니다.[^errors]

---

## 작업을 끄고 시험하기

작업을 지우지 않고 **작업 사용 안 함**으로 끄면 실행할 때 건너뜁니다. 흐름의 다른 구성을 시험할 때 씁니다. 끈 작업이 만드는 변수를 다른 작업이 쓰면 오류로 표시될 수 있습니다.[^actions]

## 샘플

합계가 틀리게 나오는 흐름을 만들어 중단점과 작업별 실행으로 값을 따라가 고칩니다. 작업은 작업 검색 칸에 이름을 입력해 찾습니다. 흐름 `개념 연습_HGD` 를 씁니다. 없으면 [P2](p02-types.html)의 1·2번으로 만듭니다.

1. 콘솔 흐름 목록에서 `개념 연습_HGD` 의 **편집**을 누릅니다. 디자이너가 이미 열려 있으면 그 창을 씁니다.
2. **Main** 탭의 빈 곳을 한 번 누르고 `Ctrl` + `A` 로 전체를 고른 뒤 `Delete` 키를 누릅니다.
3. 작업 검색 칸에 `새 목록` 을 입력하고 **새 목록 만들기**를 작업 영역으로 끌어다 놓고 **저장**을 누릅니다. 결과는 **변수 생성됨**의 `List` 에 담깁니다.
4. 작업 검색 칸에 `목록에 항목` 을 입력하고 **목록에 항목 추가**를 놓습니다. **항목 추가**에 아래를 넣고, **목록으로**가 `%List%` 인지 확인하고 **저장**을 누릅니다.

    ```
    %'1000'%
    ```

5. **목록에 항목 추가**를 하나 더 놓아 아래를 넣습니다.

    ```
    %'2000'%
    ```

6. **목록에 항목 추가**를 하나 더 놓아 아래를 넣습니다.

    ```
    %'3000'%
    ```

7. 작업 검색 칸에 `변수 설정` 을 입력하고 **변수 설정**을 맨 아래로 끌어다 놓습니다. **변수** 칸과 **값** 칸에 아래를 차례로 넣고 **저장**을 누릅니다.

    ```
    합계
    ```

    ```
    0
    ```

8. 작업 검색 칸에 `각각의` 를 입력하고 **각각의 경우**를 맨 아래로 끌어다 놓습니다. **반복할 값**에 아래를 넣고 **저장**을 누릅니다. **저장 위치**는 `CurrentItem` 그대로 둡니다.

    ```
    %List%
    ```

9. **변수 설정**을 **각각의 경우**와 **End** 사이로 끌어다 놓고 아래를 넣습니다.

    ```
    합계
    ```

    ```
    %합계 + CurrentItem%
    ```

10. **메시지 표시**를 맨 아래로 끌어다 놓습니다. **표시할 메시지**에 아래를 넣고 **저장**을 누릅니다.

    ```
    합계: %합계%
    ```

11. 작업 영역을 아래와 대조합니다.

    ```
    1  새 목록 만들기 → List
    2  목록에 항목 추가: %'1000'%
    3  목록에 항목 추가: %'2000'%
    4  목록에 항목 추가: %'3000'%
    5  변수 설정: 합계 = 0
    6  각각의 경우 CurrentItem in %List%
    7      변수 설정: 합계 = %합계 + CurrentItem%
    8  End
    9  메시지 표시: 합계: %합계%
    ```

12. 도구 모음의 **실행**(▶)을 누릅니다. 메시지 창의 값을 확인하고 **확인**을 누릅니다.

    **완료 기준**: 메시지 창에 6000 대신 `합계: 0100020003000` 이 뜬다.

13. 7번 줄의 번호 왼쪽을 누릅니다.

    **완료 기준**: 줄 번호 왼쪽에 빨간 점이 생긴다.

14. **실행**을 누릅니다. 오른쪽 세로 막대의 **{x}** 를 눌러 변수 창을 엽니다.

    **완료 기준**: 7번 줄에서 멈춰 있고, `합계` 는 0, `CurrentItem` 은 1000 이다.

15. 변수 창에서 두 변수의 이름 앞 표시를 비교합니다.

    **완료 기준**: `합계` 앞에는 `#` 이 있고 `CurrentItem` 앞에는 없다.

16. 도구 모음의 **다음 작업 실행**을 누릅니다.

    **완료 기준**: 7번 줄이 실행되어 `합계` 가 `01000` 이 된다.

17. **실행**을 누릅니다.

    **완료 기준**: 7번 줄에서 다시 멈추고 `CurrentItem` 이 2000 이다.

18. **다음 작업 실행**을 누릅니다.

    **완료 기준**: `합계` 가 `010002000` 이 된다. 숫자와 텍스트를 `+` 로 묶으면 이어 붙입니다.[^manip]

19. 도구 모음의 **중지**를 누릅니다.
20. 7번 줄의 빨간 점을 눌러 지웁니다.
21. 작업 검색 칸에 `텍스트를` 을 입력하고 **텍스트를 숫자로 변환**을 6번 줄과 7번 줄 사이로 끌어다 놓습니다. **변환할 텍스트**에 아래를 넣고 **저장**을 누릅니다. 결과는 **변수 생성됨**의 `TextAsNumber` 에 담깁니다.

    ```
    %CurrentItem%
    ```

22. 8번 줄이 된 **변수 설정**을 두 번 클릭해 열고, **값**을 아래로 바꾼 뒤 **저장**을 누릅니다.

    ```
    %합계 + TextAsNumber%
    ```

23. 8번 줄의 번호 왼쪽을 누릅니다.
24. **실행**을 누릅니다.

    **완료 기준**: 8번 줄에서 멈추고 `TextAsNumber` 앞에 `#` 이 있다.

25. **다음 작업 실행**을 누릅니다.

    **완료 기준**: `합계` 가 1000 이 된다.

26. 8번 줄의 빨간 점을 눌러 지웁니다.
27. **실행**을 눌러 이어서 돌립니다.

    **완료 기준**: 메시지 창에 `합계: 6000` 이 뜬다. **확인**을 누릅니다.

28. 8번 줄을 마우스 오른쪽 단추로 누릅니다. 메뉴를 확인하고 `Esc` 키로 닫습니다.

    **완료 기준**: 각각의 경우 안의 작업이어서 **여기에서 실행**을 쓸 수 없다.

29. 10번 줄 **메시지 표시**를 마우스 오른쪽 단추로 눌러 **여기에서 실행**을 고릅니다.

    **완료 기준**: 1~9번 줄을 실행하지 않고 메시지 창이 뜬다. **확인**을 누릅니다.
