## 키 보내기 작업

| 칸 | 값 | 기본값 |
|---|---|---|
| 키 보내기 | 전경 창 · UI 요소 · 창 인스턴스/핸들 · 제목 및/또는 클래스 | 전경 창 |
| 보낼 텍스트 | 텍스트 · 변수 · 식 또는 직접 암호화 입력 | — |
| 키 입력 간의 지연 | 키 사이 간격(밀리초). 입력 오류를 막음 | 10 |
| 하드웨어 키로 텍스트 보내기 | 켜면 전체 텍스트를 실제 키 입력처럼 보냄 | 끔 |

**보낼 텍스트** 아래 특수 키 삽입과 수정자 삽입을 누르면 화살표 키 · Caps Lock 같은 특수 키와 Shift · Control 같은 수정자를 고를 수 있습니다.[^keys]

## 표기

| 쓰려는 것 | 표기 | 예 |
|---|---|---|
| 글자 그대로 | 표기 없이 입력 | `INTERN01` |
| 키 한 번 | 키 이름을 중괄호로 감쌈 | `{Enter}` |
| 같은 키 여러 번 | `{키:횟수}` | `{Tab:3}` |
| 수정자 + 키 | 수정자를 중괄호로 감싸고 함께 누를 키를 괄호로 묶음. 두 키 모두 중괄호 | `{Control}({B})` |
| 조합 두 번 | 이어서 씀 | `{Control}({A}){Control}({C})` |
| 글자와 키 섞기 | 이어서 씀 | `line1{Enter}line2` |
| 변수 값 | `%` 표기 | `%요청['거래처']%{Tab}` |

중괄호 표기는 물리적으로 키를 누르는 동작을 흉내 냅니다.[^shortcut] 괄호 안의 키는 수정자와 동시에 눌립니다.[^shortcut]

## 키가 가는 창

기본값 **전경 창**은 그때 활성 상태인 앱으로 키를 보냅니다.[^keys] 다른 창이 앞에 있으면 키가 그 창으로 갑니다.

| 대상 | 정하는 것 | 앞에 있는 창과의 관계 |
|---|---|---|
| 전경 창 | 없음 | 앞에 있는 창이 받음. 앞서 **창 포커스**로 대상을 올림 |
| UI 요소 | 창 안의 요소 | 그 요소로 보냄 |
| 창 인스턴스/핸들 | 창 인스턴스 또는 `WindowHandle` | 그 창으로 보냄 |
| 제목 및/또는 클래스 | 창 제목 · 창 클래스 | 그 창으로 보냄 |

전경 창으로 보낼 때는 앞에 **창 포커스**를 놓고, 창 안의 특정 요소가 필요하면 창의 UI 요소 클릭 작업으로 먼저 고릅니다.[^shortcut]

## 창 포커스

**창 포커스** 작업은 지정한 창을 활성화하고 전경으로 가져옵니다.[^uia] 문서에 따라 「창 초점」으로도 적습니다.

| 칸 | 값 | 조건 |
|---|---|---|
| 창 찾기 모드 | 창 UI 요소별 · 창 인스턴스별/핸들별 · 제목별 및/또는 클래스별 | 기본은 창 UI 요소별 |
| 창 | UI 요소 | 창 UI 요소별일 때 |
| 창 인스턴스 | 창 인스턴스 또는 핸들 | 창 인스턴스별/핸들별일 때 |
| 창 제목 | 제목. 와일드카드 `?` · `*` 사용 | 제목별일 때 |
| 창 클래스 | 창 클래스 | 제목이 같은 창이 둘일 때 구별 |

앱에 따라 **창 포커스**가 창을 앞으로 가져오지 못할 수 있습니다. 확인은 키 보내기 작업으로 키를 보내 봅니다. 키 입력이 예상대로 들어가지 않으면 포커스가 오지 않은 것입니다.[^focus]

**창 포커스** 뒤에 창을 한 번 클릭하면 포커스를 확실히 옮길 수 있습니다. 클릭에 쓰는 작업은 넷입니다.[^focus]

| 작업 | 설정 |
|---|---|
| 창의 UI 요소 클릭 | — |
| 이미지로 마우스 이동 | **마우스를 옮긴 후 클릭 보내기** 켬 |
| 마우스 클릭 보내기 | — |
| 화면에서 텍스트로 마우스 이동(OCR) | **마우스를 옮긴 후 클릭 보내기** 켬 |

창의 포커스를 조건으로 쓰는 작업도 있습니다.[^uia]

| 작업 | 설정 |
|---|---|
| 창인 경우 | 포커스됨 · 포커스되지 않음으로 분기 |
| 창 대기 | 포커스를 얻을 때까지 · 잃을 때까지 대기 |
| 창 대기 | 창이 열린 뒤 전경으로 가져오는 옵션 |

창 핸들은 창을 구별하는 번호입니다. **응용 프로그램 실행**의 응용 프로그램 시작 후 칸을 응용 프로그램 로드 대기로 두면 `WindowHandle` 에 담깁니다. 제목과 클래스가 같은 창을 구별할 때 씁니다.[^handle]

## 실패하는 조건과 함께 쓰는 작업

| 키 보내기 예외 | 조건 |
|---|---|
| 대화형이 아닌 모드에서 키 입력을 보낼 수 없음 | 비대화형 실행 |
| 보낼 텍스트가 유효한 키 입력을 나타내지 않음 | 키 이름 · 표기 오류 |
| 키 입력을 보낼 활성 응용 프로그램이 없음 | 전경에 앱이 없음 |
| 키 입력을 보내지 못함 | 그 밖의 전송 실패 |

관리자 권한으로 도는 앱에 키를 보내려면 Power Automate 도 관리자 권한으로 실행합니다.[^keys]

| 같은 묶음의 작업 | 하는 일 |
|---|---|
| 입력 차단 | 실행 중 사용자의 마우스 · 키보드 입력 차단. 관리자 권한 필요 |
| 키 누르기 또는 해제하기 | Ctrl · Alt · Shift · Win 키를 누른 채로 두거나 뗌 |
| 키 상태 설정 | Caps Lock · Num Lock · Scroll Lock 켬 · 끔 |
| 마우스 클릭 보내기 | 클릭 이벤트 전송 |
| 바로 가기 키 대기 | 지정한 키를 누를 때까지 흐름을 멈춤 |
| 키보드 식별자 가져오기 | 활성 키보드 식별자를 읽음 |

## 샘플

흐름 `개념 연습_HGD` 를 씁니다. 없으면 [P2](p02-types.html)의 1·2번으로 만듭니다. 실행 중에는 마우스와 키보드를 쓰지 않습니다. 실행할 때마다 메모장과 계산기가 새로 열리므로 확인한 창은 저장하지 않고 닫습니다.

1. **Main** 탭의 빈 곳을 한 번 누르고 `Ctrl` + `A` 를 누른 뒤 `Delete` 를 눌러 줄을 지웁니다.
2. 작업 검색 칸에 `응용 프로그램` 을 입력하고 **시스템** 아래 **응용 프로그램 실행**을 작업 영역으로 끌어다 놓습니다. **응용 프로그램 경로**에 아래를 넣습니다. **응용 프로그램 시작 후**를 **응용 프로그램 로드 대기**로 바꾸고 **저장**을 누릅니다.

    ```
    notepad
    ```

3. 작업 검색 칸에 `창 포커스` 를 입력합니다. 결과가 없으면 `창 초점` 을 입력합니다. **UI 자동화** 아래 작업을 1번 줄 아래로 끌어다 놓습니다. 창을 찾는 방법을 제목으로 찾는 항목으로 바꾸고 **창 제목**에 아래를 넣은 뒤 **저장**을 누릅니다. Windows 표시 언어가 영어면 `*Notepad*` 를 넣습니다.

    ```
    *메모장*
    ```

4. 작업 검색 칸에 `키 보내기` 를 입력하고 **마우스 및 키보드** 아래 **키 보내기**를 2번 줄 아래로 끌어다 놓습니다. **보낼 텍스트**에 아래를 넣고 **저장**을 누릅니다.

    ```
    line1{Enter}line2{Enter}
    ```

5. 도구 모음의 **실행**(▶)을 누릅니다.

    **완료 기준**: 메모장에 `line1` · `line2` 두 줄이 있다.

6. **키 보내기**를 맨 아래로 하나 더 놓습니다. **보낼 텍스트**에 아래를 넣고 **저장**을 누른 뒤 **실행**합니다.

    ```
    {Control}({A})
    ```

    **완료 기준**: 메모장의 글자 전체가 선택되어 있다.

7. **키 보내기**를 맨 아래로 하나 더 놓습니다. **보낼 텍스트**에 아래를 넣고 **저장**을 누른 뒤 **실행**합니다.

    ```
    {Delete}
    ```

    **완료 기준**: 메모장이 비어 있다.

8. **키 보내기**를 맨 아래로 하나 더 놓습니다. **보낼 텍스트**에 아래를 넣고 **저장**을 누른 뒤 **실행**합니다.

    ```
    {Enter:3}end
    ```

    **완료 기준**: 빈 줄 세 개 아래에 `end` 가 있다.

9. **응용 프로그램 실행**을 맨 아래로 끌어다 놓습니다. **응용 프로그램 경로**에 아래를 넣습니다. **응용 프로그램 시작 후**는 그대로 두고 **저장**을 누릅니다.

    ```
    calc
    ```

10. 작업 검색 칸에 `대기` 를 입력하고 **흐름 제어** 아래 **대기**를 맨 아래로 끌어다 놓습니다. 초 칸에 아래를 넣고 **저장**을 누릅니다.

    ```
    3
    ```

11. **키 보내기**를 맨 아래로 끌어다 놓습니다. **키 보내기**는 **전경 창** 그대로 두고, **보낼 텍스트**에 아래를 넣은 뒤 **저장**을 누릅니다. **실행**합니다.

    ```
    123
    ```

    **완료 기준**: 계산기 표시가 `123` 이고, 메모장의 글자는 `end` 그대로다.

12. 2번 줄을 누르고 `Ctrl` + `C` 를 누릅니다. 맨 아래 줄을 누르고 `Ctrl` + `V` 를 누릅니다. 같은 창 포커스 작업이 맨 아래에 생깁니다.
13. **키 보내기**를 맨 아래로 끌어다 놓습니다. **보낼 텍스트**에 아래를 넣고 **저장**을 누른 뒤 **실행**합니다.

    ```
    456
    ```

    **완료 기준**: 메모장의 끝 글자가 `end456` 이고, 계산기 표시는 `123` 그대로다.

14. 11번에서 놓은 **키 보내기**를 두 번 클릭해 엽니다. 맨 위 **키 보내기**를 제목으로 찾는 항목으로 바꾸고, 창 제목 칸에 아래를 넣은 뒤 **저장**을 누릅니다. **실행**합니다.

    ```
    *메모장*
    ```

    **완료 기준**: 계산기가 앞에 있었는데도 `123` 이 메모장에 들어가 끝 글자가 `end123456` 이고, 계산기 표시는 `0` 이다.

15. 메모장과 계산기를 저장하지 않고 닫습니다.
