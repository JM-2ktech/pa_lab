## Excel 매크로

**Excel 매크로 실행**은 열려 있는 Excel 인스턴스에서 매크로를 실행합니다. Excel 시작으로 매크로가 든 파일을 연 뒤 이 작업을 놓습니다.[^macro]

| 칸 | 값 |
|---|---|
| Excel 인스턴스 | Excel 시작이 만든 변수 |
| 매크로 | 매크로 이름. 인수가 있으면 세미콜론으로 이어 적음 |

```
매크로이름;인수1;인수2
```

매크로 이름은 아래에서 찾습니다.[^macro][^excel]

| 찾는 대상 | 경로 |
|---|---|
| 통합 문서의 매크로 | Excel 의 **개발자** › **매크로** |
| 단추에 연결된 매크로 | 단추를 마우스 오른쪽 단추로 눌러 **매크로 할당** |

개인 매크로 통합 문서 `PERSONAL.XLSB` 의 매크로를 쓰려면 Excel 시작의 고급 옵션에서 두 항목을 켭니다.[^macro]

| 고급 옵션 | 값 |
|---|---|
| 새 Excel 프로세스에서 중첩 | 켬 |
| 추가 기능 및 매크로 로드 | 켬 |

실행에 실패하면 `Failed to run macro` 예외가 납니다.[^excel]

## CSV를 Excel로 변환

CSV 는 지정한 문자로 값을 나눈 텍스트 파일입니다. 구분 문자에 따라 쓰는 작업이 다릅니다.[^csv]

| 구분 문자 | 여는 작업 | 조건 |
|---|---|---|
| 쉼표 · 탭 | Excel 시작으로 바로 열기 | Excel 은 Windows 지역 설정의 목록 구분 기호를 씀 |
| 세미콜론 | CSV 파일에서 읽기 | 고급의 **사용자 지정 구분 기호**에 `;` 를 넣음 |

| 경로 | 순서 |
|---|---|
| ① Excel 로 열기 | Excel 시작으로 CSV 열기 → 값 읽기 → Excel 시작으로 빈 문서 열기 → Excel 워크시트에 쓰기 A1 → Excel 닫기로 `.xlsx` 저장 |
| ② CSV 파일에서 읽기 | CSV 파일에서 읽기 → Excel 시작으로 빈 문서 열기 → Excel 워크시트에 쓰기 A1 → Excel 닫기로 `.xlsx` 저장 |

## CSV 작업의 칸

| 칸 | 기본값 | 내용 |
|---|---|---|
| 파일 경로 | — | 파일 경로 또는 파일 · 경로가 든 변수 |
| 인코딩 | UTF-8 | UTF-8 · 유니코드 · 시스템 기본값 · ASCII 등 |
| 필드 자르기 | 켬 | 셀 앞뒤 공백 제거 |
| 첫 번째 줄에 열 이름 포함 | 끔 | 켜면 첫 줄이 데이터 테이블의 열 이름이 됨 |
| 열 구분 기호 | 미리 정의됨 | 미리 정의됨 · 사용자 지정 · 고정 열 너비 |
| 구분 기호 | 시스템 기본값 | 시스템 기본값 · 쉼표 · 세미콜론 · 탭 |

위 칸은 CSV 파일에서 읽기의 칸이고, 결과는 `CSVTable` 데이터 테이블입니다.[^file]

| 칸 | 기본값 | 내용 |
|---|---|---|
| 쓸 변수 | — | 데이터 테이블 · 데이터 행 · 목록 |
| 인코딩 | UTF-8 | 읽기와 같은 목록 |
| 열 이름 포함 | 끔 | 켜면 첫 행에 열 이름. 파일이 없거나 비어 있을 때만 적용 |
| 파일이 있는 경우 | 기존 내용 덮어쓰기 | 기존 내용 덮어쓰기 · 콘텐츠 추가 |
| 구분 기호 | 시스템 기본값 | 시스템 기본값 · 쉼표 · 세미콜론 · 탭 또는 사용자 지정 |

위 칸은 CSV 파일에 쓰기의 칸입니다.[^file]

**파일에 텍스트 쓰기의 인코딩 기본값은 유니코드입니다.** 이 작업으로 만든 CSV 를 CSV 파일에서 읽기로 읽으면 기본값이 서로 다르므로 인코딩을 맞춥니다.[^file]

변수에 든 CSV 글자는 변수 묶음의 CSV 텍스트 변수에서 읽기로 읽습니다. 결과는 같은 `CSVTable` 입니다.[^vars]

## 데스크톱 흐름 실행

**데스크톱 흐름 실행**은 실행 중인 흐름에서 다른 데스크톱 흐름을 호출합니다. 복잡한 흐름을 작은 흐름으로 나누거나, 특정 오류를 다룰 흐름을 따로 둘 때 씁니다.[^run-howto][^runflow]

| 항목 | 내용 |
|---|---|
| 입력 변수 | 호출하는 흐름에 입력 변수가 있으면 작업에서 값을 넣음 |
| 출력 변수 | 작업의 변수로 생성됨. 설계 중에는 일반 값으로 표시되고 실행할 때 형식이 정해짐 |
| 인스턴스 출력 | 인스턴스 칸 목록에 자동으로 나오지 않음. 직접 입력하거나 붙여넣음 |
| 세션 | 호출한 흐름과 같은 Windows 세션에서 실행 |
| 환경 | 조직 테넌트에서는 같은 환경의 흐름 |
| 종속성 | 다른 흐름 150개까지. 없는 흐름이 있거나 넘으면 실행되지 않음 |
| 재귀 | 두 흐름이 직간접으로 서로 호출할 수 없음 |
| 흐름 열기 | 작업의 메뉴에서 **흐름 이동**을 고르면 호출 대상의 디자이너가 열림 |
| 예외 | 데스크톱 흐름 실행 실패 · 데스크톱 흐름 시간 초과됨 |

## 병렬 실행

**흐름이 완료될 때까지 대기**의 기본값은 켜짐입니다. 끄면 호출한 흐름과 함께 실행합니다. 대상 앱의 예기치 않은 팝업이 부모 흐름을 멈추는 경우에 자식 흐름으로 팝업을 감시하는 용도입니다.[^runflow][^run-howto]

| 항목 | 대기 켬 | 대기 끔 |
|---|---|---|
| 부모 흐름 | 끝날 때까지 일시 중지 | 함께 실행 |
| 출력 변수 | 받음 | 무시됨 |
| 개수 | — | 루트 흐름과 함께 최대 6개 |
| 자식의 자식 | — | 병렬 실행 가능. 같은 6개 안에서 셈 |
| 부모가 끝날 때 | — | 실행 중인 병렬 자식도 취소. 자식의 실행 로그가 일부 또는 전부 없을 수 있음 |

같은 흐름 안의 묶음은 [P19](p19-subflows.html)의 하위 흐름으로 다룹니다.

## 샘플

흐름 `개념 연습_HGD` 를 씁니다. 없으면 [P2](p02-types.html)의 1·2번으로 만듭니다. Main 의 줄을 지우고 쌓습니다. 실습 자료 `C:\PA실습` 이 있어야 합니다.

1. 작업 검색 칸에 `변수 설정` 을 입력하고 **변수 설정**을 작업 영역으로 끌어다 놓습니다. **변수** 칸과 **값** 칸에 아래를 차례로 넣고 **저장**을 누릅니다.

    ```
    건수표
    ```

    ```
    %{^['키워드', '건수'], ['교육', '16'], ['클라우드', '6'], ['자동화', '6']}%
    ```

2. 작업 검색 칸에 `CSV 파일에 쓰기` 를 입력하고 **CSV 파일에 쓰기**를 맨 아래로 끌어다 놓습니다. **쓸 변수**와 **파일 경로**에 아래를 차례로 넣습니다. **열 이름 포함**을 켜고 **저장**을 누릅니다.

    ```
    %건수표%
    ```

    ```
    C:\PA실습\결과\건수.csv
    ```

3. **실행**(▶)을 누릅니다. `C:\PA실습\결과\건수.csv` 가 이미 있으면 먼저 지웁니다. 열 이름은 파일이 없거나 비어 있을 때만 쓰입니다.

    **완료 기준**: `건수.csv` 를 메모장으로 열면 첫 줄이 키워드와 건수다.

4. 2번 줄을 마우스 오른쪽 단추로 눌러 **작업 사용 안 함**을 고릅니다.
5. 작업 검색 칸에 `CSV 파일에서 읽기` 를 입력하고 **CSV 파일에서 읽기**를 맨 아래로 끌어다 놓습니다. **파일 경로**에 아래를 넣습니다. 고급에서 **첫 번째 줄에 열 이름 포함**을 켜고 **저장**을 누릅니다.

    ```
    C:\PA실습\결과\건수.csv
    ```

6. 작업 검색 칸에 `Excel 시작` 을 입력하고 **Excel 시작**을 맨 아래로 끌어다 놓습니다. **빈 문서** 그대로 두고 **저장**을 누릅니다.
7. **Excel 워크시트에 쓰기**를 맨 아래로 끌어다 놓습니다. **쓸 값** · **열** · **행**에 아래를 차례로 넣고 **저장**을 누릅니다.

    ```
    %CSVTable%
    ```

    ```
    A
    ```

    ```
    1
    ```

8. **Excel 닫기**를 맨 아래로 끌어다 놓습니다. **Excel을 닫기 전**을 **다음 형식으로 문서 저장**으로 바꾸고 **문서 경로**에 아래를 넣은 뒤 **저장**을 누릅니다.

    ```
    C:\PA실습\결과\건수.xlsx
    ```

9. **실행**(▶)을 누릅니다. 끝나면 `건수.xlsx` 를 엽니다.

    **완료 기준**: A1 이 `교육` 이고 3행까지 값이 있다.

10. 작업 영역의 빈 곳을 한 번 누르고 `Ctrl` + `A` 로 전체를 고릅니다. 고른 줄을 마우스 오른쪽 단추로 눌러 **작업 사용 안 함**을 고릅니다.
11. 작업 검색 칸에 `데스크톱 흐름 실행` 을 입력하고 **데스크톱 흐름 실행**을 맨 아래로 끌어다 놓습니다. **데스크톱 흐름**에서 `PAD 기본_HGD` 를 고르고 **저장**을 누릅니다. 이 흐름이 없으면 여기서 끝냅니다.
12. **실행**(▶)을 누릅니다.

    **완료 기준**: `A 등급 거래처` 메시지가 뜨고, 메시지 창을 닫으면 `개념 연습_HGD` 의 실행이 끝난다.
