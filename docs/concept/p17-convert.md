## 비교와 계산은 형식이 맞아야 합니다

파일에서 읽거나 앱에서 추출한 값은 대부분 텍스트입니다.[^howdate] 수학 연산은 숫자 값으로만 됩니다.[^types] 비교는 같은 형식의 값끼리만 됩니다.[^percent]

| 값이 나오는 곳 | 자료형 |
|---|---|
| 입력 대화 표시 | 텍스트 |
| 파일에서 텍스트 읽기 | 텍스트 또는 텍스트 목록 |
| 웹 페이지에서 추출한 표의 칸 | 텍스트 |
| Excel 워크시트에서 읽기 | 셀의 원래 값. `Get cell contents as text` 를 켜면 화면에 보이는 글자[^excel] |
| 변수 설정에 수를 표기 없이 입력 | 숫자 |
| 현재 날짜 및 시간 가져오기 | 날짜/시간 |

Lab 6 의 한 행은 값이 아래처럼 바뀝니다.

| 변수 | 값 | 변수 창 아이콘 | 자료형 |
|---|---|---|---|
| `%공고[4]%` | `73,000,000` | — | 텍스트 |
| `%Replaced%` | `73000000` | `T` | 텍스트 |
| `%TextAsNumber%` | `73000000` | `#` | 숫자 |
| `%최소금액%` | `50000000` | `#` | 숫자 |

`%Replaced%` 와 `%TextAsNumber%` 는 글자가 같습니다. 변수 창에서 이름 왼쪽 아이콘으로 구분합니다.

숫자와 텍스트를 `+` 로 더하면 숫자가 텍스트로 바뀌고 두 값이 이어집니다.[^percent]

| 식 | 결과 | 결과 자료형 |
|---|---|---|
| `%5 * 3%` | `15` | 숫자 |
| `%'번호 ' + 5%` | `번호 5` | 텍스트 |

## 변환 작업

| 바꾸는 방향 | 작업 | 결과 변수 | 바꾸지 못할 때 |
|---|---|---|---|
| 텍스트 → 숫자 | 텍스트를 숫자로 변환 | `TextAsNumber` | 예외 발생 |
| 숫자 → 텍스트 | 숫자를 텍스트로 변환 | `FormattedNumber` | 예외 없음 |
| 텍스트 → 날짜/시간 | 텍스트를 날짜/시간으로 변환 | `TextAsDateTime` | 예외 발생 |
| 날짜/시간 → 텍스트 | 텍스트로 날짜/시간 변환 | `FormattedDateTime` | 예외 없음 |

화면의 **텍스트로 날짜/시간 변환**은 날짜/시간을 텍스트로 바꾸는 작업입니다. 참조 문서의 이름은 「날짜/시간을 텍스트로 변환」입니다.[^text]

| 작업 | 칸 | 값 | 기본값 |
|---|---|---|---|
| 텍스트를 숫자로 변환 | 변환할 텍스트 | 숫자만 든 텍스트. 공백은 무시됨 | — |
| 숫자를 텍스트로 변환 | 소수 자릿수 | 남길 소수 자릿수. 모자라면 0을 채움 | 2 |
| 숫자를 텍스트로 변환 | 천 단위 구분 기호 사용 | 켬 · 끔 | 켬 |
| 텍스트를 날짜/시간으로 변환 | 날짜가 사용자 지정 형식으로 표시됨 | 켬 · 끔 | 끔 |
| 텍스트를 날짜/시간으로 변환 | 사용자 지정 형식 | `yyyyMMdd` 같은 표기 | — |
| 텍스트로 날짜/시간 변환 | 사용할 형식 | 표준 · 사용자 지정 | 표준 |
| 텍스트로 날짜/시간 변환 | 표준 형식 | 짧은 날짜 · 긴 날짜 · 짧은 시간 · 긴 시간 · 전체 날짜/시간(짧은 시간) · 전체 날짜/시간(긴 시간) · 일반 날짜/시간(짧은 시간) · 일반 날짜/시간(긴 시간) · 정렬 가능한 날짜/시간 | 짧은 날짜 |
| 텍스트로 날짜/시간 변환 | 사용자 지정 형식 | `yyyyMMdd` · `yyyy.MM.dd` 같은 표기 | — |

## 숫자로 바꾸기 전에 할 일

| 들어온 값 | 할 일 | 방법 |
|---|---|---|
| `1,200,000` | 쉼표 제거 | 텍스트 대체. 찾을 텍스트 `,` · 바꿀 내용 `%''%` |
| `71.5 ℃` | 단위 제거 | 텍스트 대체. 찾을 텍스트 `℃` · 바꿀 내용 `%''%` |
| 앞뒤에 공백이 있는 수 | 없음 | 변환 작업이 공백을 무시함 |
| `미정` | 분기 | 아래 숫자 판별 |

**텍스트 대체**는 찾은 글자를 전부 바꿉니다. 결과는 텍스트 값으로 `Replaced` 에 담깁니다.[^text] `%''%` 는 작은따옴표 안이 비어 있는 빈 텍스트입니다.[^percent]

| 비교하는 값 | 맞추는 방법 | 쓰는 연산자 |
|---|---|---|
| 금액과 금액 | 양쪽을 숫자 값으로 변환 | 크거나 같음 (>=) 같은 대소 비교 |

| 날짜와 날짜 | 양쪽을 날짜/시간 값으로 변환 | 날짜 빼기로 차이를 구해 숫자로 비교 |

## 숫자 판별

변환을 시도하고 실패하면 표시를 남기는 방식입니다.[^numeric] 오류 설정 화면은 [P18](p18-errors.html)에서 다룹니다.

| 순서 | 작업 | 설정 |
|---|---|---|
| 1 | 변수 설정 | `IsNumber` 에 `%True%` |
| 2 | 텍스트를 숫자로 변환 | 확인할 변수 |
| 3 | 2번 작업의 오류 설정 | 새 규칙으로 `IsNumber` 에 `%False%`. 흐름 실행 계속 |
| 4 | If | `%IsNumber%` 값으로 분기 |

## 날짜와 시간

날짜를 나타내는 텍스트를 날짜/시간 값으로 바꾸면 날짜 작업에 넣을 수 있습니다.[^howdate] 파일 이름처럼 글자가 필요한 칸에는 다시 텍스트로 바꿔 넣습니다.

| 표기 | 뜻 |
|---|---|
| `yyyy` | 연도 |
| `MM` | 월 |
| `dd` | 일 |
| `HH` | 시 |
| `mm` | 분 |
| `ss` | 초 |
| `ff` | 밀리초 |
| `zzz` | UTC 오프셋 |

**텍스트를 날짜/시간으로 변환**의 조건은 아래와 같습니다.[^howdate]

| 조건 | 동작 |
|---|---|
| 사용자 지정 형식을 끔 | PC의 지역 · 언어 설정에 있는 기본 형식으로 읽음 |
| 값에 시간 부분이 없음 | 시간이 `12:00:00 AM` 으로 정해짐 |
| 구분 기호가 `/` · `-` · `.` | 어느 쪽이든 같은 결과 |
| 값의 모양이 기본 형식과 다름 | 날짜가 사용자 지정 형식으로 표시됨을 켜고 표기를 입력 |

날짜 작업은 아래 셋을 씁니다.[^datetime]

| 작업 | 입력 | 결과 변수 | 조건 |
|---|---|---|---|
| 현재 날짜 및 시간 가져오기 | 검색(현재 날짜 및 시간 · 현재 날짜만) · 표준 시간대(기본 시스템 표준 시간대) | `CurrentDateTime` | 형식은 Windows 설정을 따름. 현재 날짜만이면 시간은 자정 |
| 날짜/시간에 추가 | 날짜/시간 · 추가 · 시간 단위(초 · 분 · 시간 · 일 · 월 · 년, 기본 초) | `ResultedDate` | 빼려면 음수를 입력 |
| 날짜 빼기 | 기준 날짜 · 뺄 날짜 · 차이 단위(초 · 분 · 시간 · 일, 기본 일) | `TimeDifference` | 결과는 숫자 값 |

Lab 7 은 납기일을 아래 순서로 만듭니다.

```
현재 날짜 및 시간 가져오기                → %CurrentDateTime%
날짜/시간에 추가      %CurrentDateTime% + 7 일 → %ResultedDate%
텍스트로 날짜/시간 변환  %ResultedDate% · yyyy.MM.dd → %납기일%
```

## 샘플

흐름 `개념 연습_HGD` 를 씁니다. 없으면 [P2](p02-types.html)의 1·2번으로 만듭니다.

1. **Main** 탭의 빈 곳을 한 번 누르고 `Ctrl` + `A` 를 누른 뒤 `Delete` 를 눌러 줄을 지웁니다.
2. 작업 검색 칸에 `변수 설정` 을 입력하고 **변수 설정**을 작업 영역으로 끌어다 놓습니다. **변수**와 **값**에 아래를 차례로 넣고 **저장**을 누릅니다. 작은따옴표로 감싼 값은 텍스트입니다.

    ```
    금액문자
    ```

    ```
    %'1,200,000'%
    ```

3. 작업 검색 칸에 `텍스트 대체` 를 입력하고 **텍스트 대체**를 1번 줄 아래로 끌어다 놓습니다. **구문 분석할 텍스트** · **찾을 텍스트** · **바꿀 내용**에 아래를 차례로 넣고 **저장**을 누릅니다. 결과는 **변수 생성됨**의 `Replaced` 에 담깁니다.

    ```
    %금액문자%
    ```

    ```
    ,
    ```

    ```
    %''%
    ```

4. 작업 검색 칸에 `텍스트를` 을 입력하고 **텍스트를 숫자로 변환**을 2번 줄 아래로 끌어다 놓습니다. **변환할 텍스트**에 아래를 넣고 **저장**을 누릅니다. 결과는 `TextAsNumber` 에 담깁니다.

    ```
    %Replaced%
    ```

5. 작업 검색 칸에 `if` 를 입력하고 **조건** 아래 **If**를 3번 줄 아래로 끌어다 놓습니다. **첫 번째 피연산자**와 **두 번째 피연산자**에 아래를 차례로 넣고, **연산자**를 **크거나 같음 (>=)**으로 바꾼 뒤 **저장**을 누릅니다.

    ```
    %TextAsNumber%
    ```

    ```
    1000000
    ```

6. 작업 검색 칸에 `메시지 표시` 를 입력하고 **메시지 표시**를 **If**와 **End** 사이로 끌어다 놓습니다. **표시할 메시지**에 아래를 넣고 **저장**을 누릅니다.

    ```
    100만 원 이상입니다.
    ```

7. 도구 모음의 **실행**(▶)을 누릅니다.

    **완료 기준**: 메시지 창에 `100만 원 이상입니다.` 가 뜬다.

8. 메시지 창의 **확인**을 누르고, 오른쪽 세로 막대의 **{x}** 를 눌러 변수 창을 엽니다.

    **완료 기준**: `금액문자` 는 `T` 아이콘에 `1,200,000`, `Replaced` 는 `T` 아이콘에 `1200000`, `TextAsNumber` 는 `#` 아이콘에 `1200000` 이다.

9. **변수 설정**을 맨 아래로 끌어다 놓고 아래를 차례로 넣습니다.

    ```
    판별대상
    ```

    ```
    %'미정'%
    ```

10. **변수 설정**을 맨 아래로 하나 더 놓고 아래를 차례로 넣습니다.

    ```
    IsNumber
    ```

    ```
    %True%
    ```

11. **텍스트를 숫자로 변환**을 맨 아래로 끌어다 놓고 **변환할 텍스트**에 아래를 넣습니다. **저장**은 아직 누르지 않습니다.

    ```
    %판별대상%
    ```

12. 대화 상자 왼쪽 아래 **오류**를 누릅니다. **오류 처리** 묶음의 **새 규칙**에서 **변수 설정**을 고르고, 변수와 값에 아래를 차례로 넣습니다.

    ```
    IsNumber
    ```

    ```
    %False%
    ```

13. **흐름 실행 계속**을 누르고 **예외 처리 모드**를 **다음 작업으로 이동**으로 둡니다. **매개 변수로 돌아가기**를 누른 뒤 **저장**을 누릅니다.
14. **If**를 맨 아래로 끌어다 놓습니다. **첫 번째 피연산자**와 **두 번째 피연산자**에 아래를 차례로 넣습니다. **연산자**는 **같음 (=)** 그대로 두고 **저장**을 누릅니다.

    ```
    %IsNumber%
    ```

    ```
    %False%
    ```

15. **메시지 표시**를 14번의 **If**와 **End** 사이로 끌어다 놓습니다. **표시할 메시지**에 아래를 넣고 **저장**을 누릅니다.

    ```
    숫자가 아닙니다.
    ```

16. **실행**합니다. 첫 메시지 창은 **확인**으로 닫습니다.

    **완료 기준**: `숫자가 아닙니다.` 창이 뜨고, 변수 창의 `IsNumber` 가 `False` 다.

17. 7번 줄 `판별대상` 을 두 번 클릭해 **값**을 아래로 바꾸고 **저장**합니다. **실행**합니다.

    ```
    %'2500'%
    ```

    **완료 기준**: `숫자가 아닙니다.` 창이 뜨지 않고, 변수 창의 `IsNumber` 가 `True` 다.

18. **변수 설정**을 맨 아래로 끌어다 놓고 아래를 차례로 넣습니다.

    ```
    납기문자
    ```

    ```
    %'2026-10-07'%
    ```

19. 작업 검색 칸에 `텍스트를` 을 입력하고 **텍스트를 날짜/시간으로 변환**을 맨 아래로 끌어다 놓습니다. **변환할 텍스트**에 첫째 값을 넣고, **날짜가 사용자 지정 형식으로 표시됨**을 켠 뒤 **사용자 지정 형식**에 둘째 값을 넣습니다. **저장**을 누릅니다. 결과는 `TextAsDateTime` 에 담깁니다.

    ```

    ```

    ```

    ```

