## 작업의 구조

모든 Excel 작업은 Excel 시작이 만든 Excel 인스턴스를 칸에 받습니다.[^excel] 시작과 닫기의 짝은 [P10](p10-instances.html)에서 다룹니다. 읽기는 그 인스턴스의 활성 워크시트에서 읽습니다. 다른 시트를 다룰 때는 **활성 Excel 워크시트 설정**을 먼저 놓습니다.

```
Excel 시작                  및 다음 문서 열기 C:\PA실습\거래처목록.xlsx → %ExcelInstance%
Excel 워크시트에서 읽기      워크시트의 사용 가능한 모든 값 → %ExcelData%
Excel 워크시트에 쓰기        쓸 값 · 열 · 행
Excel 닫기                  문서 저장 안 함 · 문서 저장 · 다음 형식으로 문서 저장
```

## Excel 시작의 칸

| 칸 | 값 | 기본값 |
|---|---|---|
| Excel 시작 | 빈 문서 · 및 다음 문서 열기 | 빈 문서 |
| 문서 경로 | 열 파일의 전체 경로 | 없음 |
| 인스턴스 표시 | 창을 보임 · 숨김 | 켬 |
| 새 Excel 프로세스에 포함 | 별도 프로세스로 엶. 다른 문서의 매크로와 추가 기능에 접근 못 함 | 끔 |
| 암호 | 암호로 보호된 문서의 암호 | 없음 |
| 읽기 전용으로 열기 | 읽기 전용으로 엶 | 끔 |
| 추가 기능 및 매크로 로드 | 추가 기능과 매크로를 불러옴 | 끔 |

이미 열려 있는 문서에는 **실행 중인 Excel에 첨부**로 연결합니다. 문서 이름이나 경로를 받습니다.[^excel]

## 읽기의 네 방식

Excel 워크시트에서 읽기의 **검색** 칸이 범위를 정합니다.[^excel]

| 검색 | 넣는 칸 | 결과 형식 |
|---|---|---|
| 단일 셀의 값 | 시작 열 · 시작 행 | 일반 값 |
| 셀 범위의 값 | 시작 열 · 시작 행 · 끝 열 · 끝 행 | 데이터 테이블 |
| 선택의 값 | 없음. 지금 선택된 셀 | 데이터 테이블 |
| 워크시트의 사용 가능한 모든 값 | 없음 | 데이터 테이블 |

열 칸에는 글자(`A`)와 숫자(`1`)를 모두 넣을 수 있습니다.[^excel]

## 첫 행을 열 이름으로

고급의 **범위의 첫 번째 행을 열 이름으로 사용**이 표의 모양을 정합니다.[^excel] 기본값은 끔입니다.

| 항목 | 켰을 때 | 껐을 때 |
|---|---|---|
| 첫 행 | 열 이름이 되고 데이터에 들어가지 않음 | 데이터 첫 행이 됨 |
| `거래처목록.xlsx` 전체의 행 수 | 12 | 13 |
| 값 읽기 | `%CurrentItem['등급']%` · `%표[0]['등급']%` | `%CurrentItem[3]%` · `%표[0][3]%` |

## 셀 내용의 형식

읽을 때 셀의 값을 어떤 형식으로 받을지 고릅니다. PAD 2.58 에서 이 세 값이 들어왔습니다.[^excel]

| 값 | 돌려주는 것 | 용도 |
|---|---|---|
| 형식화된 값(기본) | 셀의 형식대로 해석한 값. 날짜는 날짜/시간, 숫자는 숫자 | 대부분의 경우 |
| 일반 텍스트 | 화면에 보이는 글자 그대로 | 화면의 글자가 필요할 때 |
| 서식이 지정된 텍스트 값 | 서식을 반영한 문자열. 단일 셀을 읽으면 해석된 형식 | 날짜 · 통화 표시를 유지할 때 |

| 조건 | 결과 |
|---|---|
| 숫자 셀을 기본값으로 읽음 | 숫자 값. 2026-10-06 실측 `최소금액` 은 `# 50000000` |
| 날짜 셀을 기본값으로 읽음 | 시간이 함께 붙음 |
| 글자로 읽는데 열 너비가 좁아 `###` 으로 보임 | `###` 이 그대로 읽힘. 열 크기 조정 작업으로 넓힘 |

## 번호 체계

같은 흐름 안에서 Excel 번호와 데이터 테이블 번호가 다릅니다.[^types]

| 대상 | 시작 번호 | 예 |
|---|---|---|
| 워크시트의 행 | 1 | 행 `2` 는 둘째 행 |
| 워크시트의 열(숫자) | 1 | 열 `1` 은 A열 |
| 데이터 테이블의 행 · 열 | 0 | `%표[0][1]%` 는 첫 행 둘째 열 |
| 목록의 항목 | 0 | `%목록[0]%` 는 첫 항목 |

## 쓰기

**Excel 워크시트에 쓰기**는 값의 자료형에 따라 채우는 범위가 달라집니다.[^excel]

| 쓸 값 | 채우는 범위 |
|---|---|
| 글자 · 숫자 · 단일 값 변수 | 지정한 셀 하나 |
| 목록 | 지정한 셀부터 아래로 |
| 데이터 테이블 | 지정한 셀부터 오른쪽과 아래로. 있던 값을 덮어씀 |

**쓰기 모드**는 지정된 셀에 쓰기와 현재 활성 상태인 셀이 있습니다. 데이터 테이블을 쓸 때 열 이름은 들어가지 않습니다.[^lab] 머리글이 필요하면 머리글이 있는 파일을 열고 2행부터 씁니다.

한 행씩 쌓을 때는 행 칸에 변수를 넣고 쓸 때마다 늘립니다. 데이터가 이미 있는 시트에 이어 쓸 때는 다음 작업이 비어 있는 위치를 알려 줍니다.[^excel]

| 작업 | 생성 변수 | 값 |
|---|---|---|
| Excel 워크시트에서 첫 번째 자유 열 또는 행 가져오기 | `FirstFreeColumn` · `FirstFreeRow` | 완전히 비어 있는 첫 열과 첫 행의 번호. F열이면 `6` |
| Excel 워크시트에서 열의 첫 번째 빈 행 가져오기 | `FirstFreeRowOnColumn` | 그 열의 첫 빈 행 번호 |

## 닫기와 저장

| Excel을 닫기 전 | 결과 |
|---|---|
| 문서 저장 안 함(기본) | 변경을 버리고 닫음 |
| 문서 저장 | 같은 파일에 저장하고 닫음 |
| 다음 형식으로 문서 저장 | 문서 경로에 새 파일로 저장하고 닫음. 원본은 그대로 |

문서 형식의 기본값은 기본(확장명 사용)입니다. xlsx · xlsm · xls · csv · txt 등을 고를 수 있습니다. 닫지 않고 저장할 때는 **Excel 저장**을 씁니다.[^excel]

## 흔한 실패

| 증상 · 예외 | 원인 | 고치는 방법 |
|---|---|---|
| 파일을 찾을 수 없음 | OneDrive · SharePoint 로 동기화된 폴더의 파일. PAD 가 쓰는 COM 을 이 폴더들이 완전히 지원하지 않음 | 로컬에 복사해 작업한 뒤 동기화 폴더의 파일을 바꿈 |
| 읽기 전용으로 열림 | 같은 파일이 이미 열려 있음 | 실행 전에 그 파일의 창을 닫음 |
| `['등급']` 이 열을 찾지 못함 | 첫 행 옵션이 꺼져 머리글이 데이터가 됨 | 범위의 첫 번째 행을 열 이름으로 사용을 켬 |
| 엉뚱한 위치에 기록됨 | 실행 중에 셀을 누름 | 실행 중에 입력 장치를 쓰지 않음 |
| 다른 파일에 기록됨 | Excel 인스턴스 칸의 기본 변수를 그대로 둠 | 칸을 그 파일의 인스턴스로 바꿈 |
| Failed to read cell values | 지정한 셀을 읽는 데 문제 | 칸의 열 · 행과 활성 워크시트 확인 |
| Failed to write value to Excel | 값을 쓰는 데 문제 | 인스턴스가 열려 있는지와 읽기 전용 여부 확인 |
| Failed to save Excel document | 저장 문제 | 경로와 같은 이름 파일이 열려 있는지 확인 |
