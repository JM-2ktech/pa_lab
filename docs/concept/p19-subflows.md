## 하위 흐름

하위 흐름은 흐름 안에서 한 묶음으로 부를 수 있는 작업 모음입니다.[^designer] 모든 흐름에는 **Main** 이 있고, 흐름을 시작하면 Main 이 실행됩니다. 다른 하위 흐름은 하위 흐름 실행 작업으로 부를 때 실행됩니다.

| 조작 | 방법 |
|---|---|
| 만들기 | 작업 영역 위 탭 줄 오른쪽 **+ 새로운** → **하위 흐름 추가** 창에 이름과 범위 입력 |
| 고쳐 쓰기 | 탭을 눌러 그 하위 흐름의 작업 영역을 엶 |
| 작업 옮기기 | 작업을 잘라 다른 탭에 붙여넣음. 같은 하위 흐름 · 다른 하위 흐름 · 다른 디자이너 창 사이에 복사 가능 |
| 부르기 | **하위 흐름 실행** 작업 |
| 그 탭으로 가기 | **하위 흐름 실행**의 오른쪽 단추 메뉴 **하위 흐름으로 이동** |
| 목록 정렬 | 탭 줄 **하위 흐름** 메뉴. 만든 순서(기본) · 역순 · 이름순 · 사용자 지정 순서. **Main** 은 늘 맨 위 |

**하위 흐름 실행**은 있던 하위 흐름을 멈추고 지정한 하위 흐름을 실행합니다. 그 하위 흐름이 끝나면 원래 하위 흐름으로 돌아와 다음 줄을 실행합니다.[^flow] 같은 작업을 여러 번 쓰지 않으려면 하위 흐름으로 묶어 여러 번 부릅니다.

| 칸 | 값 | 기본값 |
|---|---|---|
| 하위 흐름 이름 | 부를 하위 흐름 | — |
| 식으로 입력 | 켜면 변수와 식으로 실행 중에 하위 흐름을 정함 | 끔 |

하위 흐름이 자기를 끝없이 부르는 무한 재귀는 오류 창에 경고로 표시됩니다.[^errors]

## 흐름 제어 작업

| 작업 | 동작 | 입력 | 기본값 |
|---|---|---|---|
| 하위 흐름 실행 | 지정한 하위 흐름 실행 | 하위 흐름 이름 · 식으로 입력 | 식으로 입력 끔 |
| 하위 흐름 종료 | 지금 하위 흐름을 끝내고 부른 위치로 돌아감 | 없음 | — |
| 흐름 중지 | 흐름 전체 종료 | 끝 흐름(성공적으로 · 오류 메시지와 함께) · 오류 메시지 | 성공적으로 |
| 레이블 | **이동**의 목적지 | 레이블 이름 | — |
| 이동 | 지정한 레이블로 실행 위치를 옮김 | 레이블로 이동 | — |
| 주석 | 사용자 설명 | 설명 글 | — |
| 영역 · End 영역 | 작업을 묶어 접고 펼침 | 이름(선택) | — |
| 대기 | 지정한 초만큼 실행을 멈춤 | 길이(초) | — |
| 안전 중지가 요청된 경우 | 안전 중지 요청이 있는지 확인 | 흐름 중지 | 끔 |

오류 쪽 작업인 블록 오류 발생 시 · 마지막 오류 가져오기 · 사용자 지정 오류 throw 는 [P18](p18-errors.html)에서 다룹니다.[^flow]

## 레이블과 이동

**레이블**은 표시만 하고 이동 작업이 그 위치로 실행을 옮깁니다. 흐름 앞쪽의 레이블로 이동하면 사이의 작업을 다시 실행합니다.[^flow]

버전 2.46부터 이동 작업과 다른 범위에 있는 레이블도 쓸 수 있습니다. 예로 If 블록 안의 레이블이 됩니다. 오류 블록 · 반복 · 다른 하위 흐름 안의 레이블은 안 됩니다.[^flow]

---

## 주석과 영역

**주석**은 작업 영역에 설명 글을 남기는 작업입니다.[^flow]

**영역**과 End 영역 사이의 작업은 한 묶음으로 접고 펼칠 수 있습니다. 실행 결과에는 영향이 없습니다.[^flow]

| 조건 | 내용 |
|---|---|
| 짝 | **영역**과 **End 영역**을 쌍으로만 씀 |
| 범위 | 둘이 같은 범위에 있어야 함. 하나만 반복이나 조건 안에 있으면 영역이 되지 않음 |
| 여러 영역 | 정해진 짝이 없음. 마지막 **영역**이 그 뒤의 첫 **End 영역**과 짝을 이룸 |

## 전역 변수와 로컬 변수

변수의 범위는 그 변수를 만든 하위 흐름의 범위를 따릅니다.[^scoped]

| 구분 | 전역 | 로컬 |
|---|---|---|
| 만드는 곳 | 전역 하위 흐름 | 로컬 하위 흐름 |
| 쓸 수 있는 곳 | 흐름 전체 | 만든 로컬 하위 흐름 안 |
| 변수 창 탭 | **전역** | **로컬** |
| 다른 하위 흐름과 값 주고받기 | 변수를 그대로 씀 | 입력 · 출력 변수로 넘김 |

| 조건 | 내용 |
|---|---|
| 범위 정하기 | 하위 흐름을 만들 때 **범위** 칸에서 정함 |
| 범위 바꾸기 | 만든 뒤에는 바꿀 수 없음 |
| Main | 늘 전역. 바꿀 수 없음 |
| Power Fx | Power Fx 를 켠 흐름에서는 범위 변수를 쓸 수 없음 |

로컬 하위 흐름에서 전역 변수를 쓰려면 **{x}** 목록의 전역 탭에서 고릅니다. 이름 앞에 `global.` 이 붙습니다. 직접 입력할 때는 `%global.변수이름%` 으로 적습니다.[^scoped]

로컬 하위 흐름의 입력 · 출력 변수는 그 하위 흐름을 연 상태에서 변수 창 오른쪽 위 **+** 로 만듭니다. 하위 흐름 실행 작업에서 입력 변수에 값을 넘기고, 출력 변수는 그 작업의 변수 생성됨 영역에서 받습니다.[^scoped]

## 샘플

흐름 `개념 연습_HGD` 를 씁니다. 없으면 [P2](p02-types.html)의 1·2번으로 만듭니다.

1. **Main** 탭의 빈 곳을 한 번 누르고 `Ctrl` + `A` 를 누른 뒤 `Delete` 를 눌러 줄을 지웁니다.
2. 작업 검색 칸에 `변수 설정` 을 입력하고 **변수 설정**을 작업 영역으로 끌어다 놓습니다. **변수**와 **값**에 아래를 차례로 넣고 **저장**을 누릅니다.

    ```
    금액
    ```

    ```
    1000
    ```

3. 작업 영역 위 탭 줄 오른쪽의 **+ 새로운**을 누릅니다. **하위 흐름 추가** 창의 **하위 흐름 이름**에 아래를 넣고, **범위**는 **전역** 그대로 **저장**을 누릅니다.

    ```
    금액표시
    ```

4. 탭 줄의 **금액표시** 탭을 누릅니다. 작업 검색 칸에 `메시지 표시` 를 입력하고 **메시지 표시**를 작업 영역으로 끌어다 놓습니다. **표시할 메시지**에 아래를 넣고 **저장**을 누릅니다.

    ```
    금액은 %금액%원입니다.
    ```

5. **Main** 탭을 누릅니다. 작업 검색 칸에 `하위 흐름 실행` 을 입력하고 **하위 흐름 실행**을 1번 줄 아래로 끌어다 놓습니다. **하위 흐름 이름**에서 `금액표시` 를 고르고 **저장**을 누릅니다.
6. **메시지 표시**를 2번 줄 아래로 끌어다 놓습니다. **표시할 메시지**에 아래를 넣고 **저장**을 누릅니다.

    ```
    Main 으로 돌아왔습니다.
    ```

7. 도구 모음의 **실행**(▶)을 누릅니다. 메시지 창은 **확인**으로 닫습니다.

    **완료 기준**: `금액은 1000원입니다.` 창 다음에 `Main 으로 돌아왔습니다.` 창이 뜬다.

8. 작업 검색 칸에 `주석` 을 입력하고 **주석**을 1번 줄 위로 끌어다 놓습니다. 설명 칸에 아래를 넣고 **저장**을 누릅니다.

    ```
    금액을 정하고 하위 흐름으로 표시한다
    ```

    **완료 기준**: 1번 줄에 주석이 보이고, 나머지 줄 번호가 하나씩 밀렸다.

9. **금액표시** 탭을 누릅니다. 작업 검색 칸에 `if` 를 입력하고 **If**를 1번 줄 위로 끌어다 놓습니다. **첫 번째 피연산자**와 **두 번째 피연산자**에 아래를 차례로 넣습니다. **연산자**는 **같음 (=)** 그대로 두고 **저장**을 누릅니다.

    ```
    %금액%
    ```

    ```
    0
    ```

10. 작업 검색 칸에 `하위 흐름 종료` 를 입력하고 **하위 흐름 종료**를 **If**와 **End** 사이로 끌어다 놓습니다. 대화 상자가 열리면 **저장**을 누릅니다.
11. **Main** 탭을 누릅니다. 2번 줄 **변수 설정**을 두 번 클릭해 **값**을 `0` 으로 바꾸고 **저장**한 뒤 **실행**합니다.

    **완료 기준**: `금액은 …원입니다.` 창은 뜨지 않고 `Main 으로 돌아왔습니다.` 창이 뜬다.

12. 2번 줄의 **값**을 `1000` 으로 되돌립니다.
13. **변수 설정**을 맨 아래로 끌어다 놓고 아래를 차례로 넣습니다.

    ```
    횟수
    ```

    ```
    0
    ```

14. 작업 검색 칸에 `레이블` 을 입력하고 **흐름 제어** 아래 **레이블**을 맨 아래로 끌어다 놓습니다. **레이블 이름**에 아래를 넣고 **저장**을 누릅니다.

    ```
    다시
    ```

15. 작업 검색 칸에 `변수 증가` 를 입력하고 **변수 증가**를 맨 아래로 끌어다 놓습니다. **변수 이름**과 **증가됨**에 아래를 차례로 넣고 **저장**을 누릅니다.

    ```
    %횟수%
    ```

    ```
    1
    ```

16. **If**를 맨 아래로 끌어다 놓습니다. **첫 번째 피연산자**와 **두 번째 피연산자**에 아래를 차례로 넣고, **연산자**를 **같지 않음 (<>)**으로 바꾼 뒤 **저장**을 누릅니다.

    ```
    %횟수%
    ```

    ```
    3
    ```

17. 작업 검색 칸에 `이동` 을 입력하고 **흐름 제어** 아래 **이동**을 16번의 **If**와 **End** 사이로 끌어다 놓습니다. **레이블로 이동**에서 `다시` 를 고르고 **저장**을 누릅니다.
18. **메시지 표시**를 맨 아래로 끌어다 놓습니다. **표시할 메시지**에 아래를 넣고 **저장**을 누른 뒤 **실행**합니다.

    ```
    횟수 %횟수%
    ```

    **완료 기준**: 마지막 메시지 창에 `횟수 3` 이 뜬다.

19. 작업 검색 칸에 `영역` 을 입력하고 **영역**을 13번에서 놓은 **변수 설정** 위로 끌어다 놓습니다. 이름에 아래를 넣고 **저장**을 누릅니다.

    ```
    횟수 세기
    ```

20. **End 영역**을 맨 아래로 끌어다 놓습니다. 대화 상자가 열리면 **저장**을 누릅니다. **영역** 줄 왼쪽의 화살표를 눌러 접습니다. **실행**합니다.

    **완료 기준**: 사이의 줄이 접혀 있고 `횟수 3` 창이 그대로 뜬다.

21. 작업 검색 칸에 `흐름 중지` 를 입력하고 **흐름 중지**를 `Main 으로 돌아왔습니다.` 줄 아래로 끌어다 놓습니다. **저장**을 누르고 **실행**합니다.

    **완료 기준**: `Main 으로 돌아왔습니다.` 창까지 뜨고 `횟수 3` 창은 뜨지 않는다.

22. **흐름 중지** 줄을 마우스 오른쪽 단추로 누르고 **작업 사용 안 함**을 고릅니다.
23. 탭 줄의 **+ 새로운**을 누릅니다. **하위 흐름 이름**에 아래를 넣고, **범위**를 **로컬**로 바꾼 뒤 **저장**을 누릅니다.

    ```
    로컬연습
    ```

24. **로컬연습** 탭을 누릅니다. **변수 설정**을 끌어다 놓고 아래를 차례로 넣습니다.

    ```
    로컬값
    ```

    ```
    5
    ```

    **완료 기준**: 변수 창의 **로컬** 탭에 `로컬값` 이 보인다.

25. **메시지 표시**를 1번 줄 아래로 끌어다 놓습니다. **표시할 메시지**에 아래를 넣고 **저장**을 누릅니다.

    ```
    %로컬값% / %global.금액%
    ```

26. **Main** 탭을 누릅니다. **하위 흐름 실행**을 맨 아래로 끌어다 놓고 **하위 흐름 이름**에서 `로컬연습` 을 고른 뒤 **저장**을 누릅니다. **실행**합니다.

    **완료 기준**: 마지막 메시지 창에 `5 / 1000` 이 뜬다.

27. **Main** 탭에서 아무 **메시지 표시** 줄이나 두 번 클릭해 엽니다. **표시할 메시지** 칸 오른쪽 위 **{x}** 를 눌러 변수 목록을 본 뒤 **취소**로 닫습니다.

    **완료 기준**: 목록에 `금액` 은 있고 `로컬값` 은 없다.
