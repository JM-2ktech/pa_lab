## 세 가지 반복

| 화면 이름 | 영문 | 끝나는 때 | 만드는 변수 |
|---|---|---|---|
| 반복 | Loop | 정한 횟수를 채움 | `LoopIndex` |
| 반복 조건 | Loop condition | 조건이 거짓이 됨 | 없음 |
| 각각의 경우 | For each | 목록이나 표의 항목을 모두 돎 | `CurrentItem` |

세 가지 모두 **End** 와 짝을 이루고, 사이에 놓은 작업을 되풀이합니다.[^use]

---

## 고르는 기준

| 상황 | 고르는 것 |
|---|---|
| 되풀이할 횟수를 정확히 안다 | 반복 |
| 반복 안에서 번호 변수를 써야 한다 | 반복 |
| 횟수를 미리 모르고 조건이 참인 동안 되풀이한다 | 반복 조건 |
| 목록의 항목이나 데이터 테이블의 행을 하나씩 쓴다 | 각각의 경우 |

앞의 두 줄은 문서가 반복을 쓰기 좋은 경우로 듭니다.[^use]

## 반복

| 칸 | 넣는 것 |
|---|---|
| 시작 | 번호의 시작 값. 숫자 |
| 끝 | 번호의 끝 값. 숫자 |
| 증가 | 한 번 돌 때 번호가 늘어나는 크기. 숫자 |

번호는 `LoopIndex` 에 담깁니다. 시작 값에서 출발해 돌 때마다 증가 값만큼 달라집니다.[^ref] 시작 1 · 끝 3 · 증가 1 이면 1 · 2 · 3 으로 세 번 돕니다.

---

## 반복 조건

조건이 참인 동안 되풀이합니다. 조건은 If 처럼 피연산자 둘과 연산자 하나로 이뤄집니다.[^use] 쓸 수 있는 연산자는 비교 여섯 가지입니다.[^ref]

| 연산자 | 영문 |
|---|---|
| 같음 (=) | Equal to |
| 같지 않음 (`<>`) | Not equal to |
| 보다 큼 (>) | Greater than |
| 크거나 같음 (>=) | Greater than or equal to |
| 보다 작음 (`<`) | Less than |
| 보다 작거나 같음 (`<=`) | Less than or equal to |

조건이 항상 참이면 끝나지 않습니다. 이것을 무한 반복이라고 합니다.[^use] 조건에 쓰는 변수를 반복 안에서 바꿔야 합니다. 값을 늘릴 때는 **변수 증가**를 씁니다.

## 각각의 경우

| 칸 | 넣는 것 |
|---|---|
| 반복할 값 | 목록 · 데이터 테이블 · 데이터 행 |
| 저장 위치 | 지금 항목이 담기는 변수 이름. 기본값 `CurrentItem` |

| 반복할 값 | 현재 항목의 자료형 | 읽는 표기 |
|---|---|---|
| 텍스트 목록 | 텍스트 값 | `%CurrentItem%` |
| 파일 목록 | 파일 | `%CurrentItem%` · `%CurrentItem.Name%` |
| 데이터 테이블 | 데이터 행 | `%CurrentItem['등급']%` · `%CurrentItem[3]%` |
| 데이터 행 | 그 행의 칸 값 | `%CurrentItem%` |

`CurrentItem` 이 이미 있으면 PAD 가 `CurrentItem2` 처럼 번호를 붙입니다. 반복이 둘 이상이면 **저장 위치**를 `키워드행` · `공고` 처럼 내용을 나타내는 이름으로 바꿀 수 있습니다. 읽는 표기는 [P4](p04-index.html)와 [P5](p05-properties.html)에서 다룹니다.

## 반복 종료와 다음 반복

세 가지 반복 모두에서 씁니다.[^use] 보통 반복 안의 If 블록에 넣습니다.

| 작업 | 영문 | 동작 |
|---|---|---|
| 반복 종료 | Exit loop | 반복을 끝내고 End 다음 작업으로 감 |
| 다음 반복 | Next loop | 남은 작업을 건너뛰고 다음 회차로 감 |

## 샘플

같은 일을 세 가지 반복으로 만듭니다. 목록의 키워드 셋을 `/` 로 이어 붙입니다. 작업은 작업 검색 칸에 이름을 입력해 찾습니다. 흐름 `개념 연습_HGD` 를 씁니다. 없으면 [P2](p02-types.html)의 1·2번으로 만듭니다.

1. 콘솔 흐름 목록에서 `개념 연습_HGD` 의 **편집**을 누릅니다. 디자이너가 이미 열려 있으면 그 창을 씁니다.
2. **Main** 탭의 빈 곳을 한 번 누르고 `Ctrl` + `A` 로 전체를 고른 뒤 `Delete` 키를 누릅니다.
3. 작업 검색 칸에 `새 목록` 을 입력하고 **새 목록 만들기**를 작업 영역으로 끌어다 놓고 **저장**을 누릅니다. 결과는 **변수 생성됨**의 `List` 에 담깁니다.
4. 작업 검색 칸에 `목록에 항목` 을 입력하고 **목록에 항목 추가**를 놓습니다. **항목 추가**에 아래를 넣고, **목록으로**가 `%List%` 인지 확인하고 **저장**을 누릅니다.

    ```
    교육
    ```

5. **목록에 항목 추가**를 하나 더 놓아 아래를 넣습니다.

    ```
    클라우드
    ```

6. **목록에 항목 추가**를 하나 더 놓아 아래를 넣습니다.

    ```
    자동화
    ```

7. 작업 검색 칸에 `변수 설정` 을 입력하고 **변수 설정**을 맨 아래로 끌어다 놓습니다. **변수** 칸과 **값** 칸에 아래를 차례로 넣고 **저장**을 누릅니다.

    ```
    결과1
    ```

    ```
    %''%
    ```

8. 작업 검색 칸에 `각각의` 를 입력하고 **각각의 경우**를 맨 아래로 끌어다 놓습니다. **반복할 값**에 아래를 넣고 **저장**을 누릅니다. **저장 위치**는 `CurrentItem` 그대로 둡니다.

    ```
    %List%
    ```

9. **변수 설정**을 **각각의 경우**와 **End** 사이로 끌어다 놓고 아래를 넣습니다.

    ```
    결과1
    ```

    ```
    %결과1 + CurrentItem + '/'%
    ```

10. **변수 설정**을 맨 아래로 끌어다 놓고 아래를 넣습니다.

    ```
    결과2
    ```

    ```
    %''%
    ```

11. 작업 검색 칸에 `반복` 을 입력하고 **반복** 묶음의 **반복**을 맨 아래로 끌어다 놓습니다. **시작** · **끝** · **증가**에 아래를 차례로 넣고 **저장**을 누릅니다. 목록의 번호가 0 부터여서 시작을 0 으로 둡니다.

    ```
    0
    ```

    ```
    %List.Count - 1%
    ```

    ```
    1
    ```

12. **변수 설정**을 11번의 **반복**과 **End** 사이로 끌어다 놓고 아래를 넣습니다.

    ```
    결과2
    ```

    ```
    %결과2 + List[LoopIndex] + '/'%
    ```

13. **변수 설정**을 맨 아래로 끌어다 놓고 아래를 넣습니다.

    ```
    결과3
    ```

    ```
    %''%
    ```

14. **변수 설정**을 하나 더 놓고 아래를 넣습니다.

    ```
    번호
    ```

    ```
    0
    ```

15. **반복** 묶음의 **반복 조건**을 맨 아래로 끌어다 놓습니다. **첫 번째 피연산자**와 **두 번째 피연산자**에 아래를 차례로 넣습니다. **연산자**는 **보다 작음** (`<`)으로 고르고 **저장**을 누릅니다.

    ```
    %번호%
    ```

    ```
    %List.Count%
    ```

16. **변수 설정**을 **반복 조건**과 **End** 사이로 끌어다 놓고 아래를 넣습니다.

    ```
    결과3
    ```

    ```
    %결과3 + List[번호] + '/'%
    ```

17. 작업 검색 칸에 `변수 증가` 를 입력하고 **변수 증가**를 16번 줄 아래, **End** 위로 끌어다 놓습니다. **변수 이름**과 **증가됨**에 아래를 차례로 넣고 **저장**을 누릅니다.

    ```
    %번호%
    ```

    ```
    1
    ```

18. 작업 영역을 아래와 대조합니다.

    ```
    1   새 목록 만들기 → List
    2   목록에 항목 추가: 교육
    3   목록에 항목 추가: 클라우드
    4   목록에 항목 추가: 자동화
    5   변수 설정: 결과1 = %''%
    6   각각의 경우 CurrentItem in %List%
    7       변수 설정: 결과1 = %결과1 + CurrentItem + '/'%
    8   End
    9   변수 설정: 결과2 = %''%
    10  반복 LoopIndex 0부터 %List.Count - 1%까지 1씩
    11      변수 설정: 결과2 = %결과2 + List[LoopIndex] + '/'%
    12  End
    13  변수 설정: 결과3 = %''%
    14  변수 설정: 번호 = 0
    15  반복 조건 %번호% < %List.Count%
    16      변수 설정: 결과3 = %결과3 + List[번호] + '/'%
    17      변수 증가: %번호% + 1
    18  End
    ```

19. **실행**(▶)을 누릅니다. 오른쪽 세로 막대의 **{x}** 를 눌러 변수 창을 엽니다.

    **완료 기준**: `결과1` · `결과2` · `결과3` 이 모두 `교육/클라우드/자동화/` 이고 `번호` 가 3 이다.

    각각의 경우는 번호 변수가 없고, 반복은 `LoopIndex` 를 PAD 가 늘리고, 반복 조건은 `번호` 를 작업으로 직접 늘립니다.

20. 작업 검색 칸에 `if` 를 입력하고 **If**를 6번 줄과 7번 줄 사이로 끌어다 놓습니다. **첫 번째 피연산자**와 **두 번째 피연산자**에 아래를 차례로 넣고 **저장**을 누릅니다.

    ```
    %CurrentItem%
    ```

    ```
    클라우드
    ```

21. 작업 검색 칸에 `다음 반복` 을 입력하고 **다음 반복**을 20번의 **If** 와 **End** 사이로 끌어다 놓습니다.
22. **실행**을 누릅니다.

    **완료 기준**: `결과1` 이 `교육/자동화/` 이다.

23. **다음 반복** 줄을 눌러 `Delete` 키로 지웁니다. 작업 검색 칸에 `반복 종료` 를 입력하고 **반복 종료**를 같은 **If** 와 **End** 사이로 끌어다 놓습니다.
24. **실행**을 누릅니다.

    **완료 기준**: `결과1` 이 `교육/` 이다.

25. **변수 증가** 줄을 마우스 오른쪽 단추로 눌러 **작업 사용 안 함**을 고릅니다. `번호` 가 늘지 않아 조건이 계속 참입니다.
26. **실행**을 누르고 잠시 뒤 도구 모음의 **중지**를 누릅니다.

    **완료 기준**: **반복 조건**이 끝나지 않고 돌다가 **중지**로 멈춘다. `결과3` 에 `교육/` 이 여러 번 이어져 있다.

27. **변수 증가** 줄을 마우스 오른쪽 단추로 눌러 **작업 사용**을 고릅니다.
