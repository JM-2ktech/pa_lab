## 오류의 종류

| 구분 | 나타나는 때 | 예 | 실행 |
|---|---|---|---|
| 설계 시 오류 | 개발 중. 작업 구성과 관련됨 | 필수 칸이 비어 있음 · 정의되지 않은 변수 | 실행되지 않음 |
| 런타임 오류(예외) | 실행 중 | 잘못된 파일 경로 | 흐름이 실패함. 오류 처리로 막을 수 있음 |
| 경고 | 개발 중 | 하위 흐름의 무한 재귀 | 실행됨 |

문서는 설계 시 오류를 「디자인 타임 오류」로 적습니다.[^errors] 작업에서 오류가 나면 디자이너가 작업 옆에 아이콘을 표시하고 관련 정보가 든 창을 띄웁니다. 설계 시 오류는 작업 대화 상자에도 설명이 나옵니다.

## 오류 창

오류와 경고를 모아 보여 주는 디자이너의 창입니다. 오류, 경고, 하위 흐름별로 걸러 볼 수 있습니다.[^errors]

| 열 | 내용 |
|---|---|
| 유형 | 오류 또는 경고 |
| 설명 | 오류 또는 경고의 설명 |
| 하위 흐름 | 해당 작업이 든 하위 흐름 이름 |
| 라인 | 해당 작업의 줄 번호 |

항목을 두 번 클릭하면 대화 상자가 열립니다.

| 항목의 종류 | 대화 상자의 내용 |
|---|---|
| 설계 시 오류 · 경고 | 위치(하위 흐름 · 줄 · 작업) · 오류 메시지 |
| 런타임 오류 | 메시지 · 위치(하위 흐름 · 줄 · 작업) · 가능한 수정 단계(현재 Excel 작업 오류만) · 오류 세부 정보(상관 관계 ID · 기술 설명) |

## 작업 하나의 오류 처리

기본 동작은 오류가 나면 흐름 실행이 멈추는 것입니다.[^errors] 문서는 이 설정을 「오류 발생 시」라고 부릅니다. 화면에서는 작업 대화 상자 왼쪽 아래 **오류** 단추로 엽니다.

설정을 마치면 **매개 변수로 돌아가기**를 누른 뒤 저장합니다. 설정한 작업은 오류 단추의 방패 아이콘이 채워지고 작업 영역의 줄 앞에 방패 표시가 붙습니다.

처리는 아래 차례로 적용됩니다. 재시도가 먼저 돌고, 재시도까지 실패하면 흐름 실행 계속과 새 규칙이 적용됩니다.[^errors]

| 설정 | 동작 | 쓰는 경우 |
|---|---|---|
| 재시도 정책 · 횟수 · 간격 | 정한 초만큼 기다렸다가 정한 횟수만큼 작업을 다시 실행. 문서의 기본값은 2초 간격 1회 | 페이지나 창이 늦게 떠서 나는 오류 |
| 흐름 실행 계속 | 실패해도 흐름을 이어 감. 예외 처리 모드를 고름 | 실패해도 뒤 작업을 해야 할 때 |
| 새 규칙 | 실패했을 때 할 일을 더함 | 실패 표시 남기기 · 정리 작업 |
| 고급 | 오류 종류마다 처리를 따로 구성 | 오류마다 처리가 다를 때 |

**흐름 실행 계속**의 예외 처리 모드는 셋입니다.[^errors]

| 모드 | 다음에 실행되는 것 | 조건 |
|---|---|---|
| 다음 작업으로 이동 | 순서상 다음 작업 | — |
| 작업 반복 | 같은 작업 | 성공할 때까지 되풀이 |
| 레이블로 이동 | **레이블** 작업이 있는 위치부터 | 레이블을 미리 놓음. [P19](p19-subflows.html) |

**새 규칙**으로 고르는 작업은 둘입니다.[^errors]

| 규칙 | 동작 |
|---|---|
| 변수 설정 | 정한 변수에 정한 값을 저장 |
| 하위 흐름 실행 | 정한 하위 흐름을 실행 |

같은 화면의 **자동 복구(미리 보기)**는 UI 요소를 찾지 못한 오류에서 AI가 가장 가까운 요소를 찾아 흐름을 이어 가는 기능입니다. 단일 UI 요소를 다루는 일부 UI · 브라우저 자동화 작업에만 있고, *요소를 찾을 수 없음* 오류에만 적용됩니다.[^errors]

## 작업 묶음의 오류 처리

**블록 오류 발생 시** 작업은 End 와 짝을 이루며, 사이에 놓은 모든 작업에 같은 오류 처리를 적용합니다. 작업마다 설정하지 않아도 됩니다.[^errors]

| 칸 | 값 | 기본값 |
|---|---|---|
| 이름 | 블록 이름. 표시용 | — |
| 재시도 정책 | 없음 · 고정 · 지수 | 없음 |
| 흐름 종료 오류 처리 | 0으로 나누기 · 범위 밖 항목 접근 같은 논리 오류까지 처리 | 끔 |

| 구분 | 작업 하나의 오류 설정 | 블록 오류 발생 시 |
|---|---|---|
| 적용 범위 | 그 작업 | 블록 안의 모든 작업 |
| 재시도 시작 위치 | 그 작업 | 블록의 처음 |
| 실패 뒤 계속 위치 | 다음 작업 · 같은 작업 · 레이블 | 위의 선택지에 더해 블록의 처음 또는 끝 |
| 범위 밖 목록 접근 같은 논리 오류 | 해당 없음 | 처리 가능 |

재시도가 모두 실패하면 블록의 예외 처리 모드가 적용됩니다. 블록 안 작업에 개별 오류 설정이 있으면 블록 재시도보다 그 설정이 먼저 적용됩니다.[^errors]

### 사용자 지정 오류

**사용자 지정 오류 throw** 작업은 흐름이 일부러 오류를 내게 합니다. 오류 이름과 오류 메시지를 입력하고 블록 오류 발생 시 안에 놓습니다.[^flow]

블록의 오류 처리 묶음에서 **+ 사용자 지정 오류**로 같은 오류 이름의 항목을 더하고 처리 규칙을 정합니다. 블록은 항목을 위에서 아래로 보고 이름이 같은 첫 규칙을 실행합니다. 맞는 항목이 없으면 모든 오류(기본값)의 처리를 적용합니다.[^flow]

## 마지막 오류 가져오기

**마지막 오류 가져오기** 작업은 흐름에서 마지막으로 난 오류를 오류 자료형 변수 `LastError` 에 담습니다.[^errors] 오류를 처리해 흐름을 이어 간 뒤 무엇이 실패했는지 남길 때 씁니다.

**오류 지우기**를 켜면 변수에 담은 뒤 오류를 지웁니다. 다음에 가져올 때 같은 오류를 다시 받지 않습니다. 기본값은 끔입니다.[^flow]

오류 자료형의 속성은 여섯 개입니다.[^props]

| 표기 | 값 |
|---|---|
| `%LastError.ActionName%` | 오류를 낸 작업 이름 |
| `%LastError.ActionIndex%` | 오류를 낸 작업의 번호 |
| `%LastError.SubflowName%` | 그 작업이 든 하위 흐름 이름 |
| `%LastError.Location%` | 작업과 하위 흐름의 이름 · 번호 정보 |
| `%LastError.Message%` | 오류 메시지 |
| `%LastError.ErrorDetails%` | 오류 세부 정보 |

## 샘플

흐름 `개념 연습_HGD` 를 씁니다. 없으면 [P2](p02-types.html)의 1·2번으로 만듭니다.

1. **Main** 탭의 빈 곳을 한 번 누르고 `Ctrl` + `A` 를 누른 뒤 `Delete` 를 눌러 줄을 지웁니다.
2. 작업 검색 칸에 `파일에서 텍스트` 를 입력하고 **파일에서 텍스트 읽기**를 작업 영역으로 끌어다 놓습니다. **파일 경로**에 아래를 넣고 **저장**을 누릅니다. 이 파일은 없습니다.

    ```
    C:\PA실습\없는파일.txt
    ```

3. 작업 검색 칸에 `메시지 표시` 를 입력하고 **메시지 표시**를 1번 줄 아래로 끌어다 놓습니다. **표시할 메시지**에 아래를 넣고 **저장**을 누릅니다.

    ```
    2번 줄을 실행했습니다.
    ```

4. 도구 모음의 **실행**(▶)을 누릅니다.

    **완료 기준**: 메시지 창이 뜨지 않고 실행이 멈추며, 오류 창에 1번 줄의 오류가 보인다.

5. 오류 창의 항목을 두 번 클릭합니다. 내용을 확인한 뒤 대화 상자를 닫습니다.

    **완료 기준**: 위치에 **Main** 과 1번 줄, 파일에서 텍스트 읽기가 보인다.

6. 1번 줄을 두 번 클릭해 열고 왼쪽 아래 **오류**를 누릅니다. **재시도 정책**을 **고정**으로 바꾸고 **횟수**를 `2`, **간격**을 `2` 로 둡니다. **매개 변수로 돌아가기**를 누른 뒤 **저장**을 누릅니다.

    **완료 기준**: 1번 줄 앞에 방패 표시가 있다.

7. **실행**합니다.

    **완료 기준**: 4초쯤 지난 뒤 같은 오류로 멈춘다.

8. 1번 줄을 열고 **오류**를 누릅니다. **오류 처리** 묶음에서 **모든 오류** 항목을 펼칩니다. 항목이 오류 종류별로 나뉘어 있으면 파일을 찾지 못했다는 항목을 펼칩니다. **흐름 실행 계속**을 누르고 **예외 처리 모드**를 **다음 작업으로 이동**으로 둡니다. **매개 변수로 돌아가기**를 누른 뒤 **저장**을 누르고 **실행**합니다.

    **완료 기준**: 재시도가 끝난 뒤 `2번 줄을 실행했습니다.` 창이 뜬다.

9. 메시지 창을 닫습니다. 1번 줄을 열고 **오류**를 누른 뒤 같은 항목의 **새 규칙**에서 **변수 설정**을 고릅니다. 변수와 값에 아래를 차례로 넣습니다. **매개 변수로 돌아가기**를 누른 뒤 **저장**을 누르고 **실행**합니다.

    ```
    읽기결과
    ```

    ```
    실패
    ```

    **완료 기준**: 오른쪽 세로 막대의 **{x}** 로 연 변수 창에서 `읽기결과` 가 `실패` 다.

10. 메시지 창을 닫습니다. 작업 검색 칸에 `레이블` 을 입력하고 **흐름 제어** 아래 **레이블**을 맨 아래로 끌어다 놓습니다. **레이블 이름**에 아래를 넣고 **저장**을 누릅니다.

    ```
    마무리
    ```

11. **메시지 표시**를 맨 아래로 끌어다 놓습니다. **표시할 메시지**에 아래를 넣고 **저장**을 누릅니다.

    ```
    레이블 아래 줄을 실행했습니다.
    ```

12. 1번 줄을 열고 **오류**를 누릅니다. **예외 처리 모드**를 **레이블로 이동**으로 바꾸고 `마무리` 를 고릅니다. **매개 변수로 돌아가기**를 누른 뒤 **저장**을 누르고 **실행**합니다.

    **완료 기준**: `2번 줄을 실행했습니다.` 창은 뜨지 않고 `레이블 아래 줄을 실행했습니다.` 창이 뜬다.

13. 메시지 창을 닫습니다. 작업 검색 칸에 `마지막 오류` 를 입력하고 **마지막 오류 가져오기**를 맨 아래로 끌어다 놓습니다. **오류 지우기**는 끈 채로 **저장**을 누릅니다. 결과는 `LastError` 에 담깁니다.
14. **메시지 표시**를 맨 아래로 끌어다 놓습니다. **표시할 메시지**에 아래를 넣고 **저장**을 누른 뒤 **실행**합니다.

    ```
    %LastError.ActionName% : %LastError.Message%
    ```

    **완료 기준**: 마지막 메시지 창에 작업 이름과 파일 관련 오류 메시지가 보인다.

15. 메시지 창을 모두 닫습니다. **메시지 표시**를 맨 아래로 끌어다 놓습니다. **표시할 메시지**에 아래를 넣고 **저장**을 누릅니다. 이런 이름의 변수는 없습니다.

    ```
    %없는변수%
    ```

    **완료 기준**: 오류 창에 유형이 오류인 항목이 보이고, **실행**을 눌러도 1번 줄부터 실행되지 않는다.

16. 15번에서 놓은 줄을 누르고 `Delete` 를 누릅니다.
17. `Ctrl` + `A` 를 누른 뒤 `Delete` 를 눌러 Main 을 비웁니다. 작업 검색 칸에 `블록` 을 입력하고 **흐름 제어** 아래 **블록 오류 발생 시**를 작업 영역으로 끌어다 놓습니다. **이름**에 아래를 넣습니다.

    ```
    읽기 묶음
    ```

18. **흐름 실행 계속**을 누르고, 블록 끝에서 계속하는 항목을 고른 뒤 **저장**을 누릅니다.

    **완료 기준**: 작업 영역에 **블록 오류 발생 시**와 **End** 두 줄이 있다.

19. **파일에서 텍스트 읽기**를 두 줄 사이로 끌어다 놓고 **파일 경로**에 아래를 넣은 뒤 **저장**을 누릅니다.

    ```
    C:\PA실습\없는파일.txt
    ```

20. **메시지 표시**를 19번 줄 아래, **End** 위로 끌어다 놓습니다. **표시할 메시지**에 아래를 넣고 **저장**을 누릅니다.

    ```
    블록 안 둘째 줄입니다.
    ```

21. **메시지 표시**를 **End** 아래로 끌어다 놓습니다. **표시할 메시지**에 아래를 넣고 **저장**을 누른 뒤 **실행**합니다.

    ```
    블록 뒤 줄입니다.
    ```

    **완료 기준**: `블록 안 둘째 줄입니다.` 창은 뜨지 않고 `블록 뒤 줄입니다.` 창이 뜬다.
