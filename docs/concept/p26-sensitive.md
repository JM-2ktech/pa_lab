## 값을 넣는 방법

| 방법 | 화면 표기 | 저장되는 것 | 다른 컴퓨터 |
|---|---|---|---|
| 직접 입력 | **직접 암호 입력** · **직접 암호화 텍스트 입력** | 컴퓨터 기준으로 암호화한 값 | 다시 입력해야 함 |
| 민감 변수 | **변수로 암호 입력** · **텍스트, 변수 또는 식으로 입력** | 변수 참조 | 그대로 사용 |
| 자격 증명 | **자격 증명 가져오기** | 자격 증명 참조 | 그대로 사용. 프리미엄 기능 |
| 평문(쓰지 않는 방법) | **변수 설정**의 값 칸 | 값 그대로 | 그대로 사용 |

직접 입력은 입력한 컴퓨터의 Data Protection API 로 암호화합니다.[^expr] 다른 컴퓨터에서 열면 흐름이 유효하지 않음으로 표시되고 암호를 다시 넣어야 합니다.[^passwords] 그대로 실행하면 `Expression couldn't be evaluated` 오류가 납니다.[^expr]

여러 컴퓨터에서 쓰는 흐름은 변수로 넣고 그 변수를 민감으로 표시합니다.[^expr] 흐름 검사기의 「안전하지 않은 암호 보안」 규칙도 같은 방법을 제안합니다.[^checker]

민감으로 표시해도 **변수 설정**에 직접 쓴 값은 보호되지 않습니다. 흐름 로그는 보호되지만 작업 대화 상자와 Dataverse 의 흐름 정의에 값이 보입니다.[^vars]

## 입력을 받는 경우

| 경로 | 설정 | 동작 |
|---|---|---|
| **입력 대화 표시** | **입력 유형**을 **암호**로 | 입력 글자를 가림. 결과는 텍스트 값 `UserInput`[^display] |
| 입력 변수 | **민감함으로 표시** | 콘솔의 **흐름 입력** 창과 변수 창에 기본값을 보이지 않음[^vars] |
| 클라우드 흐름 | 작업 **…** › **설정** › **보안 텍스트** | 흐름 입력 값을 로그에서 뺌[^secure] |

입력 변수의 기본값은 시험과 디버깅용입니다. 작업 대화 상자와 Dataverse 흐름 정의에서는 보호되지 않습니다.[^vars]

지침 문서는 민감한 값을 입력 변수로 넘기는 대신 **자격 증명 가져오기**를 권합니다. 자격 증명 변수는 기본으로 민감이고 실행 로그에 저장되지 않습니다.[^secure-guide]

## 자격 증명

자격 증명은 포털에서 만들고 비밀은 Azure Key Vault 또는 CyberArk 에 둡니다.[^secure-guide]

| 쓰는 곳 | 용도 |
|---|---|
| 데스크톱 흐름 연결 | 실행 때 컴퓨터에 로그인. 컴퓨터 매핑 · 인증서 기반 인증으로 MFA 요구 충족 |
| 데스크톱 흐름 | **자격 증명 가져오기**로 앱 · 파일에 로그인. SAP · SharePoint · Excel 암호 등 |
| 네트워크 | 호스트형 컴퓨터 그룹의 Microsoft Entra 하이브리드 조인 네트워크 연결 |

**자격 증명 가져오기**는 실행 때만 값을 가져오고 로그에 남기지 않습니다.[^credential] 환경 변수의 Azure Key Vault 비밀을 Dataverse 커넥터 작업으로 읽는 방법도 있습니다. 그 작업의 출력을 민감으로 표시합니다.[^secure-guide]

## 민감 변수

민감으로 표시한 변수는 디버깅할 때 변수 창에서 값이 가려집니다.[^vars]

| 조작 | 위치 |
|---|---|
| **민감함으로 표시** | 변수 창에서 변수를 마우스 오른쪽 단추로 누른 메뉴 · 변수 옆 아이콘 · **흐름 변수 편집** 창 |
| **민감하지 않음으로 표시** | 변수 창에서 변수를 마우스 오른쪽 단추로 누른 메뉴 · 변수 옆 아이콘 |
| 값 잠시 보기 | 디자이너에서 마스크 해제. 다시 마스크 가능 |

| 규칙 | 내용 |
|---|---|
| 적용 단위 | 변수 전체. 목록 항목 · 데이터 테이블 열 · 속성 하나만 표시할 수 없음 |
| 자료형 | 어떤 자료형도 가능 |
| 작업에서 사용 | 모든 작업에서 제한 없이 사용. 식에 넣으면 로그가 식 전체를 민감으로 처리 |
| 상속 | 다른 변수에 대입한 결과는 민감이 아님 |
| 상속의 예외 | 자격 증명 변수와 그 `Password` 속성. 항상 민감 |
| 보호 수준 | 변수 창의 마스크는 화면을 보는 제3자에 대한 기본 보호 |

v2.13 이하에서 만든 흐름은 편집하지 않으면 이전 동작을 유지합니다. v2.14 이상에서 편집하고 저장하면 암호화 입력 변수가 민감 표시된 텍스트 변수로 바뀝니다. 이렇게 저장한 흐름은 이전 버전에서 열리지 않습니다.[^vars]

## 값이 드러나는 곳

| 위치 | 민감 변수의 값 | 조건 |
|---|---|---|
| 변수 창(디버깅) | 가려짐 | 마스크를 해제하면 보임 |
| **변수 설정** 줄의 요약 | 가려짐 | |
| 흐름 로그의 **변수 설정** 입력 세부 정보 | 보이지 않음 | |
| 포털 실행 기록 | 저장되지 않음 | 조직 프리미엄 계정으로 로그인, 콘솔 또는 클라우드 흐름에서 실행 |
| **메시지 표시** | 보임 | |
| 데스크톱 흐름 밖으로 보낸 값 | 보임 | |
| 대입받은 다른 변수 | 보임 | 그 변수를 따로 표시하지 않았을 때 |
| **변수 설정** 값 칸에 직접 쓴 값 | 보임 | 작업 대화 상자와 Dataverse 흐름 정의 |
| 입력 변수 기본값 | 보임 | 만들기 · 편집 대화 상자, 작업 대화 상자, Dataverse 흐름 정의 |

**메시지 표시**의 내용은 흐름 실행 세부 정보에도 기록됩니다.[^monitor] 민감하지 않은 연결 문자열에 민감한 암호 변수를 넣지 않습니다.[^secure-guide]

클라우드 흐름 쪽은 작업 설정의 **보안 입력** · 「보안 출력」을 켭니다. 값이 로그에 보이지 않고 작업 오른쪽 위에 잠금 아이콘이 생깁니다.[^secure] [C24](c24-secure.html)에서 다룹니다.

## 실례: Lab 7 비밀번호 칸

[Lab 7](../lab7.html) 15번은 로그온 창의 비밀번호 칸을 **창에서 텍스트 필드 채우기**로 채웁니다.

| 상태 | 화면 | 설명 |
|---|---|---|
| **채울 텍스트**에 평문 입력 | 경고 「삽입된 텍스트 상자는 암호 필드입니다」 | 경고가 직접 암호화 입력과 민감 플래그 변수 두 가지를 제시 |
| **직접 암호화 텍스트 입력** 선택 | 값이 ●로 가려짐, 경고 없음 | 그 랩이 고른 방법 |
| 작업 영역 3번 줄 | `●●●●●` | 값이 요약에 나타나지 않음 |

이 방법은 입력한 컴퓨터에서만 값을 풉니다. 다른 PC 에서 이 흐름을 열면 3번 줄의 값을 다시 넣습니다.

같은 칸을 민감 변수로 채우려면 채울 텍스트의 입력 방식을 **텍스트, 변수 또는 식으로 입력**에 두고 민감으로 표시한 변수를 넣습니다. 이때 값의 출처가 「변수 설정」이면 위의 평문 규칙이 그대로 적용됩니다.

## 그 밖의 보호 수단

**액세스.** 데스크톱 흐름의 액세스는 소유자 · 공동 소유자 · 사용자입니다. Process 테이블 전체의 읽기 권한을 주는 Dataverse 보안 역할을 가진 사용자는 환경의 모든 데스크톱 흐름에서 공동 소유자가 됩니다.[^secure-guide]

| 공유할 때 함께 볼 구성 요소 | 흐름에서 쓰는 방법 |
|---|---|
| 자식 데스크톱 흐름 | **데스크톱 흐름 실행** |
| 작업 큐 | 작업 큐 작업 묶음 |
| 자격 증명 | **자격 증명 가져오기** |
| UI 요소 컬렉션 · 사용자 지정 작업 | 자산 라이브러리 |
| 연결 참조 | 클라우드 커넥터 작업 |

**데이터 손실 방지.** 정책으로 데스크톱 흐름의 작업 묶음을 비즈니스 · 비즈니스 외로 나누고, 작업이나 묶음을 차단합니다. 「커넥터 작업」 설정에서 개별 작업을 허용하거나 차단합니다.[^secure-guide]

**감사.** Dataverse 감사를 환경과 해당 테이블에서 켜면 데스크톱 흐름 관련 테이블의 변경과 접근을 추적합니다.[^secure-guide]

## 샘플

민감 표시의 동작과 상속되지 않는 것을 변수 창에서 확인합니다. `ABC-123` 은 연습용 글자입니다. 실제 비밀번호는 **변수 설정**에 넣지 않습니다.

흐름 `개념 연습_HGD` 를 씁니다. 없으면 [P2](p02-types.html)의 1·2번으로 만듭니다.

1. 콘솔 왼쪽 막대의 **흐름**을 누르고 `개념 연습_HGD` 의 **편집**을 누릅니다.
2. 작업 영역의 빈 곳을 한 번 누르고 `Ctrl` + `A` 로 전체를 선택합니다. 선택한 줄을 마우스 오른쪽 단추로 눌러 **삭제**를 고릅니다.
3. 작업 검색 칸에 `변수 설정` 을 입력하고 **변수 설정**을 끌어다 놓습니다. **변수**와 **값**에 아래를 차례로 넣고 **저장**을 누릅니다.

    ```
    연습값
    ```

    ```
    ABC-123
    ```

4. **변수 설정**을 1번 줄 아래로 하나 더 놓고 아래를 넣은 뒤 **저장**을 누릅니다.

    ```
    사본
    ```

    ```
    %연습값%
    ```

5. 도구 모음의 **실행**(▶)을 누르고, 오른쪽 세로 막대의 **{x}** 를 눌러 변수 창을 엽니다.

    **완료 기준**: **흐름** 묶음에서 `연습값` 과 `사본` 옆에 `ABC-123` 이 보인다.

6. 변수 창에서 `연습값` 을 마우스 오른쪽 단추로 눌러 **민감함으로 표시**를 고릅니다.
7. **실행**(▶)을 누릅니다.

    **완료 기준**: `연습값` 의 값은 가려지고, `사본` 옆에는 `ABC-123` 이 보인다.

8. 작업 영역의 1번 줄을 봅니다.

    **완료 기준**: **변수 설정** 줄의 요약에 `ABC-123` 이 보이지 않는다.

9. 작업 검색 칸에 `메시지 표시` 를 입력하고 **메시지 표시**를 2번 줄 아래로 끌어다 놓습니다. **표시할 메시지**에 아래를 넣고 **저장**을 누릅니다.

    ```
    %연습값%
    ```

10. **실행**(▶)을 누릅니다.

    **완료 기준**: 메시지 창에 `ABC-123` 이 보인다.

11. 메시지 창의 **확인**을 누릅니다. 변수 창에서 `연습값` 을 마우스 오른쪽 단추로 눌러 **민감하지 않음으로 표시**를 고릅니다.
