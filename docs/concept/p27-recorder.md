## 레코더가 만드는 것

레코더는 UI 요소에 대한 마우스와 키보드 동작을 추적해 동작마다 따로 기록합니다. 한 세션에서 UI 자동화 작업과 브라우저 자동화 작업을 모두 만듭니다.[^rec]

**완료**를 누르면 기록한 단계가 작업으로 바뀌어 작업 영역에 들어갑니다. 생성된 작업이 쓰는 UI 요소는 UI 요소 창에 자동으로 추가됩니다.

왼쪽 또는 오른쪽 클릭 뒤에는 강조 표시에 대기 메시지가 뜹니다. 레코더가 작업을 기록해 넣을 때까지 기다립니다.

---

## 조작

| 라벨 | 위치 | 동작 |
|---|---|---|
| **레코더** | 디자이너 도구 모음 | 레코더 창 열기 |
| **레코드** | 레코더 창 | 기록 시작 |
| **일시 중지** | 레코더 창 | 기록 잠시 멈춤 |
| **설명 추가** | 레코더 창 | 기록한 작업에 글 남기기 |
| **완료** | 레코더 창 | 단계를 작업으로 변환 |
| 점 아이콘 | 레코더 창 오른쪽 | **새 웹 브라우저 실행** · **이미지 녹음/녹화** |
| **캡처 모드** | 레코더 창 | UIA · MSAA 선택 |
| 오른쪽 클릭 | 기록 중인 요소 | 그 요소에서 쓸 수 있는 작업 메뉴 |

---

## 캡처 모드

| 모드 | 대상 | 특징 |
|---|---|---|
| UI Automation(UIA) | 대부분의 Windows 앱. WPF · WinForms · UWP | 요소 정보가 자세하고 계층 구조가 나음. 문서의 권장 모드 |
| Microsoft Active Accessibility(MSAA) | UIA 요소를 내놓지 않는 이전 앱. VB6 · 클래식 Win32 | 정보가 적음. UIA 를 쓸 수 없을 때 사용 |

## 입력 형태별 처리

| 대상 | 레코더의 동작 |
|---|---|
| 끌어서 놓기 | **창 크기 조정** · **창 이동** 작업 생성. **창의 UI 요소 끌어서 놓기**는 지원하지 않음 |
| 드롭다운 목록 | 전용 화면에서 값을 고름. 다중 선택이면 여러 값. 실행 때 그 값을 고르고 **확인**을 누름 |
| 날짜 선택기 | 전용 텍스트 칸에 지정 형식으로 입력. HTML 형식 date · datetime-local · month · time · week |
| 색 선택기 | 전용 텍스트 칸에 16진수 코드 입력 |
| IME 입력 | 칸을 오른쪽 클릭 › **텍스트 필드 채우기** › 창에 입력 › **텍스트 추가** |

브라우저를 띄우는 방법은 셋입니다.

| 방법 | 생성되는 것 |
|---|---|
| 점 아이콘 › **새 웹 브라우저 실행**에서 Edge · Chrome · Firefox · Internet Explorer 선택 | 로드된 페이지를 감지해 브라우저 실행 단계 구성 |
| 이미 열린 브라우저에서 기록 시작 | 로드된 페이지를 감지해 브라우저 실행 작업 생성 |
| 바탕 화면 · 시작 메뉴 · 작업 표시줄 · 폴더의 바로 가기로 직접 실행 | 바로 가기를 눌러 여는 UI 자동화 작업 생성 |

## 이미지 기반 기록

접근성 API 를 내놓지 않거나 기록을 막는 앱에서 씁니다. 이미지 인식과 OCR 로 요소를 찾고 텍스트를 뽑습니다.[^rec]

1. 레코더 창의 점 아이콘을 누르고 **이미지 녹음/녹화**를 켭니다.
2. **레코드**를 누릅니다.
3. 요소를 누르면 이미지가 자동으로 캡처되고 편집할 수 있는 기본 이름으로 저장됩니다.

텍스트를 뽑을 때는 화면을 오른쪽 클릭하고 **이미지에서 텍스트 추출**을 고릅니다. 텍스트 영역을 고른 뒤, 라벨처럼 바뀌지 않는 고정 영역을 고릅니다. 추출에는 Tesseract OCR 엔진을 씁니다.

## 기록과 직접 구성

| 항목 | 레코더 | 직접 구성 |
|---|---|---|
| 만드는 방법 | 앱에서 동작을 수행 | 작업 창에서 작업을 끌어다 놓고 칸을 채움 |
| 조건 · 반복 | 기록되지 않음 | **If** · **반복** · **각각의 경우**를 놓음 |
| 중복 작업 | 생길 수 있어 지움 | 넣은 작업만 있음 |
| UI 요소 | 자동 추가 | 작업 대화 상자의 **UI 요소 추가**로 잡음 |
| 결과 수정 | 끝난 뒤 작업을 손으로 편집 | 같음 |
| 쓰임 | 흐름의 기본 틀. 단순한 작업은 그대로 쓰기도 하고 대부분 수정이 필요함 | 처음부터 끝까지 구성 |

개발 중인 흐름에서 레코더를 실행하면 기록한 단계가 그 흐름에 더해집니다.[^rec]

## 알려진 제한

| 문제 | 해결 방법 |
|---|---|
| Windows 시작 메뉴 · 시스템 트레이의 단계가 일부 기록되지 않음 | 없음 |
| 이미지 기반 기록으로 만든 흐름의 클릭이 다른 곳으로 감 | 생성된 **이미지로 마우스 이동**의 고급 설정에서 **허용 범위**를 낮춤 |
| 오른쪽 클릭 뒤 **이미지에서 텍스트 추출** 팝업이 앱 팝업 뒤로 숨음 | 화면의 다른 곳을 오른쪽 클릭 |
| 최대화한 RDP 창에 보낸 키 입력이 이미지 기반 기록에 남지 않음 | RDP 창 크기를 줄여 전체 화면을 가리지 않게 함 |

## Record with Copilot

Record with Copilot(AI 레코더)는 문서 제목에 deprecated 로 표시되어 있습니다. 문서는 이 기능을 사용 중단했고 Power Automate for desktop 에서 쓸 수 없다고 적습니다.[^ai]

문서가 제시하는 대안은 둘입니다.

| 대안 | 내용 | 조건 |
|---|---|---|
| Copilot 으로 흐름 만들기 + 레코더 | 자연어로 흐름을 설명하고 필요하면 레코더를 씀 | 미리 보기. 회사 또는 학교 계정, 미국에 있는 환경, 영어[^copilot] |
| Copilot Studio 의 computer use | 에이전트를 만들어 자연어로 컴퓨터 작업을 자동화 | Microsoft Copilot Studio |

Copilot 이 브라우저나 UI 작업을 찾으면 임시 작업을 넣습니다. 레코더로 기록하면 이 작업이 기록 결과로 바뀝니다. 기록하기 전에는 설계 시 오류가 표시되고, 기록하거나 지우거나 끄면 사라집니다.[^copilot]

## 샘플

모의 공고 사이트에서 검색을 기록하고 생성된 작업을 읽습니다. Edge 확장이 설치되어 있어야 합니다.

흐름 `개념 연습_HGD` 를 씁니다. 없으면 [P2](p02-types.html)의 1·2번으로 만듭니다.

1. 콘솔 왼쪽 막대의 **흐름**을 누르고 `개념 연습_HGD` 의 **편집**을 누릅니다.
2. 작업 영역의 빈 곳을 한 번 누르고 `Ctrl` + `A` 로 전체를 선택합니다. 선택한 줄을 마우스 오른쪽 단추로 눌러 **삭제**를 고릅니다.
3. Edge 주소창에 아래 주소를 넣고 엽니다.

    ```
    {{ site.url }}{{ site.baseurl }}/practice/bid/
    ```

4. 디자이너로 돌아와 도구 모음의 **레코더**를 누릅니다.
5. 레코더 창의 **레코드**를 누릅니다.
6. Edge 로 가서 **공고명** 칸을 마우스 오른쪽 단추로 누르고 **텍스트 필드 채우기**를 고릅니다.
7. 열린 창에 아래를 넣고 **텍스트 추가**를 누릅니다.

    ```
    교육
    ```

8. **검색** 단추를 누릅니다. 대기 메시지가 사라질 때까지 기다립니다.

    **완료 기준**: 레코더 창에 기록된 단계가 보인다.

9. 레코더 창의 **완료**를 누릅니다.

    **완료 기준**: 작업 영역에 브라우저를 다루는 작업, 텍스트 필드를 채우는 작업, 단추를 누르는 작업이 생긴다.

10. 오른쪽 세로 막대의 **UI 요소** 단추를 눌러 UI 요소 창을 엽니다.

    **완료 기준**: 공고명 칸과 검색 단추의 요소가 보인다.

11. 도구 모음의 **실행**(▶)을 누릅니다.

    **완료 기준**: 사이트에 `검색 결과 16건` 이 보인다.

12. 작업 영역의 줄을 읽어 조건과 반복이 없는 것을 확인합니다. 도구 모음의 **저장**을 누릅니다.
